## 维护规则(写入 nvr-tutor 指引)

1. **增卡**:每个带 ID 任务收口时,tutor 把该任务解锁的 why 题按模板写入对应模块文件;禁止一次突击补写历史卡(违背间隔重复)。
2. **复测**:**2026-08-21起暂缓执行(用户要求,保证主线进度)**——到期卡只登记累积,不出题、不降级;项目最终收尾(Phase 6/总结)统一批量复测,届时按优先级抽 ①错误台账(M-xxx)关联卡 ②状态栏到期(到期越久越优先)的卡,结果当场写回状态行。
3. **升级**:全部通过 3 次提取(首次+24h+72h)的卡标"✅ 长期",Phase 6 只抽查长期卡+模拟面试。
4. **面试话术打磨**:Phase 6.2 时才把"要点"润色成口语话术;学习阶段保持技术准确优先。
