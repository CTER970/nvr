## 2. 闭卷题（8 问，手册原样；三必对=1/3/6）

1. 为什么 JPEG 返回 malloc 拷贝？（1.9-Q4 迁移+本 Phase 双消费者）
2. 为什么慢云请求不阻塞录像，却降低 AI 实际采样率？（周期=云耗时+interval）
3. 为什么 event_bus 回调必须快返回、延时报警放线程？（发布者线程上下文+锁外同步）
4. `none` 在哪过滤？是总线强制规则吗？（cloud_ai c:276；否）
5. alarm 回调和 GPIO 延时各在哪个线程？（发布者线程 / 报警线程）
6. Web 事件列表是推送还是查询？（查询，请求到来才查库）
7. DB 成功、快照失败时系统表现？（事件在库、回调照发、无快照图）
8. AI 关闭时录像/预览/本地转发为何仍可继续？（旁路隔离——三分发各自独立）
