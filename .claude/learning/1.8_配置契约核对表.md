## 审计发现（注释 vs 代码，三层证据）

1. **conf.c:196 注释与代码冲突**：注释称敏感字段（anthropic_auth_token/mqtt_user/mqtt_pass）"不在 format_value 白名单（写回=原值）"，但 c:218/235/236 实际处理了它们 → **conf_save 会把 token/密码写回 gateway.conf 落盘**（含经 Web POST /api/config 设置的值）。工程结论：磁盘明文密钥风险仍在，但 Web GET 回显已脱敏（web.c:608-620，仅显前 8 字符+****）。
2. 启动必需性实然：配置文件缺失=致命退出（main.c:117）；rtsp_url/storage_dir 为空不退出，分别表现为"拉流永远重连"“录像停摆"（主功能失效）；sqlite 缺失仅告警降级。
3. 解析器边界：`#` 后一律截断、不支持引号 → 值不能含 `#`（ai_prompt 注释已在样例中标注）。
