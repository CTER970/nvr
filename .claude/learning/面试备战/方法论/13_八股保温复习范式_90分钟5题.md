# 13 · 八股保温复习范式：90 分钟 / 5 题

> 制定：2026-10-25，依据用户本轮授权。作者：ClawsGO Science Agent。
> **地位：后续已学通用八股复习场的统一生成与管理规范。**首学/整点重教继续用 [12 号教学范式](12_八股教学范式_2026-10-18.md)；手撕、项目源码学习、冷面模拟面试各走原轨道。
> 事实源：[06 点级总表](../通用八股底稿/06_复习进度总表.md)、[02 错题册](../通用八股底稿/02_错题与战绩册.md)、[17 首轮统计](../通用八股底稿/17_第一轮学习统计分析_2026-10-25.md)。场次和最近复习状态统一记入 [18 场次管理](../通用八股底稿/18_保温复习场次管理与首场样例.md)。

## 一、目标与适用范围

首轮已覆盖的知识，以闭卷提取检查保留程度，用少量代表性问题找出遗忘、理解断点和表达风险。已会内容及时结束；局部缺口局部修复；基础模型确实失效时再重教对应考点。90 分钟为完整学习段预算，涵盖回答、判定、纠偏、必要复述和落账，不作为必须耗满的时长。

P0 首轮基线=29 活跃点全部过线（28「过」+ #30 快筛过维持）。这代表历史学习结果；隔时稳定程度由后续复习证据更新。P1 未学点、栈帧卡未验证部分和 BV 未学内容单列新学，不混入保温卷计作遗忘。#30 保持现有深度，已移除的 485 深化不恢复。

## 二、场次单位与题量

| 项目 | 默认规则 |
|---|---|
| 一场 | R01、R02……连续编号；约 90 分钟，默认每天至多一场，由用户决定实际频率 |
| 一题 | 一个考点的一道主问题，可含至多两个同主题、顺接的子问；通常覆盖结论及核心因果/旧错点 |
| 五题 | 默认覆盖五个不同考点；同考点的追问、补说和复述均不另计题数 |
| 追问上限 | 首答已显示机制与边界则停止；缺乏判定依据时至多补一个诊断追问，不另拉出一套三问验收 |
| 完成条件 | 已考题完成判定并登记下次动作；遇重教或用户喊停，可少于五题，剩余题标「未考」顺延 |
| 加量 | 前两场先试运行；用户报告用时明显有余、补教少且体验合适时，再与用户确认增至六题；不自动扩题 |

**一场不等于一轮。**一轮覆盖指当前保温池中每个考点至少接受一次有效闭卷抽查。29 点每场五个不同点，理论最少六场；错题复核占位时可能更多。覆盖完成也不等于全部稳定。

## 三、如何抽题：默认三道薄弱题 + 两道核心题

| 题位 | 选取依据 | 规则 |
|---|---|---|
| 1–3 | 历史答错、冷验复发、明确自报未内化、上场补教后待独立复核 | 优先当前仍有风险者；已经隔时独立答对的旧错降低抽样频率，不永久占位 |
| 4–5 | 已学的岗位核心高频题 | 优先本轮尚未覆盖且距上次独立回答最久者，检查熟悉题是否仍会 |

- 同时属于薄弱和高频的考点只占一个题位。默认配比可调，不为凑三道错题反复考已稳定内容。
- 同优先级先照顾未覆盖考点，再看上次有效回答时间；从同档候选中轮换，避免一直抽固定五点。
- 一场尽量跨两个知识簇，例如 C/内存、网络、并发；同一病根适合集中修复时可做专题场并说明原因。
- 核心题轮换不依赖纯随机；历史错题有优先权，全池覆盖有保底。首轮覆盖期间，同一考点通常不连续两场出现，待补教/待复核者例外。
- 有明确面试邀约时，五题可按对应岗位调整，仍标注抽样依据；不以邀约为由无边界拓深。

## 四、问卷的题源与呈现

### 4.1 两类题源分别标识

1. **面经原问**：标可核验的现行来源编号和文档位置；引用前查编号是否已退役或原帖存疑。教学卡的公司标签只作导航，不能直接充当新核验结果。
2. **历史错题复测问**：回到02册/历史学习记录中的真实缺口，用清楚的日常面试语言整理；标「历史复测整理」，不冒称公司原题。只复测已学的核心机制，不编新工况或破坏式变式。

本轮用户指定的「考历史错题+核心题」按上述两池执行。旧教学模板中的必做变式、每点必答三问不套入保温场。新领域内容、未学细节以及来源不明的所谓高频题不作为保温失败依据。

### 4.2 学生卷与执行记录分开

- 开场给场次定位：五个考点、预算、闭卷说明、本场目的。默认**逐题发出、逐题回答与闭环**；五题清单可预览。用户要求整卷作答时可一次发问卷，作答期间不插答案。
- 学生卷只放完整问句、编号、必要条件；作答前不放答案、关键词清单、旧错误原句或评分要点。
- 题干涉及代码时先核源码行号并附锚点；纯概念题无需强绑源码。复习记录、题源与讲评后参考位置另列。
- 不强制先预习当场抽中的内容；用户若刚读过该节，应如实标「预热后回答」，与冷答分开记录。
- 口述优先、文字等价；不要求照范文措辞、固定字数或背齐所有扩展知识。

## 五、90 分钟的建议分配

| 环节 | 推荐用时（预算） | 当前进度 / 已用时间 |
|---|---|---|
| 场次定位与闭卷说明 | 5 分钟 | 开场填写；实际用时由用户报告 |
| 五题串行：首答→必要追问→判定→轻量纠偏 | 每题约 10 分钟，共 50 分钟 | 逐题标已考/未考；无报告则用时记「未报告」 |
| 集中修复最影响理解的 1–2 个缺口 | 20 分钟 | 无缺口可省；勿为凑时长补新知识 |
| 本场总结、记录、下次抽样安排 | 10 分钟 | 五题各一行；保留首答与提示情况 |
| 缓冲/短休息 | 5 分钟 | 可按当场节奏前移 |
| **总预算** | **90 分钟** | **完成五题是默认目标，理解闭环优先** |

某点需要完整重教时，在剩余预算内改为该点修复，或登记独立补教场；不强行把五题拖成数小时。提前顺利完成可提前结束。时间只控节奏，不作为掌握依据。

## 六、如何判断程度：先保存首答，再按缺口分流

每题至少看四件事：结论是否准确、关键因果能否自述、是否有致命边界误解、是否独立回答。表达风险单独记录；意思明确的省略不直接判概念错误。歧义时先请学生澄清，接受申诉并核实事实。

| 本次结论 | 证据 | 当场动作 | 后续 |
|---|---|---|---|
| 独立通过 | 无提示说明结论与核心因果；旧错点被本题有效覆盖；必要追问也成立 | 确认通过，给简短反馈，进入下一题 | 本轮已覆盖；已有隔时通过证据者适当拉长间隔 |
| 表达待精化 | 模型成立，个别主语、方向或术语引发歧义；澄清后自证正确 | 只改风险句，重说一次 | 记录表达问题；无需整点重教 |
| 局部待补 | 主线正确，一段因果、旧错点或边界缺失；提示后才能补出 | 讲清缺口，再由学生用自己的话说明 | 登记「待独立复核」，不把提示后复述写成冷答通过 |
| 需重教 | 核心结论错、关键因果断裂，澄清后仍无法建立基本模型 | 针对该考点启用12号建模教学；可另排修复场 | 重教完成后仍需隔时独立复核 |
| 未考/未覆盖 | 未作答、只有自评、题目未触及对应旧错点 | 保留未知，必要时调整下次题目 | 不记通过，不把漏测的子点自动判稳定 |

**一题只能支持被抽到的部分。**抽查核心问过了，可记该考点「本次代表性抽查通过」；未涉及的旧错点继续留在队列，不据此宣称整个考点全部掌握。若旧错与核心可在一个自然问句中同时观察，就合并考，避免拆成大量零碎问题。

重教升级规则：单个表达小错不触发整点重学；同一关键机制连续两次独立复核仍失败，或一次出现基础模型明显失效，进入定向重教。重教范围止于该点的实际缺口；不重跑整批或整轮。

## 七、间隔与状态管理

保温采用独立状态，保留06表的历史学习结果：

`待抽查 → 本次独立通过 → 隔时复核通过（稳定保温）`

`局部待补 / 需重教 → 补教完成·待独立复核 → 本次独立通过`

- 初始全部为「待抽查」，表示尚无本范式下的复习证据，不能解释为过去都不会。
- 当场看答案、接受提示后重说，记修复结果；隔时无提示再答才记独立通过。
- 补教后建议隔1–3天再抽；已独立通过者建议约7天复核；两次独立通过且至少隔3天，可延长到约14天或临面抽查。均为调度建议，不是必须每天完成的硬任务。
- 稳定点仍进入低频轮换；一旦回归失败，只更新该点当前复习状态，历史首学通过事实保留。
- 本规则适用于本轮授权的八股保温。项目主线Phase复测暂缓规则保持原状；手撕独立管理。

## 八、每场必须留下的最小记录

| 字段 | 填写要求 |
|---|---|
| 场号/日期/版本 | R01起；问卷调整保留修改原因；未开考标「待开始」 |
| 题目与考点 | 保存实际问句、#号、薄弱/核心标签；题源与历史缺口位置 |
| 首答证据 | 原话或忠实摘要；注明冷答/预热、无提示/轻提示/强提示/范文辅助 |
| 判定与错因 | 采用第六节结论；概念/因果/边界/表达分开 |
| 修复结果 | 教了什么、学生能否自产说明；无修复写「无需」 |
| 下次动作 | 待复核的具体子点、建议日期或场号；未考题顺延 |
| 时间 | 推荐预算与用户自报实际值分列；未知写「未报告」 |

- 18号记录场次与当前保温状态，是复习调度唯一入口；02册只增补新暴露的实质错误或旧错复发，并链接场次，避免复制全套答案。
- 06表首学通过历史保留；仅新增复习入口及必要的当前风险指针。17号统计保留为2026-10-25快照，不随每场改写历史统计。
- 每场统计：计划题数、已考数、独立通过数、待精化数、局部待补数、需重教数、未考数；各类判定互斥。通过率分母为已考题，分母为0时写「尚未开考」。
- 覆盖进度分母为当前保温池考点数，重考不重复增加覆盖数；稳定点数另列，不与覆盖率混用。

## 九、后续生成指令（可直接复用）

> 请按《13_八股保温复习范式_90分钟5题》生成下一场。先局部查06首学状态、02历史错题、18场次与复核队列；默认90分钟五道主问题，三道薄弱题加两道核心题，优先本轮未覆盖与到期复核。每题一个考点、至多两个顺接子问，不凑必答三问，不编新情境变式。面经原问核验来源，历史错题复测问明确标整理。先生成无答案学生卷，默认逐题闭环。保存首答、提示程度、分级判定、修复和下次动作；答得好即停，缺什么补什么，必要时只重教失败考点。收场更新18，实质错题再入02；未考标未考，未报告用时标未报告。当前只生成或执行用户指定的一场，不预判通过、不自动推进P1/Phase。
