## 一、五步循环总览（骨架保持，v2.1 内容升级）

```
① 定深与边界 → ② 建模教学 → ③ 迁移考察 → ④ 证据复盘 → ⑤ 分级落册
```

> **执行形态铁律（10-19 用户拍板，v2.1.1 补）**：五步按**单点串行闭环**执行——一个点完整走完"②教学→③考察→④复盘→⑤落册"后，才进入下一个点。**禁止多点并发出卷**（一场教学 N 题齐发后统一判卷的形态不采用）。合场/深潜场也遵守：多个点在同一会话内**逐个**过，每点独立闭环。唯一例外：③考察内部的三问+扩展属于同一点，可一次发出待答。

| 步 | 做什么 | 一句话规则 |
|---|---|---|
| ① 定深与边界 | 查 15 号图定目标层 + **层次声明**（§二.0） | 先说清"本题讨论哪一层、暂不讨论什么" |
| ② 建模教学 | 四件套 + 按知识类型选图（§二） | 原理讲透可以慢；收口收出主轴句+声明"图外还有" |
| ③ 迁移考察 | **必答三问 + 扩展池**（§三） | 考察不重复刚讲的原句，重点测迁移 |
| ④ 证据复盘 | 判层+**双坐标**+纠错四型+自报+复述（§四） | 复盘比重 ≥ 考察 |
| ⑤ 分级落册 | 轻量/完整两档 + 预付三态（§六） | 一场一清；落册成本与八股覆盖面平衡 |

## 二、建模教学（v2.1：层次声明 + 四件套 + 图类型选择）

### 2.0 层次声明（新增，开场第一句）

多层知识点（内存分区/const/编译链接/虚拟内存等）开教前勾选：

```
本题现在讨论的是：□ 语言语义 □ 编译/链接布局 □ 进程运行时 □ 内核机制 □ 工程实现
暂不讨论：____；最后交付：____
```

示例（内存分区）："今天以**进程运行时的典型虚拟地址空间**为主线，再补它与 C 存储期、ELF 节的对应——三层相关但不等价，答问先分清在哪层。"——这条直接预防"局部变量一定在栈上/const 一定在 .rodata"这一族层次混淆（今日核验的 const 硬伤即此类）。

### 2.1 图类型选择表（按知识类型配图，用户确认"图表要保留且按类型选"）

| 知识类型 | 推荐图形 | 库内实例 |
|---|---|---|
| 空间布局类 | 地址空间图/区域图 | 内存六区图（A1 卡1） |
| 时间变化类 | 三时刻快照/状态转移图 | 函数调用三时刻（A1 卡2）、TCP 状态机（A3 卡2） |
| 数据流类 | 输入—处理—输出链路图 | H.264 传感器到屏链路（B 层）、零拷贝路径 |
| 对比机制类 | 并排流程图 | 阻塞 vs 非阻塞（A3 卡8）、TCP vs UDP |
| 算法/结构类 | 指针图/索引图 | 环形缓冲读写索引（A4 卡2）、链表反转（手撕） |
| 生命周期类 | 创建—使用—失效时序图 | 帧的生命周期（BV-05） |

规则：图**必配**（流程图/框架图优先，用户拍板），但类型由知识点决定——禁止把"分区图"机械套到 epoll/粘包上。

### 2.2 四件套（保留，v2.1 加两条定位规则）

| 件 | 内容 | v2.1 定位规则 |
|---|---|---|
| 一张图 | 按 2.1 选型 | 结构信息量 > 文字；精简文字不精简结构 |
| 一张表 | 维度对比（一行=一个 L2 追问骨架） | **表的字段=该点的完整判断框架**（内存分区=位置/存储期/管理者） |
| 主轴句 | 一句话锚 | **定位声明（新增）**：主轴句=覆盖最高频追问的主线锚，**不是该点的完整理论**；完整框架由维度表承担。内存分区主轴句升级为双句版：「**一个对象三个问题——放在哪、活多久、谁管；堆与栈的答案就是「谁分配谁回收」**」（前半=总框架，后半=可背锚尾；"谁分配谁回收"降为堆/栈子轴，不再独扛全点） |
| 机制演示 | mini-demo | **双规则（新增，替代"宁多勿少"）**：教学环节只对"无直观必卡"的核心机制**预置一个** demo；重教环节**按卡点诊断触发**（§五诊断表），不为完成演示而演示 |

**教学两条纪律**（保留）：收口声明"图外还有"；新增——教学时显式区分"典型模型/严格保证/常见实现"三类表述（哪些结论只是"通常情况"要当场说）。

## 三、迁移考察（v2.1：必答三问 + 扩展池）

| 必答 | 目的 | 形态 |
|---|---|---|
| Q1 核心问 | 是否建立最小模型 | 原题级直问 |
| Q2 机制问 | 因果链是否闭合 | 真题源追问 |
| Q3 变式问 | 能否迁移而非背诵 | **反向变式/新情境/教学中未出现过的新代码** |

**扩展池**（按目标层与知识类型选配，不凑数）：代码题/反例题/工程取舍题/边界题/项目挂接题/L4 实现题。
轻点（大小端）三问即收；重点（内存分区/epoll）加选 2-3 个。

**收口声明（新增，必说）**："下面的考察不会重复刚才原样讲过的句子，重点检查你能否把模型迁移到新代码和新条件。"
迁移题素材（试点首例，外部审查贡献）：`void f(void){ static int a; const int b=10; char *p=malloc(32); }`——问 a/b/p/p 指向的对象各从哪些角度判断？哪些只是"通常情况"？（收进 A1 卡1 变式池）

## 四、证据复盘（v2.1：双坐标 + 纠错四型）

### 4.1 判层先行 → **双坐标报告（新增）**

- **深度坐标**：L1-L4（15 号图）；
- **质量坐标**（=07 五维判卷尺的浓缩）：事实（准确/部分/错）｜因果（闭合/断点）｜边界（主动/追问补出/未知）｜表达（安全/措辞险）｜独立（自产/轻提示/强提示）。

报告格式："达 L2 · 质量三绿两黄（事实✓因果✓独立✓，边界待追问、表达一处措辞险）"——**深度与质量分开报，"讲得深"不等于"答得对"**。

### 4.2 纠错四型（v2.0 三型 + 第四型）

| 型 | 特征 | 处置 |
|---|---|---|
| 概念错误 | 说错事实 | 替换句+立即复述 |
| 归因偏差 | 结论对 why 错 | 反事实检验戳破 |
| 措辞险 | 用词引向错误追问 | 换词+面试安全版 |
| **层次/边界混淆**（新增） | 把语言语义当 ELF 节/把虚拟布局当物理/把通常当必然/把简化模型当 ABI 保证 | 四步：指出混淆的两层→分层各给结论→给限定词（"通常/在该层"）→一个反例验证。典型例："局部变量在栈上"（运行时典型模型）≠"局部变量有自动存储期"（语言语义）——优化后可在寄存器甚至被消除 |

### 4.3 自报缺口固定化（保留）

判卷后必问："哪些知道没说、哪些真不知道？"

### 4.4 收口复述（保留）

判据不变=**自产闭合**（结论+原因+一个边界或反例，独立说出）。

## 五、重教三板斧 → 卡点诊断表（v2.1：先诊断后选斧）

| 学生卡点 | 优先手段 | 试点对应 |
|---|---|---|
| 生活直觉不够 | 换比喻 | 记账 vs 物理清理 |
| 前后状态不清 | 快照图/时序图 | 三时刻栈快照 |
| 变量/指针变化不清 | 最小代码逐步走 | （新增手段） |
| 语言层与机器层混淆 | 双视角并排 | 作用域语义 vs 固定槽复写 |
| 只会背结论 | 反例/反向变式 | （新增手段） |

停止条件：学生能独立说出"结论+原因+一个边界或反例"。按需启用，不固定顺序。

## 六、分级落册（v2.1：轻量/完整两档 + 预付三态）

**两档规则**（02 册格式不变，只定适用范围）：

| 档 | 适用 | 内容 |
|---|---|---|
| 轻量（默认） | 普通知识点/首次接触 | 状态+一个关键错误+一个替换句+一个下次变式（=02 册现有一行制） |
| 完整 | 高频重点/连续答错/项目强绑定/发生申诉/需跨卡迁移 | 加：多轮重教记录/跨卡预付/复测日期/原始回答 |

**跨卡预付三态**（防"听过"误记成"掌握"）：

| 状态 | 含义 |
|---|---|
| 未涉及 | 未接触 |
| **已预付待验证** | 在其他卡中听过/局部复述过（≠通过） |
| 独立通过 | 本卡场景独立考察通过 |

（14 号栈帧卡现有注记即"已预付待验证"态——v2.1 起按此三态记。）
