## 一、两种场,分开用

| 场 | 口令 | 谁来做 | 场内做什么 |
| --- | --- | --- | --- |
| 验收场(每天的主模式) | `验收飞书:点1、点2、点3` | tutor | 考刚学的 3–5 个点,每点走「考察→教学→复盘」三段(第一轮整体准备期);复测巩固期回到只考不教 |
| 模拟面试(隔一批才做) | `拷打通用八股〈主题〉` | 冷面面试官 | 不讲、不提示;只打已经验收过的点,外加 2 道没学过的探针 |

验收场不报项目主线进度,不推进 Phase 3。模拟面试的冷面规则仍以 `.claude/agents/nvr-interviewer.md` 第五靶子为准;挂了的题不在那场里讲完就算会,回到下一场验收场按错题规则处理。

判卷基准不变:机制 + 权威源(man7 / APUE / TLPI / RFC / C 与 C++ 标准)。飞书不是标准。飞书和机制冲突时按机制判,错句记入错题册的「替换句」,并请你在飞书该段旁边改掉。

## 二、学到什么深度

一个点「学完」的标准是能脱稿说出三句:

1. 结论是什么。
2. 为什么是这样(一条因果,不是把飞书小标题再念一遍)。
3. 一条边界,或一个常见错法。

三句已经站住,验收时再加 **一个** 变式(换一个条件,判断结论还成不成立)。变式接住就停,不下钻第三层。飞书写得再细,验收也不按书的深度往下追。

深度封顶的样子(TIME_WAIT):

- 结论:主动关闭的一方发完最后一个 ACK 后进入 TIME_WAIT,等待 2MSL。
- 为什么:最后这个 ACK 可能丢失,对方会重发 FIN;同时让旧连接的迟到报文在网上过期,避免被新连接收走。
- 边界:大量短连接会占满主动关闭方的端口。
- 变式只问一句:最后的 ACK 丢了会怎样。不要求背出 TCP 全部状态。

来的时候只报知识点名字,不要把笔记贴进对话。预习要求分两期:第一轮整体准备期不强制先讲出三句——**考察永远先行当诊断**,教多教少由考察结果决定,预习过来考察段更省时;复测巩固期恢复「先在飞书自己讲出三句再来」,验收不当第一遍阅读。

各优先级的深度:

| 优先级 | 飞书学到 | 验收问到 |
| --- | --- | --- |
| P0 | 三句,并准备一个变式 | 三句 + 一个变式 |
| P1 | 结论 + 一个 why | 只问这两句;不过再补边界 |
| P2 | 不学 | 不问。被问到只说「知道有这个机制,项目里没用到」 |
| 送分 | 不排进学习队列 | 用通用词讲一遍;讲错才纠正 |

**底层一句(10-10 校准新增,可选层不加量)**:2025 届面经问法在从「是什么」往「底层怎么实现」升级(epoll 内核实现、malloc 底层、coredump 底层、mmap 自己怎么实现,92 份外部池里 ≈10 份)。P0 每点在变式之外**可自愿**备一句「底层用什么结构实现」——epoll=红黑树存注册 fd+就绪链表;malloc=小块走堆顶 brk、大块走 mmap;页表=多级映射;CFS=按 vruntime 排的红黑树。验收场只在三句+变式都过之后顺口带一句,答不出不算挂、不进错题册;深度到此为止,不展开源码(源码级仍在 P2)。

## 三、一场验收怎么进行

一批 **3–5 个点**;第一轮整体准备期走三段式,约 **40–60 分钟**(复测巩固期纯验收 25–40 分钟)。

| 步 | 做什么 | 到哪停 |
| --- | --- | --- |
| 0 | 开场先复测错题,最多 3 道,约 10 分钟 | 用变式问,不答原题 |
| 1 | **考察**:用校招原题问这个点,不照飞书标题念 | 听三句;单点约 5–8 分钟 |
| 2 | 三句齐 | 换一个条件问一次,能判对错就停 |
| 3 | 三句有洞 → **教学**:当场把缺的那句讲到因果成立,不整点重讲 | 学生复述正确版,记入错题册替换句 |
| 4 | 结论说不出 → **教学**:直接讲三句核心版 | 学生复述,标不过进待复测 |
| 5 | **复盘**:每点收尾给标准三句卡;场末交一张复盘表 | 每点一行:知识点/档/缺哪句/标准三句/下次动作 |

待复测超过 12 条,或同一条已经两次留在待复测里:这场不学新点,只把这些条讲到三句能复述。

收场交付一张表,每点一行:知识点、档(过 / 条件过 / 不过)、缺的是哪一句、下次动作。不过和条件过写入 `02_错题与战绩册.md`(文件不存在则本场创建);全部点的状态与场次记录同步回写 `06_复习进度总表.md`。

判分:

| 档 | 含义 | 下次 |
| --- | --- | --- |
| 过 | 三句都在,变式也接住 | 至少隔 3 天再抽一次;此前不再打开飞书这一节 |
| 条件过 | 结论对,why 或边界缺一处 | 下一场只补那一句 |
| 不过 | 概念错,或结论说不出 | 回飞书看这一节,下一场用变式重问 |

学生可以自愿接一句项目实例(例如大小端接到 `htons`)。先把通用三句说完。验收场不顺着项目往下追。项目实例如果说错,场后按源码改替换句。三档挂接仍然有效:

- 允许滑入:大小端 → `htons`;粘包 → Content-Length 定帧;锁 → 锁内盘 I/O。
- 禁止挂错:这个网关不是 epoll(一连接一线程);帧缓存是单槽覆盖,不是生产者-消费者队列;IPC 在项目里没有实例,不要编。
- 送分快过:V4L2 的 open/ioctl/mmap/DQBUF、socket 调用顺序。不排进学习队列。

## 四、哪些是重点、按什么顺序学

母集是下面的 P0,大约 30 个机制(10-10 校准后,原 26 点)。目录清单(`01_目录清单_已上传部分.md`)里其余题不挡「这一批通过」。飞书哪一章厚,也不改这个顺序。

一批 = 一次飞书阅读 + 一次验收。P0 大约 8 次验收;加上错题复测,一天一段,大约两到三周形成一面底。邀约如果马上就来,只保批次 1–4(网络三批+锁批,恰是面经频率最高的两段)。

| 批次 | 学这些 | 飞书大致位置 | 深度 |
| --- | --- | --- | --- |
| 1 | 三次握手为什么是三次;四次挥手为什么是四次;TIME_WAIT 和 2MSL;CLOSE_WAIT 是本端没关闭 | 网络 4.1 握手;4.3 连接状态与挥手 | 三句 + 一个变式 |
| 2 | 粘包/拆包和定帧;TCP 与 UDP 怎么选;MTU 与 MSS;TCP 头只留序号、确认号、窗口、标志位。变式串联:串口数据没有 Content-Length,靠什么定帧(帧头+长度字段+超时)——比亚迪/全志一面原问法 | 4.3 粘包、头部、MTU/MSS | 同上 |
| 3 | **select/poll/epoll 区别(带 LT/ET 一句);非阻塞和 `EAGAIN`。必带一句:这个网关是一连接一线程、不是 epoll,为什么这个规模下够用**(10-10 校准新增:外部池 ≈14 份+海康一面实考,原 P1 升 P0) | 网络 IO 多路复用 | 同上 |
| 4 | 进程和线程;互斥锁保护什么、死锁四个条件;条件变量为什么用 while;volatile 不是锁;**优先级反转一句(优先级继承/天花板)**(校准新增:≈10 份,海康一面实考) | OS 3.3 进程线程;3.6 锁 | 同上 |
| 5 | 内存分区;对齐的原因;栈和堆的生命周期;static 的三种用法、const、const 指针的两种读法;**虚拟内存为什么存在、缺页是什么**(校准新增:≈12 份,白名单内 ≈7) | C/C++ 章首 + 2.3 内存 | 同上 |
| 6 | 大小端;sizeof 和 strlen;strcpy/strncpy 的危险;野指针和悬空指针 | 章首区别类 | 同上 |
| 7 | 僵尸和孤儿谁来回收;fork 拷贝了什么;IPC 只留管道、本地套接字、共享内存各一句;信号只留异步安全一句 | 3.3 IPC;3.6 僵尸 | 同上 |
| 8 | UART、SPI、I²C:线数、谁是主、能不能挂多个、谁先开口;485 半双工一句。安防应用岗对照表够用;原厂/车企会追时序排错(SPI Mode 配错什么现象、I²C 仲裁),备 2–3 条变式即可 | 嵌入式 6.4 | 一张对照表;不背时序的每一位 |

手撕从第 3 批开始并行,每周 2 题、大约 20 分钟,单独写,不塞进同一场口试。顺序:安全版字符串拷贝 → `memcpy`/`memmove` 的重叠 → 链表反转 → 判断大小端 → 链表判环(接反转,同域) → 循环队列入队(宇视手撕原题;带一句「网关帧缓存是单槽覆盖,为什么不用环形队列」) → 二进制 1 的个数(位操作族) → TopK/最小堆(说清结构和插入删除复杂度即可) → 栈实现队列(两个栈,理想/ST-07 原题) → 生产者消费者模型(纸面版;必带边界句「通用模型会背,但本项目 frame_grabber 是单槽覆盖,不是队列」)。校招口径手撕出现率 26%(34/132),仍是标配环节但未过 50% 加量线,维持每周 2 题。

P0 都验收过一轮之后才开 P1。P1 每点只学「结论 + 一个 why」(点级优先级与 P1 清单在 `06_复习进度总表.md` 维护;05 面经每 +10 份增量重排)。10-10 校准:select/epoll、非阻塞 EAGAIN、优先级反转、虚拟内存/缺页四项已升 P0,见批次表;P1 重排为下列 10 点:

- 内碎片和外碎片。
- 用户态和内核态。
- HTTP 报文怎么分请求行、头、体;`mmap` 的通用含义。
- Linux 启动一条链:BootROM→uboot→kernel→rootfs→应用,每段一句(校准升档:白名单内全志×2、理想、中兴微都问;u-boot 两阶段细节仍在 P2)。
- FreeRTOS 概念:任务状态、队列 vs 信号量、中断里为什么不能阻塞;RTOS vs Linux 怎么选(恒玄/乐鑫/中兴微固件岗考;只要概念,不需要项目)。
- 环形缓冲区为什么嵌入式爱用:定长、免动态分配、覆盖旧数据;单写单读可做到无锁(与手撕第 6 题联动)。
- 排查工具链对照:gdb 条件断点 / coredump+addr2line / valgrind / strace / top 各一句(面经考「排查思路」多于考工具,主力是项目故事,这张卡只兜底)。
- DMA 与 Cache 一致性一句:DMA 和 CPU 各改各的缓存视图,谁访问谁负责失效/回刷(偏原厂/车企岗;项目无实例,不编)。
- 编译四阶段与静态/动态链接:预处理/编译/汇编/链接各做什么一句;静态链接体积大但装载即用、动态链接共享省内存但依赖运行环境(10-10 第二轮新增:校招池 ≈7 次,君正/小米/中兴/英伟达/深信服)。
- 岗位写了 C/C++ 再加:`new`/`malloc`、指针和引用;外加 C++ 浅层三句:虚函数表怎么找到函数、虚析构为什么、`extern "C"` 干什么(校准依据:安防系面经 6/10 考 C++,但问法停在这一层;容器/智能指针/模板仍在 P2)。

P2,现在不学:设备树、字符设备、pinctrl、u-boot 两阶段细节(一条链版已升 P1)、调度算法实现、epoll 红黑树的实现细节(一句版已入批 3)、多级页表、伙伴算法、ptmalloc、拥塞窗口全过程、半连接队列、HTTPS 证书链、Cookie/Session、C++ 面向对象 / 容器 / 智能指针 / 模板、中断保存现场的全过程。

## 五、复习

不过的点不靠重读整章飞书来记住。下次换一个条件再答,原题重答不算过。

| 状态 | 什么时候问 | 怎么问 | 过了去哪 |
| --- | --- | --- | --- |
| 待复测 | 下一场验收的前 10 分钟 | 换条件 | 进观察 |
| 观察 | 至少隔 3 天 | 再一个变式 | 已稳;以后只在模拟面试里碰到 |
| 已稳 | 不单独复习 | — | 飞书这一节不再打开 |

抽检顺序:先抽待复测里两次没出去的,再抽搁得最久的。一场最多 3 道。观察池没到期就不占这 3 个位子。

错因决定回不回飞书:

| 错因 | 回飞书吗 | 下次考什么 |
| --- | --- | --- |
| 概念错 | 只重看这一节 | 变式重问 |
| 只会结论,说不出 why | 不重读 | 只追问为什么 |
| 像在背笔记 | 不重读 | 换条件,当场推 |
| 飞书本身错了 | 在飞书边上改一句 | 「有人说 X,错在哪」 |

错题册每条一行,字段固定:

| 字段 | 写什么 |
| --- | --- |
| 编号 / 知识点 | 如「TCP 挥手-TIME_WAIT」 |
| 日期 | 本次验收日期 |
| 档 | 过 / 条件过 / 不过 |
| 错因 | 概念错 / 只会结论 / 背书腔 / 飞书说错 |
| 缺的那一句 | 结论、why、边界三者中的哪一句 |
| 替换句 | 一句能复述的正确口条 |
| 状态 | 待复测 / 观察 / 已稳 |
| 下次日期 | 下一场,或观察到期的日期 |

同一条两次仍是待复测:停止加新点,下一场只处理这几条。待复测总数超过 12:同样停止加新点。

## 六、模拟面试和临面

模拟面试不进每天的循环。P0 **每过完两批**,加一场 20–30 分钟:只打已经验收过的点,再加 2 道本域没学过的探针,用来发现漏网。冷面,当场不讲。报告写入 `面试备战/模拟面试/`,挂题回写错题册,状态为待复测。

有面试邀约时不打开新章节。把待复测、已到期的观察,加上批次 1–4 里仍是条件过的点,过一遍。

一面能去的线(三件同时满足):

1. 批次 1–8 都至少验收过一轮。
2. 待复测不超过 5 条。
3. 至少做过 1 场混合模拟,且没有整批概念错。
