# 项目速讲轨道说明(2026-09-07 建轨)

> 本文件是速讲轨道(`nvr-quick-tour`)的**基线文档**:目标、顺序、知识存量、能力边界、规则一次性写清。速讲教练开场先读本文件;学生随时可查。主线学习文档(progress.md/掌握档案)不因本轨道改变。

## 1. 决策背景与目标

秋招临近,投递优先。主线打磨模式(逐函数精读+证据验收)时间成本高,暂停;先用**快速轨道**在约 3–4 小时内达到「**能把项目讲明白**」:

- 这是什么项目、为什么分端/边/云三层;
- 边侧 11 个模块各自做什么、相互关系是什么(数据怎么流);
- 「我做了什么」怎么讲(部署实测/逐行梳理/注释工程化/问题清单);
- 亮点怎么讲、短板怎么坦诚说。

**非目标**:不替代主线深挖;不产生掌握证据;不教未学模块的实现细节(那是主线 Phase 2/3 的活)。

## 2. 双轨模式对比

| 维度 | 主线打磨(nvr-tutor,暂停中) | 速讲(nvr-quick-tour,进行中) |
| --- | --- | --- |
| 目标产物 | 理解——扛住追问链钻到底 | 表达——把项目当故事讲清楚 |
| 检验方式 | 闭卷、变式、换情境抽查 | 讲出来(每主题口述一遍) |
| 提问方式 | 苏格拉底优先 | 直接系统讲解 |
| 深度上限 | 不设(所有权/线程上下文/失败矩阵) | 封顶「职责+输入输出+数据流位置+选型 why 一层」 |
| 产出落点 | 掌握证据、八股卡、L3 判定 | 本目录(讲稿/架构图/应答卡) |
| 时间量级 | 每卡 70–100min | 每主题 20–40min,共 4–6 次 |

两轨不折算:速讲复述不算主线掌握证据;主线验收标准不因速讲降级。

## 3. 学习顺序(2026-09-07 确认)

1. **速讲轨道过全项目**(口令「快速过项目」):未学模块建认知层 + 已学存量转口述素材;
2. 速讲收尾跑一场「**拷打简历**」专项,把预测断点换成实测断点;
3. **开始投递**;
4. 投递期间主线恢复完整模式(口令「**继续 2.3A**」,从已发的 L1 三问待答接起)→ 2.3B → 2.4 → 2.5 → Phase 3;③④交错推进,速讲与主线进场尽量无间隔(防概览衰减)。

## 5. 速讲 agent 的方式与内容(2026-09-07 审查后定稿)

**审查记录**:建轨当日按四条需求(项目说明/模块关系/快速/不动主线)审查,补强三处——①显式继承主线铁律 1「先数据流后模块再关系」;②课程 2 标注增量重心=未学模块;③固化「能力边界与预期」小节(见第 6 节)。

**方式**:直接系统讲解,每主题(20–40min)讲完由学生口述一遍、卡壳当场补;深度封顶;事实纪律不变(源码为准、行号锚点、归属诚实);学生想深钻实现 → 指回主线任务卡。

**交付五件**:①30 秒电梯版+2 分钟完整版口述;②白板架构图(三层+11 模块+4 链路);③「我做了什么」清单(简历五条扩成 2 分钟素材+问题清单代表条目);④高频追问应答卡约 10 条(一句结论+一句展开+事实锚点);⑤坦诚短板话术。

**课程序列**(可跳序):1 定位与三层架构 → 2 模块地图+4 链路(增量重心) → 3 我做了什么 → 4 追问应答卡 → 5 连贯讲演彩排(接拷打简历)。

## 6. 预期效果与断点(六层考察模型)

| 层 | 考什么 | 速讲完成后的状态 |
| --- | --- | --- |
| ① 项目介绍 | 30秒/2分钟讲清 | **稳过** |
| ② 链路走查 | A/B/C/D 数据怎么流 | **全图能走**;A/B/C 带细节,D 在流程级 |
| ③ 选型 why | 为什么这么设计 | **全图一层深度**;Phase 1 区域不限层 |
| ④ 追问下钻 | 机制级往死里问 | **分区域**:Phase 1+cloud_ai+协议概念扛得住;**web/conf/event_bus 落库/alarm 实现/rtsp 实现层,第二问就穿** |
| ⑤ 异常与缺陷 | X 坏了会怎样 | Phase 1 强;未学模块**只能讲「发现过什么问题」,不能推演新变体** |
| ⑥ 项目挂钩通用基础 | 多线程/网络/时基 | 多线程/锁/条件变量/时基**强**;**socket/TCP/HTTP(C3/C4)是洞** |

**换算市场水平**:稳在校招③档(深度剖析+能讲 why+发现缺陷),一面项目环节大概率过;穿点是二面/深挖面恰好盯 web 线或事件链实现的面试官。升④档要素=板端 D1–D6 实证+自己的改动。断点补强顺序=主线顺序,不另排。

## 7. 规则与风险

1. 速讲结论一律标「待验证」,主线学习遇到冲突以源码为准;
2. 未学模块对外话术按诚实定位(「梳理到职责层」),到追问边界不硬撑;
3. 投递季②③交错,主线被迫中断不丢位置(接续口令都在);
4. 板端 D1–D6 别让简历数字裸奔;
5. 到期复测继续暂缓累积,收尾统一处理。
