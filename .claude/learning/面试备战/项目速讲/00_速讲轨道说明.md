# 项目速讲轨道说明(2026-09-07 建轨,09-07 夜框架学习改轨)

> 本文件是速讲轨道(`nvr-quick-tour`)的**基线文档**:目标、顺序、知识存量、能力边界、规则一次性写清。速讲教练开场先读本文件;学生随时可查。主线学习文档(progress.md/掌握档案)不因本轨道改写;过码记录只落本目录 `过码台账.md`,主线恢复时只读、不把速讲复述写成掌握证据。

## 1. 决策背景与目标

秋招临近,投递优先。主线打磨(逐函数精读+证据验收)暂停。第 1 讲电梯版已收口。学生两轮反馈后,本轨道**当前主目标**改为:

> **按主线顺序,用函数功能级读法,把 2.3A 后续未学主脊梁先走通**——整体框架、模块功能、模块联系;不进错误矩阵、选型深挖、改动后果、生命周期细节。

具体就是:从 2.3A 半成品接起 → event_bus 函数功能层 → alarm(含订阅侧框架) → C 链路走查 → C3/C4 压缩 + web → conf → D 链路与 2.5 口径收口。表达课(我做了什么 / 应答卡 / 彩排 / 拷打简历)排在这条脊梁之后,从框架上长出来,不再和框架学习抢第一优先级。

**非目标**(仍成立,措辞已按深度契约收窄):
- 不替代主线 L2/L3,不产生掌握档案证据,不推进任务 ID;
- 不教错误分支全矩阵、选型深挖、改动后果推演、生命周期细节(那是口令「继续 2.3A」起的主线活);
- 不把 rtsp_server 实现层塞进「2.3A 后续」课表(概念层已有,实现层留回补池)。

第 1 讲「3–4 小时把项目讲明白」是**已完成的表达层产物**,不再当本轨道现行时间盒或现行主目标。

## 5. 速讲 agent 的方式与内容(2026-09-07 夜改轨)

**方式**:未学主脊梁模块走**三步制**(教练系统讲解 → 学生函数功能级过码 → 口述)。SQLite/C1/C2/第 1 讲已教内容不重讲。第 1–3 讲现成讲义仍直接用,但第 2 讲后半改为按下表脊梁推进,不按「五文件并列+rtsp 实现层」旧课表。

**三步制**(每个未学模块,铁律 1:先数据流后模块再关系):

1. **教练系统讲解(10–15min)**:链路位置与职责 → 框架结构(线程/主循环/所有权一句话)→ 主要函数地图(铁律 8 分级,叶子点名即过)→ 一层选型 why;每个函数结论带 `文件:行号`。
2. **学生函数功能级过码(25–60min)**:`.h` 全读;`.c` 主要函数**逐个扫函数体**,每个一句话「做什么/输入输出/主流程哪一步」;错误分支只标记出口类型**不展开矩阵**;叶子只看名字;web.c 的 serve_* 精读 4 个代表、其余建 URL→函数映射。
3. **学生口述(约 10min)**:职责+框架+主流程串函数;卡点入 `复述卡点清单.md`;过闸后写入 `过码台账.md`(已扫函数 / 能串的主流程 / 明确没碰的深挖点)。

**深度契约**:必握=模块功能/框架结构/主要函数作用/主流程串联/一层 why;留主线=错误分支全矩阵/选型深挖/改动后果推演/生命周期细节/变式闭卷。

**2.3A 接续铁律**:本模块是半成品。讲解从 `publish` 主流程起,stmt 五步/bind 存储类/C1 copy-then-release **一句带过、不重讲**。过码范围=`.h` + `publish`(c:110-180) + 查询家族骨架(`query_filtered`/`row_to_event`/`get`/`count`)。

**主线 L1 折算**(写进台账,tutor 口令「继续 2.3A」必须先读):
- 台账该模块「函数功能层过闸」= 主线 L1 观察级(阅读清单+能指认输入输出/主流程)免重做;
- **不**免 L2 失败路径、审计①快照 I/O 持锁深挖、闭卷/变式,不写掌握档案,不推进任务 ID;
- 2.3B 若台账标明订阅侧已并入 alarm 过闸,主线 2.3B 的 L1 压缩为核对订阅者名单,不重开 80min。

## 6. 预期效果与断点(六层考察模型)

## 7. 规则与风险

1. 速讲结论一律标「待验证」,主线学习遇到冲突以源码为准;
2. 未学模块对外话术按诚实定位(「梳理到函数功能层」),到追问边界不硬撑;
3. 投递季框架脊梁与主线深挖交错,主线被迫中断不丢位置(接续口令都在);**主线开场必读过码台账**,避免把已过闸的 L1 再布置一遍;
4. 板端 D1–D6 别让简历数字裸奔;
5. 到期复测继续暂缓累积,收尾统一处理;
6. **不写** progress.md / 学习掌握档案 / 八股卡片 / Phase 手册;唯一学习痕迹=`过码台账.md`+`复述卡点清单.md`。
