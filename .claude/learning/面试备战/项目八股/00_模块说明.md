## 一、这个模块是什么、为什么有它(定位与意义)

秋招面试里,面试官对八股基础内容的考察占比很大,而且大多是**直接提问**——问一个知识点,听你怎么答,不一定和项目交叉。本项目经过五行简历口述圈和此前的模块学习,已经持有大量八股知识,但它们散在七册八股卡片、五件盲区新知和各挂接卡里,**缺一个"按面试考察频次组织、面向口头表达"的集中层**。本模块补的就是这一层:把"已持有"转成"说得出",把"没碰过"补齐。

场景定义:**秋招面试中,面试官问到本项目所体现的八股基础内容时,直接、准确、有边界地口头作答。**

## 二、范围原则(三不收)

1. **只收本项目的八股**。判定句:把题目里的项目词去掉,这道题还完整成立吗?成立(如"三次握手过程")→ 归通用八股工作区(另行单独准备);不成立、答案必须落到本项目的实然或选型(如"为什么切段必须等关键帧")→ 归本区。
2. **不收 video2lcd 的八股**。第二个项目(主答 V4L2/解码显示)的八股在它自己的工作区准备。
3. **不重复项目深挖叙事**。简历行五层+防线、事故链、缺陷战绩属于"项目深挖卷",资产在 07/02/11/12 号文件,本模块不复制;两边通过卡内"项目挂接"互相指。

## 四、卡片格式

- **高频区全字段**:档位头 / ①知识点是什么 / ②面试官怎么问 / ③口述回答 / ④高频追问+接法 / ⑤项目实然锚点(自查用,答题不看)/ ⑥坑点一句 / ⑦状态行。
- **低频区瘦身版**:知识点一两句 + 口述两三句 + 追问一句。
- **☆材料版**:待补项(共 8 张)同样按模板生成,口述回答标「材料版」——先照卡补齐知识、练熟后转正式卡。

## 五、使用方法

1. 复习以**直问直答**为主:遮住③,看②的问法自己说,再对答案。
2. 按**追问链滚动**,不按序号背:④里指到的卡号互相串着过。
3. 说错的卡在状态行打点;连错两次进错题台账(沿用 M-xxx 机制)。
4. 口径纪律:答案以源码实然 + 权威源(man7/RFC/FFmpeg 文档)为准;锚点行号答题时不看、只作自查;满话红线见各卡⑥;估算数字必须带"估算"口径,不说成实测。
5. 取材关系:八股卡片 01-07 册(学习期积累)、盲区新知 01-05(外部学习核对版)、11/12 号包(按行训练包/事故专场)、07 拷打表(项目深挖卷)——本模块是它们的"面试表达层"收口,不替代。
