## 一、编号规则

| 规则 | 内容 |
|---|---|
| 池前缀 | **Z = 中厂池**（重点①，安防/原厂/相机/网设/通信/AI 消电/车载边界七线）；**G = 国企/家电池**（重点②）；**D = 大厂池**（非重点，邀约激活制） |
| 编号形态 | `Z-001`~`Z-099`、`G-001`~`G-005`、`D-001`~`D-042`，三位数字，池内全序 |
| 稳定性 | **新号一经分配永不变更、永不复用**；B3 批起尾部续号（Z-100 起 / G-006 起 / D-043 起） |
| 引用格式 | `Z-078（原 ST-13）`；跨池引用直接写新号 |
| 重复处理 | URL 确认重复 → 保留先入库一侧，后入侧编号**退役**并在 §六登记（如 B2-04 并入 Z-002）；题目疑似同场但 URL 不同 → 双方保留，标 ⚠ 挂 §七 |
| 排序规则 | 池内按业务线分节，节内按公司样本数降序、公司内按年份升序；**后续新增一律尾部续号，不插队**（分组靠"线"列维持，不重排） |
