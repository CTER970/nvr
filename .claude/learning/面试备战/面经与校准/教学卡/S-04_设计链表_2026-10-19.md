# S-04｜707. 设计链表（Design Linked List）

> **卡头**：S-04｜LC707｜F1 链表族｜P0｜Medium｜C++（C 风格）
> **实证**：海康 HS-022/078｜全志珠海 B2-28 三面"中间插一个数据"
> **定位**：dummy 哨兵+前驱遍历——把"头插/尾插/中间插/删"全部统一成"找到前驱、改两根指针"的一套 API。

---

## 一、题目解析

- **输入**：对 `MyLinkedList` 的操作序列——`get(index)`、`addAtHead`、`addAtTail`、`addAtIndex(index,val)`（index==length 为尾插，>length 不插，<0 视为 0 头插）、`deleteAtIndex`。节点数上限 1000，index 范围 [0, 1000]，值域 [0,1000]。
- **输出**：`get` 返回第 index 个节点值（非法返回 −1），其余操作**原地修改**链结构。
- **约束确认**（写码前 30 秒口述）：头插=普通插的特例吗？→是，用 dummy 统一；删头有特判吗？→dummy 前驱从(dummy,0)起步即消；index 边界？→每处都查。
- **一句话考什么**：能否用**哨兵统一八种边界**，把 CRUD 全部收敛到"前驱节点"一个概念上。

## 二、解题思路

单链表的一切修改都发生在"前驱→我→后继"三元组上——找到前驱就拥有一切。让 dummy 恒占第 −1 位：**头节点与普通节点再无区别**。核心是私有函数 `prevAt(index)`：从 dummy 走 index 步，返回目标的前驱；插入删改全部建立在它之上。

**指针现场示意**（`addAtIndex(2, 9)` 在 1→2→3 中间插）：

```
dummy → 1 → 2 → 3 → nullptr
        ↑_______
prevAt(2)：prev 从 dummy 起步走 2 步到节点 1（index 的前驱）

dummy → 1      2 → 3        node->next = prev->next（先接后）
        prev ↑ ↑ node        prev->next = node（再接前）
dummy → 1 → 9 → 2 → 3 ✓
```

**关键边界**：`prevAt` 中 `while (index-- > 0)` 循环体内必须查 `prev->next`——防止删空链/越界时对空解引用；`addAtIndex(n)` 走 n 步恰好停在尾节点（原尾是 index n−1 的前驱位置语义）。

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```cpp
class MyLinkedList {
    struct Node { int val; Node* next; Node(int v) : val(v), next(nullptr) {} };
    Node dummy{0};
    int size = 0;

    Node* prevAt(int index) {          // 返回第 index 节点的前驱
        Node* prev = &dummy;
        while (index-- > 0 && prev->next)
            prev = prev->next;
        return prev;
    }

public:
    int get(int index) {
        if (index < 0 || index >= size) return -1;
        Node* p = prevAt(index)->next;
        return p ? p->val : -1;
    }

    void addAtHead(int val) { addAtIndex(0, val); }
    void addAtTail(int val) { addAtIndex(size, val); }

    void addAtIndex(int index, int val) {
        if (index > size) return;
        if (index < 0) index = 0;
        Node* prev = prevAt(index);
        Node* node = new Node(val);
        node->next = prev->next;
        prev->next = node;
        ++size;
    }

    void deleteAtIndex(int index) {
        if (index < 0 || index >= size) return;
        Node* prev = prevAt(index);
        Node* victim = prev->next;
        prev->next = victim->next;
        delete victim;
        --size;
    }
};
```

### 3.2 教学讲解版（关键决策注释）

```cpp
// 决策①：成员 dummy 而非函数内局部——对象生命周期内哨兵要一直在，
// 每个操作都借它起步；栈成员自动构造/回收，无泄漏风险
Node dummy{0};
int size = 0;   // 决策②：显式维护长度，get/删的合法性 O(1) 判定，
                // 不靠走链试探——add/delete 处 ±1 维护不变量"size 恒等于真实节点数"

Node* prevAt(int index) {
    // 从 dummy（第 -1 位）起步走 index 步 = 前驱：
    // 头节点（index 0）的前驱是 dummy 本身——头特判在坐标系里就消失了
    Node* prev = &dummy;
    // 循环条件捎带 prev->next：index 超出链长时停在尾节点，
    // 循环内 prev=prev->next 永不对空解引用（next 只可能是遍历方向的安全值）
    while (index-- > 0 && prev->next)
        prev = prev->next;
    return prev;
}

void addAtIndex(int index, int val) {
    if (index > size) return;      // 先全量查边界再动结构——半途而废的插入
    if (index < 0) index = 0;      // 会留下半接的指针现场
    Node* prev = prevAt(index);
    Node* node = new Node(val);
    // 顺序纪律：node->next 先接后（此时 prev->next 是唯一记忆点），
    // 先改 prev->next 则后继地址永久丢失
    node->next = prev->next;
    prev->next = node;
    ++size;                        // 不变量"size=真实节点数"在改动后必须立刻恢复
}

void deleteAtIndex(int index) {
    if (index < 0 || index >= size) return;
    Node* prev = prevAt(index);
    Node* victim = prev->next;     // 先留影再摘链——摘完就找不到了
    prev->next = victim->next;     // 跨接：前驱直连后继，victim 出局
    delete victim;                 // 嵌入式视角：不 delete 就是内存泄漏，
    --size;                        // 面试官几乎必查这一行
}
```

## 四、代码解析

**四块结构**：

1. **状态块**：`dummy` 哨兵+`size` 计数。size 让所有边界判定 O(1) 且**先判后动**——任何修改前合法性已定，出错动作根本不发生。
2. **prevAt 块**（坐标系核心）：从 dummy 走 index 步恒得前驱；条件里捎带 `prev->next` 兜底越界（停在尾）。头节点的前驱是 dummy——头特判被坐标系吞掉。
3. **插入块**：`addAtHead/addAtTail` 只是 `addAtIndex(0/size)` 的别名——**一套代码三种入口**，改一处三处受益。双句顺序纪律：先接后再接前，反了丢后继。
4. **删除块**：留影→跨接→`delete`→`--size`。delete 不能省——嵌入式面试的内存纪律分。

**不变量视角**：每个公有函数返回时，"dummy 恒在第 −1 位、size 恒等于 dummy 后真实节点数、链以 nullptr 终"恒成立；prevAt 的循环不变量是"prev 走过的步数恒等于已消耗的 index 配额"。

## 五、复杂度

- **时间**：单次操作 O(n)（n=size）——`prevAt` 最多走 n 步；`get/add/delete` 都被它决定。`addAtHead` 表面 O(1)，实现里仍走 prevAt(0)=0 步，确实 O(1)，但这是坐标系的红利而非独立代码路径。最坏=平均（操作位置均匀与否只影响常数）。
- **空间 O(1)**（单次操作）
  - **口径说明**：指**辅助空间**——prev/node/victim 指针 O(1)；new 出的节点是**题目要求的数据空间**（设计题的"输出即本体"），不计入辅助；单链实现不存额外索引结构。
  - 升级口径：若换双链+尾指针，addAtTail/addAtHead 双 O(1)——追问时的加分延伸。
- **口述模板**："单次 O(n) 辅助空间 O(1)——一个哨兵、一个长度计数、至多一个 new 节点；new 的节点是数据本身不算辅助；要 O(1) 头尾插就得双链表+尾指针，我可以现场画。"
