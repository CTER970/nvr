# S-28｜滑动平均/窗口滤波（禁 malloc、避浮点）

> **卡头**：S-28｜嵌入式原创｜F5 特色族｜P1｜嵌入式进阶｜纯 C（原创轨）
> **实证**：大疆 HS-004/005/006 三场同题（ADC 采样去噪是嵌入式笔试/手撕的招牌题）
> **定位**：环形缓冲+游标是流式数据处理的通用骨架——滑动窗口、串口接收 FIFO、音频缓冲一脉相承；"减旧加新"增量法贯穿所有窗口统计量（均值/方差/最值单调队列）。

---

## 一、题目解析

- **输入**：ADC 逐个到来的采样值流（16 位无符号），每次来一个算一次窗口均值。
- **输出**：最近 W 个样本的算术平均（整数即可），供控制/显示使用。
- **约束确认**（写码前 30 秒口述）：能 malloc 吗？→禁（无 MMU/碎片风险）；能用 float 吗？→避（很多 MCU 无 FPU，软浮点又慢又费栈），改**定点移位**；窗口没填满时输出什么？→按已有样本数平均（启动期输出不失真）。
- **一句话考什么**：环形缓冲免移位 + 增量更新和免重算 + 定标移位替除法——三条嵌入式资源洁癖一起考。

## 二、解题思路

朴素法每来一个样本把窗口 W 个数全部重加一遍（O(W)/样本），且若用普通数组"整体左移"再 O(W) 搬数据。两个瓶颈一起消：**环形缓冲**让写入位置循环转圈，免搬移；**增量更新和**让"新均值=旧和−出局样本+进局样本"，每样本 O(1)。

```
W=8 环形缓冲（pos=下一个写入槽）：
        ┌───┬───┬───┬───┬───┬───┬───┬───┐
buf[]   │ 10│ 12│ 9 │ 11│ . │ . │ . │ . │
        └───┴───┴───┴───┴───┴───┴───┴───┘
          0   1   2   3   ↑ pos=4（已存 count=4 个）

新样本 x 到达：
  pos ──────────→ 写 buf[pos]=x；sum += x
  pos ──+1 mod W →（buf[pos]==x 即"槽 0"在下一轮成为出局者）
  若窗口已满：out=buf[pos]（写前先取），sum −= out
  mean = sum >> 3        /* W=8 → 除法变移位 */

不变量：窗口未满时 sum=已存样本之和，pos=count；
       已满后 sum≡buf[pos..pos+W-1]（绕圈）之和，pos 恒指最旧槽。
```

移位要求 W 为 2 的幂（W=8→`>>3`）；面试口述时主动点出"选 2 的幂窗口是为把除法折成移位"。

## 三、代码（两版）

### 3.1 面试清爽版（环形缓冲+游标+增量和）

```c
#define W_LOG2 3
#define W      (1 << W_LOG2)   /* 窗口=8，2 的幂 → 均值用移位 */

typedef struct {
    unsigned short buf[W];
    unsigned int   pos;      /* 下一写入槽；窗口满后恒指最旧样本 */
    unsigned int   count;    /* 已存样本数（≤W） */
    unsigned int   sum;      /* 当前窗口内样本之和（增量维护） */
} ma_filt_t;

unsigned int ma_push(ma_filt_t *f, unsigned short x)
{
    if (f->count == W) f->sum -= f->buf[f->pos];  /* 先减出局者 */
    f->buf[f->pos] = x;                           /* 再写入新样本 */
    f->sum += x;
    f->pos = (f->pos + 1) & (W - 1);              /* 环形回绕：2幂窗口 & 代替 % */
    if (f->count < W) f->count++;
    return f->sum >> W_LOG2;                      /* 均值=和右移（窗口满） */
}
/* 注：启动期未满时 sum>>LOG2 会偏小；严格按 count 平均见讲解版 */
```

### 3.2 教学讲解版（启动期精确+关键决策注释）

```c
unsigned int ma_push_exact(ma_filt_t *f, unsigned short x)
{
    /* 窗口已满：槽 pos 存的是最旧样本——这是"pos 先写后绕"留下的不变量，
       增量法的正确性完全押在它身上：必须先减旧值、再覆盖该槽 */
    if (f->count == W) {
        f->sum -= f->buf[f->pos];
    } else {
        /* 启动期 pos==count：槽内是未初始化数据，绝不能减（减了 sum 就脏）。
           未满分支的职责只是"记账"：count 追上去，pos 永远指向第一个空槽 */
    }

    f->buf[f->pos] = x;          /* 覆盖最旧槽 / 填下一个空槽，同一行代码 */
    f->sum += x;

    f->pos = (f->pos + 1) & (W - 1);   /* 环形回绕；2 的幂窗口才能用 & 代替 % */

    if (f->count < W) f->count++;

    /* 启动期按 count 平均（整数除法）：不做 0.5 舍入诡计，偏小 1 LSB 可接受；
       窗口满后 W 是 2 的幂，除法严格等于移位，无精度损失 */
    return (f->count == W) ? (f->sum >> W_LOG2) : (f->sum / f->count);
}
```

## 四、代码解析

**三块结构**：

1. **结构体块**：静态数组声明在结构体内，由调用方静态分配（`static ma_filt_t g_adc_ma;`）——禁 malloc 的正解是**编译期定容**，不是 VLA。
2. **更新块**：顺序纪律——**先减出局者→再覆盖槽→再加新值→最后推进 pos**。减旧必须在覆盖前（覆盖后旧值就丢了）；推进 pos 必须在最后（前面三步都依赖"pos 指向最旧/空槽"这一前提）。
3. **回绕块**：`(pos+1)&(W-1)` 仅当 W 为 2 的幂成立；若窗口非 2 幂（如 W=10）改 `% W`，且均值不能用移位，得保留除法或用倒数乘法。

**不变量视角**：每轮结束时，`sum` 恒等于"缓冲区内 count 个有效样本之和"，`pos` 恒指向"最旧样本（满时）或第一个空槽（未满时）"——两命题合起来保证下一次 push 的"减旧加新"减掉的恰是被覆盖的那个值。

## 五、复杂度

- **时间 O(1)/样本**：增量更新固定做一次减、一次加、一次回绕；扫描 n 个样本 O(n)。对照朴素重算 O(n·W)——W=256、1kHz 采样时从 25.6 万次加法/秒降到 3 千次，这是面试官想听的量化对比。
- **空间 O(W)**（口径：辅助空间）
  - **口径说明**：缓冲区 W 个槽是算法**必须的工作存储**，计入辅助空间（非"输出空间"——输出只是一个均值整数）；W 为编译期常量，嵌入式预算时直接折成"2 字节×W 的静态 RAM"。无递归栈；无输入复用问题（输入是流，无输入数组可复用）。
- **口述模板**："每样本 O(1)，增量和减旧加新；空间就是一个 2 的幂大小的静态环形缓冲，W 个短整型，RAM 开销编译期定死，禁 malloc、无浮点。"
