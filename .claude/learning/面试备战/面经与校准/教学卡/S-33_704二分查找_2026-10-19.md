# S-33｜704. 二分查找（Binary Search）

> **卡头**：S-33｜LC704｜F6 排序查找族｜P1 第五批｜Easy｜C++（C 风格）
> **实证**：MTK HS-132
> **定位**：闭区间 `while(l<=r)` 是一族二分的母版——口述左右界变式（LC34/35/69）时不变量口径不变，只换收缩与返回值。

---

## 一、题目解析

- **输入**：升序整型数组 `nums`（元素互不相同）+ 目标 `t`；规模 1~5e4，值域 ±1e4。
- **输出**：t 的下标；不存在返回 −1。要求 O(log n)。
- **约束确认**（写码前 30 秒口述）：区间开闭？→ 闭区间 [l, r]，r=n−1；空数组？→ 本题 n≥1，仍留 l>r 返回 −1 兜底；中点计算溢出？→ `l+(r-l)/2`，不用 `(l+r)/2`。
- **一句话考什么**：闭区间不变量 + 三分支收缩是否真正让区间缩小（死循环免疫）。

## 二、解题思路

先声明不变量：**t 若存在，必在 [l, r] 内**。每步取中点比较：命中返回；`arr[m]<t` 说明 t 只可能在中点右侧，弃左半（`l=m+1`）；反之弃右半（`r=m−1`）。区间每次至少缩小一半，l>r 时区间为空即不存在。

```
n=6, t=7                l   m   r
[1  3  5  7  9 11]      0   2   5   arr[2]=5 < 7 → l=3
        [7  9 11]       3   4   5   arr[4]=9 > 7 → r=3
        [7]             3   3   3   arr[3]=7 命中 → 返回 3 ✔
```

现场快照（第二轮收缩后）：`l=3, r=3`，区间剩一个元素——闭区间下 `l==r` 仍需进循环判定，这就是 `<=` 的由来。

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int l = 0, r = (int)nums.size() - 1;
        while (l <= r) {
            int m = l + (r - l) / 2;
            if (nums[m] == target) return m;
            if (nums[m] < target)  l = m + 1;
            else                   r = m - 1;
        }
        return -1;
    }
};
```

### 3.2 教学讲解版（关键决策注释）

```cpp
class Solution {
public:
    int search(vector<int>& nums, int target) {
        // r = n-1：本题求下标，空数组直接 l>r 不进循环返回 -1，无需特判
        int l = 0, r = (int)nums.size() - 1;
        // <= 而非 <：闭区间 [l,r] 在 l==r 时还剩一个元素未判定，
        // 用 < 会漏判（返回前还得补查 nums[l]，是常见翻车点）
        while (l <= r) {
            // 防溢出中点：l+r 在 int 下可能溢出；l+(r-l)/2 恒安全
            int m = l + (r - l) / 2;
            if (nums[m] == target) return m;
            // m 已判定 ≠ t，弃之：l=m+1 / r=m-1 必须跨过 m，
            // 若写 l=m / r=m，区间可能不缩 → 死循环（变式题高发坑）
            if (nums[m] < target)  l = m + 1;
            else                   r = m - 1;
        }
        // l>r：区间为空，不变量给出"t 不存在"
        return -1;
    }
};
```

## 四、代码解析

**三块结构**：

1. **初始化块**：`r=n-1` 定闭区间口径——之后所有边界行为都由这一个决定派生（`<=`、`m±1`、空判 `l>r`）。开闭选择就是二分的"先声明区间含义"。
2. **循环块**：三分支各自维护不变量——`m` 已判定不等，**必须跨过 m** 收缩（`m±1`），保证区间严格缩小；这是不死循环的充要条件。
3. **退出块**：`l>r` 区间空，"t 在 [l,r] 内"的否定即"t 不存在"。

**不变量视角**：每轮开始时，"t 若存在则下标在 [l,r] 内"恒成立；三个分支都只剔除**已证明不含 t** 的部分，故成立；退出时空区间给出结论。

## 五、复杂度

- **时间 O(log n)**：区间每轮至少减半（m 及一侧被整段丢弃），最坏=平均=O(log n)，与数据分布无关。
- **空间 O(1)**（口径：辅助空间）：l/r/m 三个标量；迭代实现无递归栈。
- **口径说明**：输入数组属输入空间不计入；无输出空间（返回下标标量）。
- **口述模板**："时间 O(log n)，区间每轮严格减半；辅助空间 O(1)，迭代无递归栈。我的口径是闭区间 [l,r]：`while(l<=r)`、收缩 `m±1`——左右界变式（第一个/最后一个等于 t）只改收缩和返回，不变量口径不变。"
