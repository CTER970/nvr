# S-45｜54. 螺旋矩阵 / 48. 旋转图像

> **卡头**：S-45｜LC54/48｜F8 数组与矩阵族｜P1｜Medium｜C++（C 风格）
> **实证**：定性（笔试向高频）
> **定位**：矩阵双姊妹题——螺旋打印考**四边界收缩**的循环不变量，旋转 90° 考"**先转置再逐行反转**"的分解巧思。

---

## 一、题目解析

- **LC54 输入/输出**：m×n 矩阵 → 顺时针螺旋顺序的元素列表。
- **LC48 输入/输出**：n×n 矩阵 → 原地顺时针旋转 90°（不允许辅助矩阵）。
- **约束确认**：非方阵（54）？→矩形也要处理；单行单列？→边界收缩后自然退化；48 要求原地？→是。
- **一句话考什么**：边界变量的**收缩纪律**（54）与几何变换分解（48）。

## 二、解题思路

**螺旋**：四变量 top/bottom/left/right 圈定未打印区。每圈四段：上行左→右、右列上→下、下行右→左、左列下→上；每段打完收缩对应边界。**每段打印前判边界**（单行/单列时后两段不能重复走）。

**旋转 90° 分解**：`顺时针转 90° = 按主对角线转置 + 每行反转`。

```
转置（行列互换）:     行反转:
1 2 3              1 4 7              7 4 1
4 5 6      →        2 5 8      →       8 5 2
7 8 9              3 6 9              9 6 3
                  （ij 互换）        （每行左右翻）
```

为什么成立：元素 `(i,j)` 转置后到 `(j,i)`，行反转再把 `j → n-1-j`，合起来 `(i,j) → (j, n-1-i)`——正是顺时针 90° 的坐标映射。**一次交换+一次翻转都是原地操作**，无需辅助矩阵。

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
vector<int> spiralOrder(vector<vector<int>>& mat) {
    vector<int> out;
    int top = 0, bottom = mat.size() - 1;
    int left = 0, right = mat[0].size() - 1;
    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; j++) out.push_back(mat[top][j]);
        top++;
        for (int i = top; i <= bottom; i++) out.push_back(mat[i][right]);
        right--;
        if (top <= bottom) {
            for (int j = right; j >= left; j--) out.push_back(mat[bottom][j]);
            bottom--;
        }
        if (left <= right) {
            for (int i = bottom; i >= top; i--) out.push_back(mat[i][left]);
            left++;
        }
    }
    return out;
}

void rotate(vector<vector<int>>& m) {
    int n = m.size();
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            swap(m[i][j], m[j][i]);
    for (int i = 0; i < n; i++)
        for (int l = 0, r = n - 1; l < r; l++, r--)
            swap(m[i][l], m[i][r]);
}
```

### 3.2 教学讲解版

```cpp
vector<int> spiralOrder(vector<vector<int>>& mat) {
    vector<int> out;
    // 不变量：未打印区 = 子矩阵 [top..bottom] × [left..right]
    // 每圈四段各收缩一条边界，区被剥掉一"圈"
    int top = 0, bottom = mat.size() - 1;
    int left = 0, right = mat[0].size() - 1;

    while (top <= bottom && left <= right) {
        // 第一段（上行）无条件走——循环能进来至少还有一行
        for (int j = left; j <= right; j++) out.push_back(mat[top][j]);
        top++;

        // 第二段（右列）无条件走——收缩后至少还有一列
        for (int i = top; i <= bottom; i++) out.push_back(mat[i][right]);
        right--;

        // 第三/四段必须先验边界！
        // 剩一行的情形：top 已越过 bottom，再走"下行"会把同一行倒序重复打印
        if (top <= bottom) {
            for (int j = right; j >= left; j--) out.push_back(mat[bottom][j]);
            bottom--;
        }
        // 剩一列的情形同理：再走"左列"会重复同一列
        if (left <= right) {
            for (int i = bottom; i >= top; i--) out.push_back(mat[i][left]);
            left++;
        }
    }
    return out;
}

void rotate(vector<vector<int>>& m) {
    int n = m.size();
    // 转置：只扫上三角（j 从 i+1 起）——
    // 全扫会把每个元素换两次 = 没换（交换是对合）
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            swap(m[i][j], m[j][i]);

    // 每行反转：双指针首尾换，每行独立进行
    for (int i = 0; i < n; i++)
        for (int l = 0, r = n - 1; l < r; l++, r--)
            swap(m[i][l], m[i][r]);
}
```

## 四、代码解析

**螺旋的四段节奏**：走一段→收一边。核心纪律是**第三、四段的前置边界判断**——单行/单列残余时它们必须被跳过，否则重复打印（`3×3` 没问题、`3×1` 就翻车的经典 bug）。判断用的是**收缩后的** top/bottom（第一段刚收过），顺序即语义。

**旋转的两步分解**：转置只碰上三角（对角线元素原地不动、全扫=换两次白换）；行反转与 S-36 整串反转同手法。两步都是原地交换——**零辅助矩阵**的 O(1) 空间由此达成。

**追问预案**（对话层）：逆时针 90°？→转置+每列反转（或反转行序再转置）；180°？→整体双指针反转全部元素。

## 五、复杂度

- **时间**：螺旋 O(m·n)（每元素恰打印一次）；旋转 O(n²)（转置 n²/2 次交换+行反转 n²/2 次）。最坏=平均。
- **空间**
  - **螺旋 O(1) 辅助**——**口径说明**：返回列表是**输出空间**（结果本身），按口径不计辅助；四个边界变量是全部辅助。
  - **旋转 O(1)**：原地交换，无输出（改的就是输入）——比"新建矩阵逐位搬"的 O(n²) 辅助版高一档。
- **口述模板**："螺旋 O(mn)：四边界剥圈，第三四段必须验边界防单行重复；旋转 O(n²) 原地：先转置（只碰上三角）再每行反转——映射 (i,j)→(j,n-1-i) 的分解实现，零辅助矩阵。"
