# S-26｜环形缓冲区/循环队列（两法判满空 + SPSC 免锁）

> **卡头**：S-26｜嵌入式原创｜C2 位运算/C 基本功/嵌入式特色族｜P0 第三批｜进阶｜纯 C
> **实证**：华为 HS-010、宇视（循环队列入队原题）
> **定位**：count 法 vs 浪费一格法判满空、SPSC 单写者原则——NVR 帧搬运、日志、驱动的通用底盘。

---

## 一、题目解析

- **输入**：定长数组容量 N；offer 入队元素 / poll 出队；变体追问：不锁如何线程安全。
- **输出**：FIFO 队列；满 return false（宇视题面：入队要判满返回）。
- **约束确认**（写码前 30 秒口述）：判满用计数还是留空格？→两法都要会说；head/tail 谁动？→生产者只写 tail、消费者只写 head；索引回卷点？→`% N` 或 N 取 2 的幂时 `& (N-1)`。
- **一句话考什么**：环形=线性数组+索引回卷；满空区分是唯一算法难点；免锁靠"每个索引只有一个写者"。

## 二、解题思路

数组是直的，把 head（读位）与 tail（写位）两个索引**对 N 取模**即可首尾相接成环。难点：head==tail 既可能是空也可能是满——两种解法：①**count 法**：维护计数，`count==0` 空、`count==N` 满，判空 O(1) 直白、代价是每次操作多动一个变量（多核下 count 若被两端写就破坏免锁）；②**浪费一格法**：只写 tail 追 head——入队前看 `(tail+1)%N==head` 则满（故意留一格不装），`head==tail` 则空；省掉计数且 head/tail 各归一方，SPSC 免锁的自然形态。代价是可用容量 N−1。

```
浪费一格法（N=8，已装 3 个，■=数据）：

  idx:   0   1   2   3   4   5   6   7
        [ ] [ ] [H■] [■] [■T] [ ] [ ] [ ]
              ↑head(读位)     ↑tail(下一个写入位)

  满（7 个，tail 停在 head 前一格）：       SPSC 数据流：
  [T] [H■] [■] [■] [■] [■] [■] [■]        生产者 ──写 buf[tail]──┐
  (tail+1)%N==head → 满，留一格不装         只推进 tail            ▼
  空：head==tail（两者重合）                消费者 ←读 buf[head]── 环
                                           只推进 head
```

**SPSC 免锁原理**：tail 仅生产者写、head 仅消费者写，各 `volatile`；生产者序：**先写数据后推进 tail**，消费者序：**先读数据后推进 head**——另一端看到索引推进时，数据必然已就绪（配合内存屏障 `smp_wmb/rmb` 保证写序对外可见，单核 MCU 上 volatile 足够）。每索引单写者 = 无竞争，免锁成立。

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态，浪费一格法）

```c
#include <stdint.h>
#include <stdbool.h>

#define RING_SIZE 8u               /* 2 的幂，% 可换 & */
#define RING_MASK (RING_SIZE - 1u)

typedef struct {
    uint32_t buf[RING_SIZE];
    volatile uint32_t head;        /* 消费者唯一写者 */
    volatile uint32_t tail;        /* 生产者唯一写者 */
} ring_t;

bool ring_offer(ring_t *r, uint32_t v) {          /* 入队（判满） */
    uint32_t t = r->tail;
    if (((t + 1u) & RING_MASK) == r->head) return false;  /* 满 */
    r->buf[t] = v;
    r->tail = (t + 1u) & RING_MASK;
    return true;
}

bool ring_poll(ring_t *r, uint32_t *out) {        /* 出队（判空） */
    uint32_t h = r->head;
    if (h == r->tail) return false;               /* 空 */
    *out = r->buf[h];
    r->head = (h + 1u) & RING_MASK;
    return true;
}
```

### 3.2 教学讲解版（关键决策注释，含 count 法对照）

```c
/* count 法对照：加成员 volatile uint32_t count;
   offer: 满判 count==N；装数据；tail 前进；count++   ← count 被两端写！
   poll : 空判 count==0；取数据；head 前进；count--
   优点：判空判满直观、容量用满 N 格。
   缺点：count 是共享可写变量，SPSC 下属于"第二竞争点"，
         免锁属性被破坏——多核必须原子操作或回到浪费一格法 */

bool ring_offer(ring_t *r, uint32_t v) {
    uint32_t t = r->tail;             /* 先快照：满判与写入用同一 t，
                                         防判满后 tail 又被(自己)推进 */
    if (((t + 1u) & RING_MASK) == r->head)
        return false;                 /* 满判定=tail 前一格撞 head：
                                         故意留一格，满空判定从此分离 */
    r->buf[t] = v;                    /* 顺序纪律①：先写数据 */
    r->tail = (t + 1u) & RING_MASK;   /* 顺序纪律②：后发布索引——
                                         消费者看到新 tail 时数据必就绪 */
    return true;                      /* &(N-1) 回卷：N 为 2 的幂时
                                         等价 %N 且免除除法指令 */
}

bool ring_poll(ring_t *r, uint32_t *out) {
    uint32_t h = r->head;
    if (h == r->tail) return false;   /* 唯一"空"形态：两索引重合 */
    *out = r->buf[h];                 /* 先取数据（此刻生产者不可
                                         能覆写此格：它还空着 1 格余量）*/
    r->head = (h + 1u) & RING_MASK;   /* 后释放格子给生产者 */
    return true;
}
```

## 四、代码解析

**三块结构**：

1. **结构体块**：容量宏取 2 的幂——`& (N-1)` 替代 `% N`（S-20 母题直接落地）；head/tail 声明 volatile：MMIO/多核视角下索引读写不可缓存合并，每次都真访存。
2. **offer 块**（宇视考点：判满返回）：满判 `(tail+1)&mask==head` 先行，写满静默覆盖是实时系统经典事故；两步顺序纪律"数据先行、索引殿后"是发布语义，反了消费者会读到脏格。
3. **poll 块**：空判 `head==tail` 是唯一空形态（浪费一格换来的二义性消解）；先取数后推进 head，把格子还给生产者的动作放最后。**count 法对照**（3.2 头部注释）：容量用满 N 格、判满直观，但 count 双端写破坏 SPSC 单写者前提——两法互说优缺是面试标准追问。

**不变量视角**：任意时刻"已装数据 = 从 head 沿环走到 tail 前一格"，可用格 ≥ 1（满时恰留 1 格）；SPSC 不变量更强——head 只被消费者改、tail 只被生产者改，双方读对方索引永远是"已发布"的稳定值，故无锁。

**项目桥（NVR frame_grabber）**：单槽（grab→handoff 一个 mailbox）vs 环形（grab 连续生产、encoder 消费，互不阻塞）——采集端速率突发由环形吸收；单槽适合"只关心最新帧"的场景（V4L2 的 dqseq 思想）。

## 五、复杂度

- **时间 O(1)**：入队出队各常数步（判满/写/回卷 = 移位+与+访存）；无遍历无搬移，与数据量无关。`& mask` 版比 `% N` 少一次除法（嵌入式真金白银）。
- **空间 O(N)**
  - **口径说明**：指**数据结构自身**——数组 N 格为**存储空间**；浪费一格法**可用容量 N−1**（1 格为判满代价）；count 法容量 N 但多 4 字节计数；辅助量 head/tail O(1)。均无递归。
- **口述模板**："环形=定长数组+索引取模回卷；判满空两法：count 法直观但计数双端写，浪费一格法留一格分离满空、head/tail 各归一方——SPSC 免锁就靠每索引单写者加先数据后索引的发布序；单次操作 O(1)，空间 O(N) 可用 N−1。"
