# S-36｜344/151. 反转字符串 / 翻转字符串里的单词

> **卡头**：S-36｜LC344/151｜F7 字符串·算法族｜P1｜Easy/Medium｜C++（C 风格）
> **实证**：CVTE HS-014（单词翻转现场）、CVTE HS-045（整体翻转）
> **定位**：双指针首尾交换的基本功 + "两遍翻转法"的巧思（整体翻+逐词翻）——嵌入式按字节处理的典型场景。

---

## 一、题目解析

- **LC344 输入/输出**：字符数组 `s[]`，原地反转（O(1) 空间）。
- **LC151 输入/输出**：含前导/尾随/多余空格的句子，输出单词顺序反转、单词间单空格的串。
- **约束确认**：原地？→是（344 硬性）；151 允许 O(n) 辅助吗？→可以，但进阶要求原地。
- **一句话考什么**：首尾双指针交换 + **翻转的组合律**（整体翻+局部翻=词序翻转）。

## 二、解题思路

**整体反转**：left/right 双指针向中间走，逐对交换——`while (l < r)` 一轮收两格。

**单词级反转（151）两遍法**：
1. 先清理空格（双指针写入法：word 间只留一个空格，去首尾）；
2. 整串反转："hello world" → "dlrow olleh"；
3. 逐词再翻："dlrow"→"world"、"olleh"→"hello" → "world hello"。

```
"  hello   world  "
清空格 → "hello world"
整体翻 → "dlrow olleh"
逐词翻 → "world hello"     （词内字符序被两次翻转复原，词序被一次翻转颠倒）
```

两遍翻转的原理：翻转是**对合操作**（做两次回原状）——词内字符经历两次翻转恢复原样，而词与词的相对顺序只经历一次翻转被颠倒。

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
void reverseRange(vector<char>& s, int l, int r) {
    while (l < r) {
        char t = s[l];
        s[l++] = s[r];
        s[r--] = t;
    }
}

void reverseString(vector<char>& s) {
    reverseRange(s, 0, (int)s.size() - 1);
}

string reverseWords(string s) {
    int n = 0, i = 0, N = s.size();
    while (i < N) {
        while (i < N && s[i] == ' ') i++;
        if (i >= N) break;
        if (n) s[n++] = ' ';
        while (i < N && s[i] != ' ') s[n++] = s[i++];
    }
    s.resize(n);
    reverseRange(s, 0, n - 1);
    for (int l = 0, r = 0; r <= n; r++) {
        if (r == n || s[r] == ' ') {
            reverseRange(s, l, r - 1);
            l = r + 1;
        }
    }
    return s;
}
```

### 3.2 教学讲解版

```cpp
// 抽出区间反转作为原子操作：两处调用（整体翻/逐词翻）共用一份逻辑
void reverseRange(vector<char>& s, int l, int r) {
    while (l < r) {          // l==r（奇中点）自然跳过——中心字符无需动
        char t = s[l];
        s[l++] = s[r];       // 交换后各自向中心推进
        s[r--] = t;
    }
}

string reverseWords(string s) {
    // 阶段一：原地清理空格（快慢指针写入法）
    // n 是"已写区"游标：词首补一个空格（跳过首词），词内逐字符搬运
    int n = 0, i = 0, N = s.size();
    while (i < N) {
        while (i < N && s[i] == ' ') i++;       // 跳过连续空格
        if (i >= N) break;                       // 尾部空格清完
        if (n) s[n++] = ' ';                     // 非首词 → 词间单空格
        while (i < N && s[i] != ' ') s[n++] = s[i++];   // 搬运整词
    }
    s.resize(n);                                 // 截掉尾巴冗余

    // 阶段二：整体翻转（词序颠倒，词内字符暂时乱序）
    reverseRange(s, 0, n - 1);

    // 阶段三：逐词复原——扫描空格定词界，词内再翻一次恢复原拼法。
    // r==n 的哨兵条件让最后一个词（后面没有空格）也被处理
    for (int l = 0, r = 0; r <= n; r++) {
        if (r == n || s[r] == ' ') {
            reverseRange(s, l, r - 1);
            l = r + 1;
        }
    }
    return s;
}
```

## 四、代码解析

**三阶段结构**（151）：清空格 → 整体翻 → 逐词翻。

纪律两条：①清空格用**读写双指针**（n 写、i 读），读快写慢天然跳过多余空格——与数组去重同一手法；②逐词翻的边界由 `r == n || s[r] == ' '` 双条件定——**哨兵条件**处理末词，避免循环后补刀。

**不变量视角**（阶段一）：任意时刻 `s[0..n)` 是已清理文本且保持原词序——i 只前进不回退，信息只被压缩不被丢失。

## 五、复杂度

- **时间**：344 整体反转 O(n)（n/2 次交换）；151 三阶段各 O(n) 合计 **O(n)**，每字符至多被碰常数次。
- **空间 O(1)**
  - **口径说明**：三阶段全部**原地**——清理用原串前段、翻转用交换、resize 截尾；辅助空间仅常数下标。若用 stringstream/split 版本则 O(n) 辅助（口述对照）。
- **口述模板**："反转=双指针首尾交换 O(n)/O(1)；词序反转两遍法：清空格、整体翻、逐词翻——翻转做两次复原词内序，只留词序颠倒，全程原地。"
