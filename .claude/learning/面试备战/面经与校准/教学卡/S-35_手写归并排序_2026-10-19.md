# S-35｜手写归并排序（分治 + 合并）

> **卡头**：S-35｜嵌入式原创（LC912 数组版对应）｜F6 排序与查找族｜P1｜基础+｜C++（C 风格）
> **实证**：HS-054 汇总帖（含海康）
> **定位**：归并 = "分到原子再组装"——merge 步骤与 S-03 合并链表同源；**稳定排序**和 O(n) 辅助数组是两大口述点。

---

## 一、题目解析

- **输入**：整数数组 `nums` 及长度 n（值域任意）。
- **输出**：升序排序（原地呈现于 nums）。
- **约束确认**：要求稳定？→归并天然稳定（合并时相等取左）；时间下限？→比较排序 O(n log n)，归并能稳定达到；空间可 O(1) 吗？→标准归并不能（需 O(n) 辅助），这是与快排的取舍点。
- **一句话考什么**：**分治三段式**（分解/解决/合并）在数组上的标准落地。

## 二、解题思路

递归二分到单元素（天然有序），回程时逐层**合并两个有序段**。merge 借助辅助数组 tmp：双指针比较取小写入 tmp，拷回原位。

```
[5,2,3,1]
 分: [5,2]  [3,1]      →  再分: [5][2] [3][1]
 治+合: [2,5] [1,3]    →  合并: [1,2,3,5]

merge(a, l, m, r):  左段 a[l..m]  右段 a[m+1..r]
  i 从 l、j 从 m+1，取小者进 tmp，尾段整体拷入
```

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
void msort(vector<int>& a, vector<int>& tmp, int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    msort(a, tmp, l, m);
    msort(a, tmp, m + 1, r);

    int i = l, j = m + 1, k = l;
    while (i <= m && j <= r)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];
    while (i <= m) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (k = l; k <= r; k++) a[k] = tmp[k];
}
```

### 3.2 教学讲解版

```cpp
void msort(vector<int>& a, vector<int>& tmp, int l, int r) {
    // 递归出口：l >= r 即单元素（或空段）——分治的原子情况
    if (l >= r) return;

    // 中点：l + (r-l)/2 防溢出写法（(l+r)/2 在 int 上界附近会爆）
    int m = l + (r - l) / 2;

    // 先分后合：两条递归返回时，左右段各自已有序——
    // 这是本函数的【契约】，merge 依赖它才能成立
    msort(a, tmp, l, m);
    msort(a, tmp, m + 1, r);

    // 合并阶段：i/j 双游标比较取小。
    // <= 保证稳定性：相等时取左段元素，原序得以保留
    int i = l, j = m + 1, k = l;
    while (i <= m && j <= r)
        tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++];

    // 尾段整体拷入：另一段已耗尽，剩余部分本就有序，
    // 逐个比较纯属浪费——与链表合并的"余段整体接上"同构
    while (i <= m) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];

    // tmp 写回：merge 不能边比边写回 a（会踩掉未读的右段元素）——
    // 这正是 O(n) 辅助数组不可省的原因
    for (k = l; k <= r; k++) a[k] = tmp[k];
}
```

## 四、代码解析

**三块结构**：分（取中点）→ 治（双递归）→ 合（tmp 中转+写回）。

两条纪律：①merge **必须经 tmp 中转**——直接写回 a 会覆盖尚未读取的右段元素（对照：链表合并不需要 tmp，因为链表改指针不占位）；②`<=` 决定稳定性，写 `<` 就把相等元素逆序了。

**不变量视角**：任意层递归返回后 `a[l..r]` 有序且是原元素的排列——由原子情况与 merge 的保序性归纳成立。

**口述对比**（高频追问）：归并 vs 快排——时间：都是平均 O(n log n)，但归并最坏也是（快排已序退化 O(n²)）；空间：归并 O(n) 辅助 vs 快排 O(log n) 栈；稳定性：归并稳定快排不稳；链表场景归并全胜（S-08 已证）。

## 五、复杂度

- **时间 O(n log n)**：递归树 log n 层 × 每层合并总量 n；最坏=平均=最好（与输入分布无关，对比快排的硬优势）。
- **空间 O(n)**
  - **口径说明**：**辅助数组 tmp 占 O(n)**（一次性开满，全程复用不叠加）+ 递归栈 O(log n)（量级被 tmp 压住）。输入数组是原地写回，无独立输出空间。**O(n) 辅助是归并的固有代价**，面试要主动承认而非含糊。
- **口述模板**："归并 O(n log n) 三段式：分到单元素、回程合并取小；稳定（相等取左）；代价是 O(n) 辅助数组做中转——原地写回会踩掉右段未读元素。"
