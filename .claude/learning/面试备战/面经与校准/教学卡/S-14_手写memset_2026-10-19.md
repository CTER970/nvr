# S-14｜手写 memset（按字节语义）

> **卡头**：S-14｜嵌入式原创（无 LC 对应）｜F2 库函数手写族｜P1｜嵌入式基础｜纯 C（原创轨）
> **实证**：TCL（国企线样板题型："无标准库实现 memset/memcpy"，分池分析 §六）
> **定位**：一行循环的题 + 一个**语义陷阱**——`memset` 按字节填充，"用它把 int 数组初始化为 1"会得到 0x01010101，这个坑能讲出来就是加分。

---

## 一、题目解析

- **输入**：`void *s, int c, size_t n`（c 取**低 8 位**参与填充；n 字节）。
- **输出**：返回 s 原值；副作用为 n 字节每个都被填成 `(unsigned char)c`。
- **契约三问**：c 超过 255？→截断取低八位（如 0x101 只填 0x01）；能对 int 数组整体赋"任意值"吗？→**不能**（见陷阱）；返回什么？→s 原值。
- **一句话考什么**：**字节级语义意识**——memset 的世界没有"类型宽度"，只有字节。

## 二、解题思路

实现本身是库函数族最短的：逐字节赋值 n 次。考点全在**语义边界**：

```
int arr[3]; memset(arr, 1, sizeof(arr));
意图: arr = {1, 1, 1}
实际: 每个 int 的 4 个字节都是 0x01 →
      0x01010101 = 16843009  ← 不是 1！

小端机内存视图（每格一字节）:
arr[0]: [01][01][01][01]  →  值 0x01010101
memset(..., 0, ...) 之所以正确: 全零字节无论怎么组合都是 0
```

结论：memset 只适合填 0（或 -1，因 0xFF 补码恰为 -1）；任意值初始化用循环。

## 三、代码（两版）

### 3.1 面试清爽版

```c
#include <assert.h>

void *my_memset(void *s, int c, size_t n)
{
    assert(s);
    unsigned char *p = s;
    while (n--) *p++ = (unsigned char)c;
    return s;
}
```

### 3.2 教学讲解版

```c
void *my_memset(void *s, int c, size_t n)
{
    assert(s);

    // void* 无宽度，必须转字节指针逐个写。
    // (unsigned char)c 是契约的落地：int c 只取低 8 位，
    // 转换即"截断"，超过 255 的值被显式丢弃而非隐式溢出
    unsigned char *p = s;
    while (n--) *p++ = (unsigned char)c;

    // 返回 s 原值（p 已走到尾部）——链式风格与其他 mem 族一致
    return s;
}
```

## 四、代码解析

**单循环结构**：`while (n--)` 惯用法从尾往前数——n 为 0 时零次执行（契约：n=0 合法且无操作）。`(unsigned char)c` 的显式截断是文档级写法：告诉读者"我知道 c 是 int，且我只取它的低字节"。

**陷阱的原理讲解**（面试加分主体）：类型值 = 字节的**组合解释**（int=4 字节按端序拼装）；memset 只负责把每个字节写成同一值，**不参与解释**。填 0 之所以万无一失：全零字节在任何宽度/端序/符号解释下都是 0；填 -1 同理（0xFF…FF 补码）。"memset 任意非 0 值初始化数组"是 C 面试的经典错误答案，能主动拆穿=内存模型过关。

**高频追问**（对话层）：`memset(p, 0, sizeof(p))` 对 `int *p`？→只清了指针自身 8 字节，不是数组——sizeof(指针) 家族错误；对堆内存？→分配后 memset 代替 calloc？→语义等价但 calloc 可能有分配期清零优化。

**不变量视角**：`while (n--)` 每轮 n 减一、p 进一格，"剩余字节数"与"剩余区间"严格同步——循环退出时 n 恰为 0 且 p 落在目标尾后一格，无多写无漏写。

## 五、复杂度

- **时间 O(n)**：n 字节各写一次；最坏=平均。真实 glibc 按对齐走 word 级快路径（口述加分）。
- **空间 O(1)**
  - **口径说明**：辅助空间=一个字节指针；目标缓冲区属调用者空间。
- **口述模板**："O(n) 逐字节填 c 的低八位；辅助空间 O(1)。memset 只认字节不认类型——填 0/-1 安全，填 1 到 int 数组得到 0x01010101，任意值初始化要循环。"
