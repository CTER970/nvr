# S-37｜125. 验证回文串

> **卡头**：S-37｜LC125｜F7 字符串·算法族｜P1｜Easy｜C++（C 风格）
> **实证**：小米 HS-127（汇总帖）
> **定位**：成本极低的顺手题——首尾双指针 + 大小写/非字母数字归一化，5 分钟收卡型。

---

## 一、题目解析

- **输入**：字符串 `s`（含字母、数字、空格与标点）。
- **输出**：bool——只考虑字母和数字、忽略大小写后是否回文。
- **约束确认**：空串/过滤后为空？→true（视为回文）；数字参与比较吗？→参与（"0P" 不是回文，0≠p）；大小写？→归一后比较。
- **一句话考什么**：双指针 + 字符分类过滤（isalnum/tolower 的正确使用）。

## 二、解题思路

l 从头、r 从尾向中间推进；各自**跳过非字母数字字符**（"., " 全部无视），停在合法字符上比较小写形式——不等即 false；相遇/交错即 true。

```
"A man, a plan"
l→'A'          r→'n'   → 'a'=='n'? 继续: l 走到 'm'…（过滤掉 ", " 等）
每轮: 先各自 while 跳非法 → 再 tolower 比较 → 双推进
```

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        int l = 0, r = (int)s.size() - 1;
        while (l < r) {
            while (l < r && !isalnum((unsigned char)s[l])) l++;
            while (l < r && !isalnum((unsigned char)s[r])) r--;
            if (tolower((unsigned char)s[l]) != tolower((unsigned char)s[r]))
                return false;
            l++;
            r--;
        }
        return true;
    }
};
```

### 3.2 教学讲解版

```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        int l = 0, r = (int)s.size() - 1;

        while (l < r) {
            // 内层过滤循环必须带 l<r 卫兵：
            // 全标点串（".,."）过滤时 l 会一路冲过 r 形成越界读
            while (l < r && !isalnum((unsigned char)s[l])) l++;
            while (l < r && !isalnum((unsigned char)s[r])) r--;

            // tolower 前的 (unsigned char) 转换：ctype 家族防负索引 UB
            if (tolower((unsigned char)s[l]) != tolower((unsigned char)s[r]))
                return false;   // 首个不等对 → 立即判负（早退）
            l++;
            r--;                // 该对相等，双方向中心推进
        }
        return true;            // 指针相遇/交错：所有对都相等
    }
};
```

## 四、代码解析

**双层循环结构**：外层管"对"的推进，内层管单侧过滤——职责分离，各自简单。

两条纪律：①内层过滤的 `l < r` 卫兵不可省（全标点串越界的唯一防线）；②**先过滤后比较**的顺序——若先比较后过滤，标点会参与首对比较产生误判。

**不变量视角**：每轮外层开始时，`s[0..l)` 与 `(r..n-1]` 的合法字符已两两配对且相等——区间外的部分已被"证明回文"，收缩至空即整体回文。

## 五、复杂度

- **时间 O(n)**：l、r 各自单调推进，合计至多 n 次；每字符常数次分类调用。最坏=平均。
- **空间 O(1)**
  - **口径说明**：双指针原地，无辅助缓冲；对照版"先过滤拷贝到新串再反转比较"需 O(n) 辅助——双指针法胜。
- **口述模板**："首尾双指针 O(n)：各跳过非字母数字，tolower 后比较，不等早退；空间 O(1) 原地，比先拷贝再反转省一个数组。"
