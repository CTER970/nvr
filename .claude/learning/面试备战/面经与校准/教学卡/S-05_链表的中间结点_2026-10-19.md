# S-05｜876. 链表的中间结点（Middle of the Linked List）

> **卡头**：S-05｜LC876｜F1 链表族｜P1｜Easy｜C++（C 风格）
> **实证**：地平线 HS-016
> **定位**：快慢指针测距——S-02 判环、S-08 归并找中点共用的同一个动作原语。

---

## 一、题目解析

- **输入**：单链表头 `head`，节点数 1~100，值域 1~100（题目保证非空）。
- **输出**：中间节点——**偶数长度时返回第二个中间点**（`[1,2,3,4]` 返回 3 所在节点）；只读不改链。
- **约束确认**（写码前 30 秒口述）：链保证非空？→是（不然 slow 起步就是空）；偶数取哪个中点？→第二个，若面试官要第一个得换起步/判条件；只许一趟扫描吗？→快慢指针正合适。
- **一句话考什么**：快慢指针的**比例关系**（fast 行程恒为 slow 两倍）如何直接兑换成"中点"。

## 二、解题思路

fast 一次两步、slow 一步同发：任意时刻 fast 走了 slow 的两倍路程。fast 到终点时 slow 恰在**半程**——中点数学上免费到手，无需先量长度再走第二趟。

**指针现场示意**（`1→2→3→4→5` 与偶数 `1→2→3→4`）：

```
奇数 5 节点：
s →1→ 2 → 3 → 4 → 5 → ∅
f →1→→3→→5→∅      fast 落在最后节点后 next 为空？不——
第3轮: fast=5, fast->next=∅ → 停，slow=3 ✓正中

偶数 4 节点：
第2轮: fast=4, fast->next=∅ → 停，slow=3 ✓第二个中点
（若要第一个中点：需判 fast->next->next 提前一站刹车——变式考点）

节奏表：
轮次   slow   fast
 0      1      1
 1      2      3
 2      3      5（奇）/ 4（偶）→ 停表条件 fast->next==∅
```

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```cpp
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        return slow;
    }
};
```

### 3.2 教学讲解版（关键决策注释）

```cpp
class Solution {
public:
    ListNode* middleNode(ListNode* head) {
        // 同点起步：两者出发位置相同，比例关系 "fast=2×slow"
        // 从第 0 步就成立，无偏置需要修正
        ListNode* slow = head;
        ListNode* fast = head;
        // 两级条件缺一不可：
        //   奇数长度——fast 停在最后节点，fast->next==∅ 拦下；
        //   偶数长度——fast 跳过最后节点落在 ∅，fast==∅ 拦下。
        // 只查一级就会对空指针做 ->next 解引用
        while (fast && fast->next) {
            slow = slow->next;          // 每轮 +1
            fast = fast->next->next;    // 每轮 +2——行程比恒 1:2
        }
        // 出口即答案：fast 走 n 或 n-1 步（视奇偶），slow 恰走 ⌊n/2⌋ 步
        // ——正是第 ⌊n/2⌋+1 个节点，即单中点/第二个中点，无需后处理
        return slow;
    }
};
```

## 四、代码解析

**三块结构**：

1. **起步块**：slow/fast 同源于 head——比例不变量从第 0 步成立，免校准。
2. **行进块**：两步指针一次跳两格，前提是"跨过的节点存在"——这就是循环条件查两级（`fast` 与 `fast->next`）的原因：奇数链快者停尾、偶数链快者落空，两种终局各被一级条件接住。
3. **收尾块**：返回 slow 零后处理——出口状态与目标位置由 1:2 行程比直接锁定，这就是"一趟扫描"的结构性来源。

**不变量视角**：每轮结束后"fast 距 head 的步数恒等于 slow 的两倍"成立；循环终止时 fast 的行程是 n−1（奇）或 n（偶），slow 相应为 ⌊n/2⌋——恰为第二个中点的下标，正确性由比例式一行给出。

## 五、复杂度

- **时间 O(n)**：fast 先到终点，slow 只走一半；总步数 1.5n 量级，一趟完成。最坏=平均（与值无关，只依赖节点数与奇偶）。
- **空间 O(1)**
  - **口径说明**：指**辅助空间**——slow/fast 两个指针 O(1)；输入节点不计入；**只读不改链**，无输出空间、无递归栈。
  - 对照口径：先量长度再二趟走 n/2 步的朴素法同为 O(n)/O(1)，但要**两趟**——快慢指针的收益在扫描次数而非复杂度阶，这一点主动说破是加分项。
- **口述模板**："时间 O(n) 一趟扫描——fast 走两步 slow 走一步，fast 到尾时 slow 恰在中点；辅助空间 O(1) 就俩指针；朴素两趟法复杂度同阶但扫两遍，偶数取第二中点是本题默认口径。"
