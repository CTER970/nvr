# S-22｜SWAP 宏三版（临时/加减/异或）

> **卡头**：S-22｜嵌入式原创｜C2 位运算/C 基本功/嵌入式特色族｜P1 第三批｜基础+｜纯 C
> **实证**：CVTE HS-014、讯飞 HS-097（"安全 SWAP"）
> **定位**：同一功能三种实现的风险谱系——UB、别名自毁、类型截断，宏工程题的集大成。

---

## 一、题目解析

- **输入**：两个待交换的变量（经宏传入）；追问：三版各自的坑与推荐版。
- **输出**：可交换任意同型变量的 SWAP 宏 + 各版本风险口述。
- **约束确认**（写码前 30 秒口述）：宏还是函数？→宏（任意类型复用）；两变量同地址怎么办？→异或版自毁、加减版也可能 UB；加减版溢出允许吗？→有符号溢出是 UB，不能靠"回绕碰巧对"。
- **一句话考什么**：三版全写得出、坑全说得出、最后选得出——工程判断而非炫技。

## 二、解题思路

三版对照：①**临时变量版**：`t=a; a=b; b=t;`——零坑，唯一代价一个临时；②**加减版**：`a=a+b; b=a-b; a=a-b;`——第一步 `a+b` 有符号溢出即 UB（无符号回绕虽定义良好但依赖数学巧合，面试定性为"险"）；③**异或版**：S-19 的三连，无溢出但**同地址自毁**（`a^=a` 归零）。三版共有的宏层坑：参数副作用双求值、复杂实参需括号、浮点走加减版精度损失。

```
加减版（a=5, b=3）：
a = a+b = 8   ← 中间值 8：若 a,b 是 int 且原本很大，此处可能溢出（UB）
b = a-b = 5   （8-3=原a）
a = a-b = 3   （8-5=原b）

异或版同地址自毁：SWAP(x, x) 展开
x ^= x :  x = 0            ← 原值当场清零，信息全失
x ^= x :  0
x ^= x :  0               → 返回值"x"恒 0，救不回

安全版结构（讯飞 HS-097）：
do { __typeof__ 临时 + 别名判断 } while(0)
```

**`do{}while(0)` 的意义**：把多条语句包成**单条语句**——`if (cond) SWAP(a,b); else ...` 中裸多语句会让 else 悬空（编译错误），do-while(0) 吞掉分号语义，是内核宏的通用骨架。

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```c
/* 版本 1：临时变量（推荐） */
#define SWAP_T(a, b) do {  \
    (a) = (a) + (b) - ((b) = (a));  /* 单行技巧版，可读性差，慎用 */ \
} while (0)

/* 版本 2：加减版（有溢出风险） */
#define SWAP_A(a, b) do {  \
    (a) += (b); (b) = (a) - (b); (a) -= (b);  \
} while (0)

/* 版本 3：异或版（同地址自毁） */
#define SWAP_X(a, b) do {  \
    if (&(a) != &(b)) { (a) ^= (b); (b) ^= (a); (a) ^= (b); } \
} while (0)
```

### 3.2 教学讲解版（关键决策注释，推荐安全版）

```c
/* 推荐：临时变量 + typeof + do{}while(0) —— 三重防护
   ① do{}while(0)：多语句包成单语句，if-else/循环体内调用不炸；
   ② __typeof__ 声明与参数同型的临时：任意类型可用（含结构体），
      参数各出现一次（初始值与写入），无副作用双求值；
   ③ 无自毁问题：临时变量独立地址，&(a)==&(b) 也只是白换一轮 */
#define SWAP(a, b) do {                 \
    __typeof__(a) _t = (a);             /* 冻结原 a：单次求值 */  \
    (a) = (b);                          /* b 覆写 a */            \
    (b) = _t;                           /* 冻结值还给 b */         \
} while (0)
/* 加减版口述：a+=b 一步即可能 signed 溢出=UB，无符号虽回绕可救但
   依赖 (a+b)-b==a 的无符号巧合；浮点因舍入误差禁用。
   异或版口述：见 S-19 三连推导；仅整数可用、同地址自毁需判指针。
   结论：工程上永远临时变量版——零 UB、全类型、可优化性好。 */
```

## 四、代码解析

**三块结构**：

1. **SWAP_A 加减版**：代数正确性来自 `b=(a+b)-b=原a`、`a=(a+b)-原a=原b`；风险集中在第一行 `a+=b`——有符号溢出 UB，面试必须主动报出。技巧单行版 `(a)=(a)+(b)-((b)=(a))` 内含未指定求值顺序，属"聪明但危险"的反面教材。
2. **SWAP_X 异或版**：三步推导见 S-19；此处强调 `&(a)!=&(b)` 别名防御必须在最前——这是 CVTE/讯飞共同追杀点。仅适用于整数类型。
3. **SWAP 推荐版**：`do{}while(0)` 骨架 + `__typeof__` 临时 + 参数单次求值——把 S-21 的副作用教训直接落地；变量名 `_t` 有遮蔽风险，内核实践用 `__UNIQUE_NAME`（口述加分）。

**不变量视角**：三版共同不变量是"`_t`/叠加态中始终保有原 a 的信息"——临时版在第①行冻结、加减版在 `a+b` 里以和的形式保管、异或版在 `a^b` 里以异或形式保管；交换正确性 = 该信息在覆写发生前已被保管。

## 五、复杂度

- **时间 O(1)**：三版均为常数次读+写（临时版 3 次读写、加减版 3 次运算、异或版 3 次）；与类型大小相关时（结构体）为 O(sizeof)。
- **空间 O(1)**
  - **口径说明**：指**辅助空间**——临时版一个同型临时（O(sizeof(T))）；加减/异或版**零临时**（这正是它们被发明的原因，嵌入式极端栈场景口述点）；无递归。
- **口述模板**："三版都会写：加减版第一步就可能 UB；异或版同地址自毁要判指针；工程首选临时变量+do-while(0)+typeof——全是 O(1)，加减/异或省的是那一个临时变量，代价是两层坑。"
