# S-06｜160. 相交链表（Intersection of Two Linked Lists）

> **卡头**：S-06｜LC160｜F1 链表族｜P1｜Easy｜C++（C 风格）
> **实证**：地平线 HS-016（与"链表中点"同场连问）
> **定位**：双指针"换道走"技巧——用等长化消掉长度差，是"快慢指针家族"之外的另一支双指针。

---

## 一、题目解析

- **输入**：两条单链表头 `headA/headB`（节点数 0~10⁴），可能在某一节点汇合为同一条尾段（交叉后不再分叉）。
- **输出**：第一个相交节点指针；不相交返回 nullptr。
- **约束确认**：两链都可为空？→是；相交点可能是任一链的头？→是；不允许修改链表？→是；O(1) 空间？→要求。
- **一句话考什么**：**长度差对齐**思想——让两个指针走过相同的总路程后同步抵达交点。

## 二、解题思路

两条链若相交，则从交点起完全共用尾段；两指针若走过**相同的总长度**，就会在同一时刻到达交点。但两条链前段长度可能不同（长度差 d）。

消除长度差的优雅做法：指针 a 先走完 A 链再转到 B 链头继续；指针 b 先走完 B 链再转到 A 链头继续。两者走过的总长都是 `lenA + lenB`，且后半程进入了对方的"前段"——换道之后两指针剩余路程相同，必然同刻到达交点（或同刻到达 nullptr，即不相交）。

```
A: a1 → a2 ┐                 长度 2 + 公共段 3
            ├→ c1 → c2 → c3
B: b1 → b2 → b3 ┘            长度 3 + 公共段 3

指针a路程: a1 a2 c1 c2 c3 | b1 b2 b3 c1 ←  第8步两指针同在 c1
指针b路程: b1 b2 b3 c1 c2 c3 | a1 a2 c1 ←  第8步
```

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        ListNode *a = headA, *b = headB;
        while (a != b) {
            a = a ? a->next : headB;
            b = b ? b->next : headA;
        }
        return a;
    }
};
```

### 3.2 教学讲解版

```cpp
class Solution {
public:
    ListNode *getIntersectionNode(ListNode *headA, ListNode *headB) {
        // 双指针各自从本链头出发
        ListNode *a = headA, *b = headB;

        // 终止条件的统一性：相等时退出——可能是交点，也可能是共同走到 nullptr。
        // "同时为空"也触发 a == b，天然覆盖"不相交"情形，无需特判
        while (a != b) {
            // 换道走：走完自己的链后跳到对方头部。
            // 这样两指针总路程都是 lenA + lenB，
            // 消除了前段长度差——这是本算法的全部核心
            a = a ? a->next : headB;
            b = b ? b->next : headA;
        }
        return a;   // 交点或 nullptr
    }
};
```

## 四、代码解析

**单循环结构**：每轮各走一步；到尾（nullptr）就换到对方头。两条顺序纪律：①换道判断必须用 `a ? a->next : headB` 三目式——**走到 null 的那一刻就该换道，而不是再走一步**；②两指针必须对称处理（都换道），只换一个就破坏"总路程相等"的前提。

**不变量视角**：设 A 独有段长 x、B 独有段长 y、公共段长 z。指针 a 走 `x+z+y` 步后处于公共段起点（换道后走完 B 的独有段）；指针 b 同理走 `y+z+x` 步——路程相等，且此后同步。若两链不相交（z 段为空、尾不同），两指针最终同刻到达 nullptr，循环条件 `a != b` 破裂，返回 nullptr——相交与不相交被同一套逻辑覆盖，零特判。

对照版（口述级）：先各走一遍求长度差 d，长链指针先走 d 步再同步走——思想相同，换道版只是把它写得无特判。

## 五、复杂度

- **时间 O(m+n)**：两指针各走至多 m+n 步（换道后最多再走一整条链）；最坏=平均。
- **空间 O(1)**
  - **口径说明**：辅助空间=两个指针；哈希法对照版需 O(m) 集合——换道法的胜利点。输入与结果共享节点，不计入。
- **口述模板**："时间 O(m+n)，两指针各走一遍两链总长；空间 O(1)——换道走消长度差，比哈希法省掉整个集合。"
