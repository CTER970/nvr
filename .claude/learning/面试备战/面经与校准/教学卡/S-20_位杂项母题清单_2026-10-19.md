# S-20｜位杂项（判 2 的幂/取位段/平均不溢出）

> **卡头**：S-20｜嵌入式原创｜C2 位运算/C 基本功/嵌入式特色族｜P1 第三批｜Easy｜纯 C
> **实证**：定性（族内母题清单成员，与 S-17/S-18 同场出现）
> **定位**：族内母题清单卡——`n&(n-1)` 判 2 的幂、位段宏族、`(a&b)+((a^b)>>1)` 防溢出平均。

---

## 一、题目解析

- **输入**：①判 2 的幂：整数 n（可能为 0/负数）；②取位段：`uint32_t` 与 [shift,width)；③平均值：两非负 `uint32_t`，相加可能溢出。
- **输出**：①是否 2 的幂（bool）；②位段数值；③不溢出的平均。
- **约束确认**（写码前 30 秒口述）：判幂的 n 能为 0 或负吗？→必须显式排除，0 会误判；位段取出后要循环使用还是一次性？→宏无副作用即可；平均的两数都接近 UINT32_MAX 吗？→是，`a+b` 直接 UB/回绕。
- **一句话考什么**：三道小题各防一个坑——0 值坑、移位顺序坑、加法溢出坑。

## 二、解题思路

**判 2 的幂**：2 的幂二进制恰一个 1（1,10,100,…），`n&(n-1)` 消掉唯一那个 1 得 0。**坑**：n=0 时 `0 & -1 = 0` 误判为真，必须 `n>0 &&` 前置（`&&` 短路保证 n-1 不在 n=0 上求值也安全）；负数同理被 n>0 挡掉。

**取位段**：S-17 write_field 的读兄弟版——先右移对齐再掩码：`(x>>shift)&((1u<<width)-1)`。顺序纪律：先移后掩（先掩后移会把相邻位拖进来）。

**平均不溢出**：`(a+b)/2` 的 `a+b` 会溢出。按位拆解：`a&b` 是**同位全是 1 的部分**（进位信息，×2），`a^b` 是**恰有一方是 1 的部分**（无进位和）。平均 = (2×同位 + 异位)/2 = `(a&b) + ((a^b)>>1)`——同位部分右移一位补齐（不再产生任何进位），全程最大值 ≤ max(a,b)，绝不溢出。

```
判 2 的幂：n=8=0b1000，n-1=0b0111
  1000 & 0111 = 0000 → 是   （唯一 1 被消光）
  n=6=0b110，n-1=0b101 → 100 ≠ 0 → 否（两个 1，消一个还剩一个）

防溢出平均：a=0b1110(14), b=0b1010(10)，直接 14+10=24 未溢出但临界已险
  a&b = 0b1010 (10)   ← 同为 1 的位=成对进位，2×10=20
  a^b = 0b0100 ( 4)   ← 恰一方为 1=无进位和
  (a&b)+((a^b)>>1) = 10 + 2 = 12 = (14+10)/2 ✓ 中途最大值不超 max(a,b)
```

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```c
#include <stdint.h>
#include <stdbool.h>

bool is_power_of_two(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}

uint32_t read_field(uint32_t x, int shift, int width) {
    return (x >> shift) & ((1u << width) - 1u);
}

uint32_t avg_no_overflow(uint32_t a, uint32_t b) {
    return (a & b) + ((a ^ b) >> 1);
}
```

### 3.2 教学讲解版（关键决策注释）

```c
#include <stdint.h>
#include <stdbool.h>

bool is_power_of_two(int n) {
    /* n>0 必须前置且必须用 &&：0 会得 0&-1==0 误判"是幂"，
       负数补码含多个 1 同样误判；&& 短路让 n-1 只在 n>0 时求值 */
    return n > 0 && (n & (n - 1)) == 0;
    /* 原理：2 的幂二进制恰一个 1，n-1 借位恰好消掉它 */
}

uint32_t read_field(uint32_t x, int shift, int width) {
    /* 顺序纪律：先 >> 对齐到 bit0，再 & 低 width 位全 1 掩码；
       反过来先 & 后移，掩码会跟着左移，相邻位段被拖进结果。
       ((1u<<width)-1) 生成 0b...0111，位段题的万能掩码 */
    return (x >> shift) & ((1u << width) - 1u);
}

uint32_t avg_no_overflow(uint32_t a, uint32_t b) {
    /* a&b=两数同为 1 的位（每对贡献 2），a^b=恰一方为 1 的位（贡献 1）；
       平均= (2*同位 + 异位)/2 = 同位 + (异位>>1)。
       (a&b) 本身 ≤ min(a,b)，(a^b)>>1 ≤ (max-min)，全程无加法进位
       可能越界——这就是"不溢出"的根源，不是碰巧 */
    return (a & b) + ((a ^ b) >> 1);
}
```

## 四、代码解析

**三块结构**：

1. **is_power_of_two**：一行双条件，缺一不可——`n>0` 守 0/负数，`n&(n-1)` 验唯一性。顺手背下变式：判 4 的幂=先判 2 的幂再 `& 0x5555...55`（奇数位）；低 2 的幂对齐=`(n+mask)&~mask`。
2. **read_field**：S-17 的 write_field 配对（那卡是写，这卡是读），两者共掩码公式 `(1u<<width)-1`，方向相反：读先移后掩、写先清后装。
3. **avg_no_overflow**：本质是"按位拆进位"。同位部分 `a&b` 直接给平均的贡献（一对 1 平均后仍是一个 1 在该位），异位部分 `>>1` 对半——两项相加每 bit 最多进一位到更高位且不越过 max(a,b)。另一等价式 `a + ((b-a)>>1)`（b≥a 时）也常被追问：无符号下 b-a 不回绕，也安全。

**不变量视角**：恒等式 `(a&b)*2 + (a^b) = a + b` 对一切 a,b 成立（每 bit 拆和），防溢出平均只是把它两边除 2 并用移位实现——代数正确性而非黑魔法。

## 五、复杂度

- **时间 O(1)**：三题各为常数条位运算指令；与数值大小、位段位置无关，无循环。
- **空间 O(1)**
  - **口径说明**：指**辅助空间**——全部中间量是标量；无输出空间（返回值）；无递归。位运算族整体"零额外结构"，这正是嵌入式偏爱它的原因。
- **口述模板**："判 2 的幂 n>0 且 n&(n-1) 为 0——0 必须显式排除；取位段先移后掩；防溢出平均 (a&b)+((a^b)>>1)，按位拆进位，中途不超过 max(a,b)，全是 O(1)。"
