# S-19｜136. 只出现一次的数字（异或）+ 不用临时变量交换

> **卡头**：S-19｜LC136｜C2 位运算/C 基本功/嵌入式特色族｜P1 第三批｜Easy｜C++（C 风格）
> **实证**：大疆 B2-15（异或消重与异或 swap 连考）
> **定位**：`a^a=0、a^0=a` 的推导链——串起消重、swap、找奇次元素一族。

---

## 一、题目解析

- **输入**（LC136）：非空数组，恰有一个元素出现一次，其余均出现两次；长度 1~10⁴。
- **输出**：那个只出现一次的元素；附加题：不用临时变量交换两个整数。
- **约束确认**（写码前 30 秒口述）：其余元素恰两次还是任意偶数次？→两次（奇数次需换 137 题）；允许额外空间吗？→O(1) 才是本题考察点；异或 swap 两个变量同地址会怎样？→自毁成 0，必须防。
- **一句话考什么**：异或的**自消性**（a^a=0）与**单位元性**（a^0=a）叠加交换律结合律——全员连异或，成对者湮灭，孤儿存活。

## 二、解题思路

三条性质推导：①`a^a=0`（同位同值必为 0）；②`a^0=a`（0 是异或单位元）；③交换律+结合律（异或是按位的模 2 加法，加法满足两者）。于是"全员异或"可任意重排——把成对的挪到一起互相湮灭，最后剩 `0^孤独值=孤独值`。hash 计数 O(n)/O(n) 是下界兜底，异或把空间压到 O(1)。

swap 异或版：连续三步 `a^=b; b^=a; a^=b;`，展开即 `b = b^(a^b) = a`（消去 b）、`a = (a^b)^a = b`——**不引入第三方却借 a 自身当临时仓库**。同地址调用 `SWAP(a,a)` 时第一步 `a^=a` 直接归零，后两步救不回——别名坑。

```
全员异或（[4,1,2,1,2]）：
4 ^ 1 ^ 2 ^ 1 ^ 2  -- 交换律重排 -->
4 ^ (1^1) ^ (2^2)  =  4 ^ 0 ^ 0  =  4

异或 swap（a=5=0b0101, b=3=0b0011）：
a ^= b :  0b0101^0b0011 = 0b0110 (6)   a 变成"两数之和的模2影"
b ^= a :  0b0011^0b0110 = 0b0101 (5)   b 拿到原 a
a ^= b :  0b0110^0b0101 = 0b0011 (3)   a 拿到原 b
```

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int x = 0;
        for (int v : nums) x ^= v;
        return x;
    }
};

/* 附加：不用临时变量 swap（异或三连） */
void xor_swap(int& a, int& b) {
    if (&a != &b) {
        a ^= b;
        b ^= a;
        a ^= b;
    }
}
```

### 3.2 教学讲解版（关键决策注释）

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        /* 异或满足交换律+结合律（按位模 2 加法），全员连 ^ 的结果
           与顺序无关——成对元素无论相隔多远，重排后必然相邻湮灭；
           0 是单位元，用 x=0 起步可无特判地吃下第一个元素 */
        int x = 0;
        for (int v : nums) x ^= v;   /* 不变量：x=已扫元素中孤儿值^0 */
        /* 退出循环时：成对者全湮灭 → x 恰为只出现一次的那个 */
        return x;
    }
};

void xor_swap(int& a, int& b) {
    /* 别名防御必须在最前：若 &a==&b，第一步 a^=a 会把变量清零，
       后两步在 0 上空转，原值永久丢失——同变量 swap 是自毁 */
    if (&a != &b) {
        a ^= b;   /* a ← a^b：两数信息的叠加态（可逆） */
        b ^= a;   /* b ← b^(a^b) = 原a：b 与叠加态异或，b 自消 */
        a ^= b;   /* a ← (a^b)^原a = 原b：a 自消，a 拿到原 b */
    }
}
```

## 四、代码解析

**两块结构**：

1. **singleNumber**：累加器 x 起步 0（单位元），每轮 `x ^= v`——成对元素贡献 0、孤儿贡献自身。哈希表版 O(n)/O(n) 口述一句作对照即可，别真写。约束"恰一次 vs 两次"是性质成立的全部前提：三个三次出现会异或成自身（a^a^a=a），剩奇次元素的 137 题需数位统计。
2. **xor_swap**：三步代数展开见注释——每步都靠"异或自己=消掉自己"。顺序纪律：三步顺序固定不可换（第二步的 a 必须是第一步的叠加态）；指针相等判断在前，防 SWAP(a,a) 自毁。讲分点：这是语言/编译器经典题，工程上直接 `std::swap`/临时变量（见 S-22），异或版会杀死编译器优化并损失可读性。

**不变量视角**：循环任意时刻，`x = (已扫元素中落单者) ^ (已扫成对元素全部湮灭后的 0)` = 落单者；swap 三步任意时刻，`a^b` 的值恒等于 `原a^原b`（信息守恒），第三步结束完成角色互换。

## 五、复杂度

- **时间 O(n)**：每个元素恰好异或一次；与数据分布无关，最坏=平均。
- **空间 O(1)**
  - **口径说明**：指**辅助空间**——累加器 x 一个标量；输入数组是**输入空间不计入**；无输出空间（返回标量）；无递归。哈希表版需 O(n) 额外，正是本题要压掉的部分。
- **口述模板**："全员异或一趟，成对的靠 a^a=0 湮灭，0^a=a 让孤儿存活，交换律保证顺序无关——O(n) 时间 O(1) 辅助空间；异或 swap 三连是同一性质，但必须防同地址自毁。"
