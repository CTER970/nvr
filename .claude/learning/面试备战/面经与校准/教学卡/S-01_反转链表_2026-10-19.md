# S-01｜206. 反转链表（Reverse Linked List）

> **卡头**：S-01｜LC206｜F1 链表族｜P0｜Easy｜C++（C 风格）
> **实证**：小米 HS-002/076｜字节 PICO B2-34｜MTK B2-39
> **定位**：三指针逐个掉头——指针操作类题的地基，迭代+递归双写是链表族的第一次全量演练。

---

## 一、题目解析

- **输入**：单链表头 `head`，节点数 0~5000，值域 −5000~5000。
- **输出**：反转后的新头——**原节点原地掉头**（不新建节点、不拷贝数据，只改 `next` 指向）。
- **约束确认**（写码前 30 秒口述）：空表？→是，返回 nullptr；单节点？→是，原样返回；需原地？→是，只改指向。
- **一句话考什么**：指针现场掌控力——一次错误的前进顺序就断链；以及能否把递归版讲成"子问题+回程接线"。

## 二、解题思路

单向链表没有前驱指针，掉头前必须先把前驱存进变量、把后继存进变量，否则一改指向就丢链。迭代法就是**四拍循环**：存后继→掉头→前驱前进→当前前进，直到 `cur` 走空，`prev` 恰好停在最后一个节点即新头。

**指针现场示意**（`1→2→3→nullptr` 处理完一个节点时）：

```
初始：  nullptr    1 → 2 → 3 → nullptr
          ↑        ↑
        prev     cur

一轮后： nullptr ← 1    2 → 3 → nullptr     next 先存住 2
                  ↑    ↑    ↑                1->next=prev 掉头
                prev  cur  next              prev/cur 各前进一格
                        （next 本轮用完即弃）

循环不变量：prev 链（已反转）与 cur 链（未反转）在空中相邻，
           cur 走空时 prev 即新头
```

**递归版口述**：先一路递归到链尾拿到 `newHead`；回程时每一层执行 `head->next->next = head; head->next = nullptr;`——让我的后继反过来指我，我则斩断向后的指针变成新尾。递归基：空表或单节点直接返回 `head`。

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* cur = head;
        while (cur) {
            ListNode* next = cur->next;
            cur->next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }
};
```

### 3.2 教学讲解版（关键决策注释）

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        // prev 从 nullptr 起步而不是 new 一个节点：
        // 反转后原头必须指向 nullptr，这个"值"首轮就要用，天然存在于语义里
        ListNode* prev = nullptr;
        ListNode* cur = head;
        while (cur) {
            // 顺序纪律①：next 必须先存——掉头会覆盖 cur->next，
            // 之后再也找不到原后继，链从这里断
            ListNode* next = cur->next;
            // 掉头本体：不变量"prev 领一条已反转链"因此多收一个节点
            cur->next = prev;
            // 顺序纪律②：prev 必须先于 cur 前进——
            // 若先 cur = next，prev 就永远追不上 cur 刚让出的位置
            prev = cur;
            cur = next;
        }
        // 循环出口 cur 为空，prev 恰好是原链最后一个节点=新头；
        // 空表时循环零执行，prev=nullptr 就是正确答案，无需特判
        return prev;
    }
};
```

## 四、代码解析

**三块结构**：

1. **初始化块**：`prev=nullptr` 不是随便的初值——它是"反转后原头的新指向"这一语义的天然取值，也让空表情形零特判通过。
2. **主循环块**（四拍）：存后继→掉头→双前进。两条顺序纪律——①`next` 先存（掉头覆盖 `cur->next`，后存即断链）；②`prev` 先于 `cur` 前进（反了 prev 永远错位一格）。
3. **收尾块**：`cur` 走空即所有节点已掉头，`prev` 即新头——出口状态与返回值天然重合，这就是"不用特判"的结构性原因。

**不变量视角**：每轮开始时，"prev 领一条已反转完成的链；cur 领一条尚未反转的链；两链合计恰为原链所有节点"恒成立。循环结束时 `cur` 为空——全部节点已归 prev 链，正确性直接得证。

**递归 vs 迭代**：递归版用 n 层栈帧隐式保存"回去的路"，迭代版用 prev/next 两个指针显式保存——空间 O(n) 换 O(1)，这正是面试官追问的落点。

## 五、复杂度

- **时间 O(n)**：循环四拍恰好执行 n 次，每个节点恰好掉头一次；最坏=平均（与值分布无关）。
- **空间 O(1)**（迭代版）
  - **口径说明**：指**辅助空间**——prev/cur/next 三个指针 O(1)；题目已给的 n 个节点属**输入空间，不计入**；结果链**复用输入节点**（零新建、零拷贝），无独立输出空间。
  - 递归版需另计 **O(n) 递归栈深**（n 层栈帧），5000 节点即 5000 层——嵌入式面试官眼里这是可点名扣分项。
- **口述模板**："时间 O(n) 每个节点掉头一次；迭代版辅助空间 O(1)——只有三个指针，原地复用节点；递归版要加 O(n) 栈深，5000 节点有爆栈风险，所以现场默认迭代版。"
