# S-17｜寄存器位操作三板斧（置位/清零/翻转/取位段）

> **卡头**：S-17｜嵌入式原创｜C2 位运算/C 基本功/嵌入式特色族｜P0 第三批｜基础｜纯 C
> **实证**：大疆 HS-005、讯飞 HS-096、地平线 B2-46（"指定为取反"原话变体）
> **定位**：`|=` 置位、`&=~` 清零、`^=` 翻转、`(x>>n)&1` 取位——一切外设驱动 read-modify-write 的标准姿势。

---

## 一、题目解析

- **输入**：寄存器当前值 `x`（`uint32_t`）、目标位号 `n` 或位段 `[shift, shift+width)`、写入值 `val`。
- **输出**：完成置位/清零/翻转/取位/改位段后的新值（寄存器语义：返回新值供写回）。
- **约束确认**（写码前 30 秒口述）：位号范围？→0~31，移位 ≥32 是 UB；改位段时 val 超出宽度怎么办？→必须先 `& mask` 截断；读硬件寄存器用什么读？→volatile（每次都真读）。
- **一句话考什么**：单 bit 的三运算（`|`/`&~`/`^`）+ 位段的"先清空槽再装入"两步合成。

## 二、解题思路

单 bit 三板斧由三种位运算的真值特性决定：`|1` 强制置 1（`|0` 保持）；`&0` 强制清 0（`&1` 保持）；`^1` 翻转（`^0` 保持）——"保持/强制"二选一就是全部武器。取位：先右移把目标位落到 bit0，再 `&1` 挡住其余位。**改位段**（如把 bit4~bit6 三位改成 val）是嵌入式最标准的 read-modify-write：`&=~mask` 清空槽 → `|=(val<<shift)` 装入新值——顺序不能反，先装入再清空会把刚装入的位清掉。

```
x = 0b1011_0100，对 bit3 操作：

置位  x |=  (1u<<3):  1011_0100 → 1011_1100   (bit3 强制 1)
清零  x &= ~(1u<<3):  1011_1100 → 1011_0100   (bit3 强制 0)
翻转  x ^=  (1u<<3):  1011_0100 → 1011_0000   (bit3 取反=地平线"指定为取反")
取位  (x>>3)&1     :  1011_0100 >>3 = 0b10110 → &1 = 0

改位段 bit[6:4]=0b101（width=3, shift=4）：
mask = ((1u<<3)-1)<<4 = 0b0111_0000
  x &= ~mask :  1_0111_0100 → 1_0000_0100   槽内清空，槽外不动
  x |= 101<<4:  1_0000_0100 → 1_0101_0100   新值装入
```

`(1u<<width)-1` 生成"低 width 个 1"（2³−1=0b111），再左移 shift 到位——掩码生成的万能公式。

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```c
#include <stdint.h>

#define BIT(n)          (1u << (n))
#define SET_BIT(x, n)   ((x) |=  BIT(n))
#define CLR_BIT(x, n)   ((x) &= ~BIT(n))
#define TOG_BIT(x, n)   ((x) ^=  BIT(n))
#define GET_BIT(x, n)   (((x) >> (n)) & 1u)

/* 位段写入：把 x 的 [shift, shift+width) 改为 val */
static inline uint32_t write_field(uint32_t x, uint32_t val,
                                   int shift, int width) {
    uint32_t mask = ((1u << width) - 1u) << shift;
    return (x & ~mask) | ((val << shift) & mask);
}
```

### 3.2 教学讲解版（关键决策注释）

```c
#include <stdint.h>

/* 三板斧的"保持/强制"真值表根基：
   置位  |1 强制 1，|0 保持 → x |= BIT(n)
   清零  &0 强制 0，&1 保持 → x &= ~BIT(n)
   翻转  ^1 取反， ^0 保持 → x ^= BIT(n)      */
#define SET_BIT(x, n)   ((x) |=  BIT(n))
#define CLR_BIT(x, n)   ((x) &= ~BIT(n))
#define TOG_BIT(x, n)   ((x) ^=  BIT(n))
/* 取位必须先 >> 后 &1：直接 x & BIT(n) 得到的是 0b1000 而非 1，
   右移先归位到 bit0，&1 才得到 0/1 可直接当布尔用 */
#define GET_BIT(x, n)   (((x) >> (n)) & 1u)

static inline uint32_t write_field(uint32_t x, uint32_t val,
                                   int shift, int width) {
    /* (1<<width)-1 = 低 width 位全 1（width 个 1 减 1 进位借光），
       再 <<shift 对准槽位；BIT 也用它生成更宽的段掩码 */
    uint32_t mask = ((1u << width) - 1u) << shift;
    /* 顺序纪律：必须先 &=~mask 清槽再 |= 装入——
       反过来先装后清，新值恰好被 mask 命中，全被清成 0 */
    /* val 先 & mask 截断：调用者传入超宽 val 时不污染相邻位段 */
    return (x & ~mask) | ((val << shift) & mask);
}

/* 真实外设姿势：volatile 保证每次都真正读写 MMIO，
   绝不被编译器优化成"读一次缓存到寄存器" */
static inline void reg_set_bit(volatile uint32_t *reg, int n) {
    *reg |= BIT(n);       /* read-modify-write 三拍一眼可见 */
}
```

## 四、代码解析

**三块结构**：

1. **单 bit 四则**：SET/CLR/TOG 三个赋值运算宏覆盖外设控制 90% 需求；GET 的顺序纪律是"先移后与"——直接 `x & BIT(n)` 返回的是位权值不是 0/1。
2. **write_field**：掩码生成 `(1u<<width)-1` 借"2 的幂减 1"进位借光原理；两步合成的顺序不可换（先清后装）；`val & mask` 截断是对调用者的防御。合成式单 return 无中间写回——纯函数形态便于断言。
3. **volatile 块**：MMIO 寄存器必须 volatile 指针，read-modify-write 在一句 `*reg |= BIT(n)` 内完成；非原子，中断并发场景需关中断或用硬件 set/clear 寄存器（如 STM32 的 BSRR）。

**不变量视角**：`x & ~mask` 与 `val<<shift & mask` 两路结果在 mask 槽内外互补（一路槽内全 0、另一路槽外全 0），`|` 合并槽外保持原值、槽内恰为新值——"槽外不动、槽内换新"恒成立。

## 五、复杂度

- **时间 O(1)**：每条都是常数条机器指令（移位/与/或/异或）；与位号、寄存器值无关，无循环无分支。
- **空间 O(1)**
  - **口径说明**：指**辅助空间**——mask 等中间量全在寄存器/栈上，固定常数；无输出空间（返回值）；无递归。
- **口述模板**："三板斧全是 O(1) 指令级操作：置位或、清零与上取反、翻转异或；位段写入先掩码清槽再装入，顺序不能反；真实寄存器加 volatile 做 read-modify-write。"
