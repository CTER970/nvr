# S-18｜191. 位 1 的个数（Number of 1 Bits）

> **卡头**：S-18｜LC191｜C2 位运算/C 基本功/嵌入式特色族｜P0 第三批｜Easy｜C++（C 风格）
> **实证**：小米 B2-11、字节 HS-029、大疆 HS-053（变式：1~N 中数字 1 出现总次数）
> **定位**：`n&(n-1)` 消最低位 1——"2 的幂判定/两人一组异或消重"同一根母题。

---

## 一、题目解析

- **输入**：32 位无符号整数 `n`（LC191 保证 32 位；若题面是 int 需先转 unsigned）。
- **输出**：二进制中 1 的个数（popcount / Hamming weight）。
- **约束确认**（写码前 30 秒口述）：负数怎么办？→本题 unsigned 天然无符号位问题；循环次数上限？→32（逐位版）/ popcount 个数（快版）；n=0 直接返回 0。
- **一句话考什么**：`n&(n-1)` 每次精确消去**最低位的 1**，循环次数即答案——比逐位扫描快"少几个 0 转几轮"。

## 二、解题思路

对照两版：①逐位右移：每一位 `&1` 数一遍，循环 32 次，1 多 0 少都要转；②`n &= n-1`：每次消掉最低位的 1，循环次数=1 的个数，最坏 32（全 1），最好 1 次。

**`n&(n-1)` 为什么恰好消最低位 1（借位解释）**：减 1 时，最低位的 1 需要被减掉，它后面的 0 不够减、逐级借位——结果是"最低位的 1 变 0，其后所有 0 变 1，其上各位原样"。再与原数按位与：从最低位 1 往下，一边是 0 一边是 1（相与得 0）；最低位 1 处 1&0=0；其上各位 1&1 或 0&0 保持——**除被消的那个 1，全部不变**。

```
n     = 0b1011 (11)      最低位的 1 在 bit0
n - 1 = 0b1010 (10)      bit0 借位：1→0（此处低位无 0，只翻自身）

n     :  1 0 1 1
n-1   :  1 0 1 0
&(消) :  1 0 1 0   ← bit0 的 1 被消，其余原样  → count=1

n=0b1010 时：n-1=0b1001（bit1 的 1 变 0、bit0 的 0 借成 1）
n&(n-1): 0b1000          → count=2     再来一轮 0b1000&0b0111=0 → 循环 3 轮=答案 3
```

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```cpp
class Solution {
public:
    int hammingWeight(uint32_t n) {
        int cnt = 0;
        while (n) {
            n &= n - 1;
            cnt++;
        }
        return cnt;
    }
};
```

### 3.2 教学讲解版（关键决策注释，含逐位右移对照版）

```cpp
class Solution {
public:
    int hammingWeight(uint32_t n) {
        /* 不用 for 32 次的逐位版，用 n&=n-1：循环次数=1 的个数。
           依据：n-1 借位后"最低位 1 清零、其后 0 全变 1、其上不变"，
           按位与恰只消掉这一个 1——不变量：每轮 popcount 恰好减 1 */
        int cnt = 0;
        while (n) {       /* n==0 即全部 1 已耗尽，不用额外计数器判停 */
            n &= n - 1;
            cnt++;
        }
        return cnt;
    }
};

/* 对照版：逐位右移，O(1) 个变量但循环次数恒 32
   int hammingWeight(uint32_t n) {
       int cnt = 0;
       for (int i = 0; i < 32; i++) {
           cnt += n & 1u;   // 先取 bit0 再右移，顺序不能反
           n >>= 1;
       }
       return cnt;
   }                                                           */
```

## 四、代码解析

**两块结构**：

1. **`n&=n-1` 快版**：循环条件直接用 `n` 非零——每消一个 1，n 的 1 个数减 1，消光即 0，判停与计数天然同步。`cnt++` 与 `n&=n-1` 顺序无关紧要，但"先改 n 再计数"的写法读起来一拍一循环更清晰。
2. **逐位对照版**：`cnt += n&1` 必须在 `n>>=1` **之前**——先移后取，取的是已经离开的 bit0。该版优势是循环次数固定 32（与 1 的个数无关），适合计时确定性的场合；劣势是 0 多时白转。

**不变量视角**：进入每轮时，"cnt = 已消掉的 1 的个数，n 中剩余 1 的个数 = 总数 − cnt"恒成立；循环退出时 n=0，cnt 恰为 popcount(n₀)。

**变式口述（大疆 HS-053：1~N 中数字 1 总次数）**：那是数位 DP/按位统计题，与 popcount 无算法关联，考的是听到"1 的次数"不条件反射——先分辨"二进制 1 的个数"还是"十进制数字 1 出现次数"。

## 五、复杂度

- **时间 O(k)**，k=1 的个数：快版每轮恰消一个 1，最坏 O(32)=O(1)（32 位定宽上界）；逐位版恒 O(32)。两版在 32 位输入下都视为 O(1)，但快版平均轮数=期望 popcount≈16。
- **空间 O(1)**
  - **口径说明**：指**辅助空间**——cnt 与 n 共 2 个标量；无输出空间（返回 int）；无递归栈。
- **口述模板**："用 n&(n-1) 每次消最低位的 1——减 1 借位把最低位 1 清零、后面 0 全变 1，相与后只剩它被消掉；循环几次有几个 1，32 位上界即 O(1)，空间一个计数器。"
