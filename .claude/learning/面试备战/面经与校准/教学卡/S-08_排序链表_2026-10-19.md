# S-08｜148. 排序链表（Sort List）

> **卡头**：S-08｜LC148｜F1 链表族｜P1｜Medium｜C++（C 风格）
> **实证**：CVTE HS-014（现场）、MTK HS-132（汇总帖）
> **定位**：链表族的集大成题——快慢找中点（S-05）+ 合并有序链表（S-03）两个母题的组合应用，面试讲"怎么拼"比写码更重要。

---

## 一、题目解析

- **输入**：单链表头 `head`（节点数 0~5×10⁴，值 −10⁵~10⁵）。
- **输出**：升序排序后的链表头。
- **约束确认**：进阶要求 O(n log n) 时间 + O(1) 空间？→是（自底向上归并才能 O(1)；递归归并栈 O(log n) 常被接受）；可否改节点值？→可，但链表题惯例改指针。
- **一句话考什么**：**分治在链表上的落地**——数组排序会快排不稀奇，链表首选归并的原因要能讲清。

## 二、解题思路

链表排序为什么选归并不选快排：①快排依赖**随机访问**做 partition（链表 O(1) 访问只有头，partition 退化）；②归并的核心操作"合并两段有序"在链表上是 O(1) 空间改指针（数组要辅助数组）；③归并稳定。

递归版三步：**快慢指针找中点**（slow 停在前半尾，从中点断链）→ **两半各自递归排序** → **合并两条有序链表**（就是 S-03 原题）。

```
4 → 2 → 1 → 3
    ↓ 找中点并断开
[4 → 2]      [1 → 3]
  ↓ 递归        ↓ 递归
[2 → 4]      [1 → 3]
    └── merge（S-03）──┘
        1 → 2 → 3 → 4
```

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
class Solution {
    ListNode* merge(ListNode* a, ListNode* b) {
        ListNode dummy(0);
        ListNode* t = &dummy;
        while (a && b) {
            if (a->val <= b->val) { t->next = a; a = a->next; }
            else                  { t->next = b; b = b->next; }
            t = t->next;
        }
        t->next = a ? a : b;
        return dummy.next;
    }
public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;
        ListNode *slow = head, *fast = head->next;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }
        ListNode* mid = slow->next;
        slow->next = nullptr;
        ListNode* left = sortList(head);
        ListNode* right = sortList(mid);
        return merge(left, right);
    }
};
```

### 3.2 教学讲解版

```cpp
public:
    ListNode* sortList(ListNode* head) {
        // 递归出口：空链或单节点天然有序——分治的原子情况
        if (!head || !head->next) return head;

        // 找中点：fast 从 head->next 起步（不是 head！）。
        // 起步偏移一格使 slow 停在【前半段的最后一个】，
        // 由此断链后两半长度 ceil/floor 均分；
        // 若 fast 也从 head 起步，两节点链会切成 2/0 —— 无限递归，栈溢出
        ListNode *slow = head, *fast = head->next;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
        }

        ListNode* mid = slow->next;
        slow->next = nullptr;      // 物理断链：分治的前提是两半真正独立

        ListNode* left  = sortList(head);   // 排前半
        ListNode* right = sortList(mid);    // 排后半
        return merge(left, right);          // 合并 = S-03 原题原样复用
    }
```

## 四、代码解析

**三块结构**：

1. **找中点块**：`fast` 起步 `head->next` 是本题最隐蔽的正确性细节——它决定 `slow` 停在前半尾而非后半头，保证**两半都非空**（否则 2 节点链切不动，无限递归）。断链 `slow->next = nullptr` 必须在做递归前完成。
2. **递归块**：先排左、再排右、后合并——后序位置做 merge，符合"先分解到原子再向上组装"。
3. **merge 块**：S-03 逐行复用（dummy+tail+余段），这就是"母题思维"的现场证明：面试官在这题想看的恰恰是你**能否识别出子问题已学过**。

**不变量视角**：每层递归的契约是"给我一条链，还你一条有序链"；分解保证子链严格变短且非空，故递归必终止；merge 保证两条有序链合成一条有序链——归纳成立。

## 五、复杂度

- **时间 O(n log n)**：递归深度 log n 层，每层 merge 合计处理 n 个节点。最坏=平均=最好（归并与数据分布无关——对比快排链表版退化的另一佐证）。
- **空间 O(log n)**
  - **口径说明**：指**递归栈**深度（每层 O(1) 局部变量 × log n 层）；merge 本身 O(1) 辅助（dummy+指针）；输入节点全部复用，无输出空间。**进阶 O(1) 空间**需自底向上迭代归并（每轮按步长 1,2,4… 切段合并，口述即可）。
- **口述模板**："归并排序，时间 O(n log n) 与数据分布无关；递归栈 O(log n)，merge 借哑节点 O(1)；真要 O(1) 就自底向上按步长迭代合并。"
