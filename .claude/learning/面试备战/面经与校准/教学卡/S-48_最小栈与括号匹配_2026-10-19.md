# S-48｜155. 最小栈 / 20. 有效的括号

> **卡头**：S-48｜LC155/20｜F9 栈与队列族｜P1｜Easy｜C++（C 风格）
> **实证**：HS-068（华为 C++ 岗：数组/链表实现栈）
> **定位**：栈的两张入门对卡——最小栈考**辅助栈同步**设计，括号匹配考**栈的弹压时序**；同场常以"用数组手写栈"为先导问题。

---

## 一、题目解析

- **LC155 输入/输出**：push/pop/top/getMin 四操作，各 O(1)；pop/top/getMin 保证作用于非空栈。
- **LC20 输入/输出**：仅含 `()[]{}` 的串 → 是否合法嵌套闭合。
- **约束确认**：155 getMin 弹出后要回落到次小？→是（动态维护）；20 空串？→合法；交错如 `([)]`？→非法。
- **一句话考什么**：空间换时间的**同步栈**设计 + 括号的**LIFO 对偶**（左括号进栈等右括号来对账）。

## 二、解题思路

**最小栈**：主栈存全部元素；**辅助栈同步存"当前时刻的最小值"**——push 时辅助栈压 `min(新值, 辅助栈顶)`；pop 时两栈同弹。任何时刻辅助栈顶=当前栈内最小，getMin 直接读。

```
push 5,2,7,1:
主栈:   [5] [2] [7] [1]
辅栈:   [5] [2] [2] [1]   ← 每层都是"到该层为止的最小值"
pop → 双弹 → 辅栈顶回到 2  ← 最小值自动"回落"，这就是同步的意义
```

**括号匹配**：左括号一律压栈；右括号到来时弹栈比对**同类**——栈空而遇右括号（无左可配）或弹出不匹配即非法；扫描完栈必须为空（还有左括号没等到配对）。

```
"( [ ] )"
'(' push → '[' push → ']' 弹'[' 匹配✓ → ')' 弹'(' 匹配✓ → 栈空 → 合法
"([)]"  → ')' 弹出'[' ✗ 非法（最近未配对的必须先被配——LIFO）
```

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
class MinStack {
    stack<int> st, mn;
public:
    void push(int val) {
        st.push(val);
        mn.push(mn.empty() ? val : min(val, mn.top()));
    }
    void pop() { st.pop(); mn.pop(); }
    int top()  { return st.top(); }
    int getMin(){ return mn.top(); }
};

bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else {
            if (st.empty()) return false;
            char t = st.top(); st.pop();
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) return false;
        }
    }
    return st.empty();
}
```

### 3.2 教学讲解版

```cpp
class MinStack {
    stack<int> st, mn;   // 主栈+镜像辅助栈：层数严格同步
public:
    void push(int val) {
        st.push(val);
        // 辅助栈每层语义："若弹掉本层及以下之后，栈内最小是谁"
        // 由 min(新值, 旧最小) 一句话维护——历史的最小记录永不丢失
        mn.push(mn.empty() ? val : min(val, mn.top()));
        // 空栈卫兵在首元素：它是第一个，也是当时的唯一最小
    }
    void pop() { st.pop(); mn.pop(); }   // 双弹缺一不可：
        // 只弹主栈 → 辅助栈层数错位，getMin 读到已弹层的旧值
    int top()   { return st.top(); }
    int getMin(){ return mn.top(); }     // O(1) 直读：全部代价在 push 时预付
};

bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);              // 左括号：先记账，等右括号来对
        } else {
            // 右括号先到而栈空 → 没有任何左括号欠账可还 → 非法
            if (st.empty()) return false;
            char t = st.top(); st.pop();
            // 弹出的必须是"同类型"——栈顶是最近的未配左括号，
            // 嵌套合法性要求最近的先配（LIFO 与嵌套结构天然同构）
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) return false;
        }
    }
    return st.empty();   // 扫完栈非空 → 有左括号永远没等到配对
}
```

## 四、代码解析

**最小栈**：核心是**不变量"两栈层数相等，且 mn 第 k 层 = 主栈前 k 层最小"**——push 维护、pop 双弹保持、getMin 免费读取。这个"空间换时间"（O(n) 辅助栈买 O(1) 查询）是嵌入式缓存/统计设计的微缩模型。追问预案：省空间版（辅助栈只在新最小时压、相等也压）——口述即可。

**括号**：三出口的完备性——右括号无账可还（栈空早退）、还错账（类型不匹配）、账未还清（尾检栈空）。三个条件缺一漏一类非法。追问预案：最长合法括号子串（LC32）→栈存下标而非字符。

## 五、复杂度

- **时间**：155 四操作各 O(1)（getMin 的代价被 push 预付——**口径说明：单次 O(1) 无均摊水分**）；20 为 O(n) 单遍，每字符一次压/弹。
- **空间**：155 O(n)——**口径说明**：辅助栈最坏 O(n)（递减序列每层都新最小），是换取 O(1) getMin 的对价；20 O(n) 最坏（全左括号）。
- **口述模板**："最小栈=镜像辅助栈：每层同步存'到该层为止的最小'，getMin O(1) 直读，代价 O(n) 空间；括号匹配=左压右弹，三个非法出口：栈空遇右、类型错配、尾扫栈非空。"
