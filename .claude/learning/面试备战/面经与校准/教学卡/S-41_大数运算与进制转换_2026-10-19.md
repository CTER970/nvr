# S-41｜大数运算与进制转换（字符串版）

> **卡头**：S-41｜嵌入式原创（无 LC 对应，牛客笔试常见）｜F7 字符串·算法族｜P1｜Medium｜C++（C 风格）

> **定位**：字符串模拟数值运算的身份题——"数不存在 int 里、存在字符数组里"的世界观，与 S-13 atoi/S-40 IP 互转共同构成"解析-数值化-拼装"三件套。

## 一、题目解析

- **输入**：以字符串表示的超长非负整数（可远超 64 位，如 100 位十进制）；进制转换变体给任意进制 b（2~16）。
- **输出**：两数之和/乘积的字符串形式；进制变体输出目标进制表示。**不允许**转 long long（溢出即错）。
- **约束确认**（写码前 30 秒口述）：最长多少位？→笔试口径按 10^3~10^4 位设计，数组开够；有前导零？→结果要去前导零（"00012"→"12"，全零保留一个"0"）；乘法结果位上限？→m+n 位（两数位数之和），按上界开数组。
- **一句话考什么**：**把手工竖式搬到数组**——按位运算+进位纪律，外加"数字字符 ⇄ 数值"的双向换算。

## 二、解题思路

**世界观**：数值大到 int 装不下时，唯一可靠的容器就是字符串/数组——每位一个字符，运算规则回到小学竖式。加法从**最低位**（两串末尾）对齐竖式相加，逐位"本位和+进位"；乘法是"错位加"：a 的第 i 位 × b 的第 j 位贡献到结果的第 i+j 位，最后统一处理进位。

**进制转换（辗转除二取余法）**：十进制串 → 目标进制，反复"整体除以 b，记下余数"——除法同样按位从高位到低位做：每位 = 上一位余数×10+本位，商写回，末位余数即一个输出位；余数**逆序**收集。关键不变量：被除数任何时刻都 < b×10。

```
加法竖式（低位对齐，t=进位）：
    1 2 9       i 从末位起：9+4+t → 本位 3 进 1
  +   3 4       "123"+"34" → "157"
  ───────       循环条件：i/j 未尽 或 t≠0，三者任一在就继续

乘法错位（123×45）：
  贡献矩阵：i+j 位累加，先全加完再统一进位
  res[5]（m+n 上界），最后转字符串+去前导零

十进制→二进制（除2取余）："10" → 5 余0 → 2 余1 → 1 余0 → 0 余1
  余数逆序：1010
```

进行到一半的现场（加法，i=1，即十位）：t=1（个位进了 1），本位 2+3+1=6 写 6、t 归 0——**进位变量在每轮开始时携带上轮溢出，结束时要么清零要么留在结果最高位**。

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```cpp
string bigAdd(const string &a, const string &b) {
    int i = a.size() - 1, j = b.size() - 1, t = 0;
    string res;
    while (i >= 0 || j >= 0 || t) {
        int s = t;
        if (i >= 0) s += a[i--] - '0';
        if (j >= 0) s += b[j--] - '0';
        res += (char)('0' + s % 10);
        t = s / 10;
    }
    reverse(res.begin(), res.end());
    return res;
}

string decToBase(const string &num, int base) {
    if (num == "0") return "0";
    string n = num, res;
    while (n != "0") {
        string q; int r = 0;
        for (char c : n) {                 /* 高位到低位除 base */
            int cur = r * 10 + (c - '0');
            q += (char)('0' + cur / base);
            r = cur % base;
        }
        int k = 0; while (k < (int)q.size() - 1 && q[k] == '0') k++;  /* 去商前导零 */
        n = q.substr(k);
        res += "0123456789ABCDEF"[r];      /* 余数逆序收集（最后统一 reverse） */
    }
    reverse(res.begin(), res.end());
    return res;
}
```

### 3.2 教学讲解版（关键决策注释）

```cpp
string bigAdd(const string &a, const string &b) {
    // 从最低位（两串末尾）起算——竖式方向；
    // i/j 独立递减：短串走尽后 s 只加长串位，天然对齐，无需预补零
    int i = a.size() - 1, j = b.size() - 1, t = 0;
    string res;
    // 循环条件三通道：i 未尽 / j 未尽 / 进位未清——
    // 特别注意 t!=0：最高位再溢出时要多写一位（99+1=100），
    // 漏了 t 通道就丢掉结果的最高位
    while (i >= 0 || j >= 0 || t) {
        int s = t;                          // 本轮从"继承的进位"起步
        if (i >= 0) s += a[i--] - '0';      // 字符→数值：-'0' 换算，
        if (j >= 0) s += b[j--] - '0';      // 数值→字符：+'0' 写回——双向换算是本题骨架
        res += (char)('0' + s % 10);        // 本位 = 和的个位
        t = s / 10;                         // 恢复不变量：t 恒为"已处理位的总溢出"
    }
    // 低位先产生→res 是逆序的，最后整体翻转才得答案；
    // 若逐位头插（insert 到开头）则 O(n²)，尾插+一次 reverse 是 O(n)
    reverse(res.begin(), res.end());
    return res;
}
```

## 四、代码解析

**三块结构**：

1. **对齐块**：双下标各自从末尾出发，短串耗尽后自然跳过——**不需要**把两串补成等长（补零是多余动作，暴露"没想清楚对齐本质"）。
2. **竖式块**：每轮三件事——继承进位、按位求和、拆出本位与新进位。顺序纪律：`s % 10` 与 `s / 10` 必须在同一轮内完成，进位不落盘到下一轮就是丢数据。
3. **收尾块**：逆序翻转+去前导零（乘法）；加法结果天然无前导零（除非输入带）。

**进制转换的独立纪律**：除法从**高位**向低位做（商要传给下一位），与加法从**低位**做起方向相反——两者不要混淆；余数收集顺序与产生顺序相反，最后 reverse。

**不变量视角**：加法每轮开始时，"res 已含最低 k 位的正确和（逆序），t 等于这 k 位相加的总进位"恒成立；进制转换每轮开始时，"n 始终是剩余数值的十进制串，且每一位都 < base"恒成立（这正是除法能按位进行的合法性来源）。

## 五、复杂度

- **时间**：加法 O(max(m,n))——每位恰好处理一次；乘法 O(m·n)——每一位对相乘一次；进制转换 O(位数×每轮除法长度)=O(n²/每一位缩减) 量级（笔试口径够用，优化版用万进制压位，口述加分项）。
- **空间 O(m+n)**
  - **口径说明**：结果字符串是**输出空间**（题目要求的产物）；辅助空间=进位变量与下标 O(1)（加法）/乘法的中间累加数组 O(m+n) 计辅助（它不是最终形态，还要进位规整+转字符串）。
- **口述模板**："加法双下标从末尾对齐，每轮'继承进位-求和-拆本位'，循环条件含进位通道防丢最高位；乘法 i+j 位错位累加最后统一进位；进制转换按位除 base 取余、余数逆序——全是数组模拟竖式，int 装不下就这么做。"
