# S-09｜61. 旋转链表（Rotate List）

> **卡头**：S-09｜LC61｜F1 链表族｜P2 激活池｜Medium｜C++（C 风格）
> **实证**：小米 B2-14（"链表平移，投屏写"）
> **定位**：小米实考的"链表平移"原型——闭合环+断开点计算，考的是**把旋转问题转化为模运算**。

---

## 一、题目解析

- **输入**：链表头 `head`，非负整数 `k`（0 ≤ k ≤ 2×10⁹）。
- **输出**：链表向右旋转 k 次后的头（每个节点右移 k 位，尾部绕回头部）。
- **约束确认**：k 可以远大于 n？→可以（必须取模，否则超时）；空链/单节点？→原样返回；k=0 或 k%n==0？→原样返回。
- **一句话考什么**：**k %= n 的化归** + 闭合成环再在精确位置断开。

## 二、解题思路

右旋 k 位 = 让倒数第 (k%n) 个节点成为新头。三步：①遍历求长度 n（顺便找到尾节点）；②`k %= n`，若 0 直接返回；③**尾接头闭合成环**，再从头走 `n − k − 1` 步到达断点（新尾），新头 = 断点下一节点，断点 next 置空。

```
1→2→3→4→5, k=2          （n=5, k%5=2）
闭环: 1→2→3→4→5↘
      ↑─────────↗       走 n-k-1=2 步到节点 3（新尾）
断开: 1→2→3 ×  4→5→...   新头=4 → 结果 4→5→1→2→3
```

为什么成环再断：避免"找到新尾"与"找到旧尾"分两次遍历拼接的指针纠缠——环结构下"新尾的下一个"天然就是新头，一刀两断即完成。

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (!head || !head->next) return head;
        int n = 1;
        ListNode* tail = head;
        while (tail->next) { tail = tail->next; n++; }
        k %= n;
        if (k == 0) return head;
        tail->next = head;
        ListNode* p = head;
        for (int i = 0; i < n - k - 1; i++) p = p->next;
        ListNode* newHead = p->next;
        p->next = nullptr;
        return newHead;
    }
};
```

### 3.2 教学讲解版

```cpp
class Solution {
public:
    ListNode* rotateRight(ListNode* head, int k) {
        if (!head || !head->next) return head;

        // 第一遍遍历：一石二鸟——数出长度 n，同时握住尾节点
        // （闭环操作需要尾节点，单独再找就是浪费一次遍历）
        int n = 1;
        ListNode* tail = head;
        while (tail->next) { tail = tail->next; n++; }

        // k 可达 2×10^9，不取模必超时——旋转 n 次回到原状
        k %= n;
        if (k == 0) return head;      // 整周期：原样返回（此时未动过链，零成本）

        tail->next = head;            // 闭合成环：旋转变成"选断点"问题

        // 新尾 = 从头走 n-k-1 步（倒数第 k+1 个节点）
        // 例：n=5,k=2 → 走 2 步到节点 3；其 next（4）即新头
        ListNode* p = head;
        for (int i = 0; i < n - k - 1; i++) p = p->next;

        ListNode* newHead = p->next;
        p->next = nullptr;            // 在环上精确断开——唯一的破坏性写
        return newHead;
    }
};
```

## 四、代码解析

**四块结构**：求长握尾 → 取模早退 → 闭环 → 定位断点并断开。

三条顺序纪律：①**早退必须在闭环之前**（k%n==0 时链从未被改，直接返回最干净；若先闭环再判断就得先断回去）；②`tail->next = head` 之后链处于"环"这个中间态，**必须保证后续断开路径无条件执行**（否则内存里留下自引用环=泄漏）；③断点循环用 `n-k-1` 而非 `n-k`——`p` 停在**新尾**而非新头，因为断开动作只能由尾做（尾才有 next 可置空）。

**不变量视角**：闭环后的环序列 = 原序列无限循环的骨架；任何"右旋 k"等价于"从任一定点起数 n−k 个节点作为新链"——把一个动态过程（转 k 次）化归为一次静态定位。

## 五、复杂度

- **时间 O(n)**：遍历一次数长度 + 走 n−k−1 步断点，合计 < 2n；k 取模后与 k 的原始大小无关。
- **空间 O(1)**
  - **口径说明**：辅助空间=常数个指针；全部输入节点复用（原地重排），无新节点。
- **口述模板**："O(n) 两遍扫：第一遍数长握尾，取模后闭成环，走 n−k−1 步断开；空间 O(1) 纯指针操作。"
