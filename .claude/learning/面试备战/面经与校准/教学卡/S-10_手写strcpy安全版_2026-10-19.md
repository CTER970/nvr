# S-10｜手写 strcpy 安全版

> **卡头**：S-10｜嵌入式原创（无 LC 对应）｜F2 库函数手写族｜P0（签到四件套之一）｜嵌入式基础+｜纯 C（原创轨）
> **实证**：大华 HS-050 笔试、海康 HS-078、MTK B2-39 组题（定向池库函数族 10 次之首）
> **定位**：安防链身份题——**函数契约的精确理解**：`'\0'` 拷到哪停、NULL 怎么防、返回值为什么是 `char*`。

---

## 一、题目解析

- **输入**：目标缓冲区指针 `dst`、源字符串指针 `src`（C 标准契约：两者均不可为 NULL，调用者保证 dst 空间 ≥ strlen(src)+1）。
- **输出**：返回 `dst` 原值（支持链式调用）；副作用为完整复制含结尾 `'\0'`。
- **契约三问**（原创轨的"约束确认"）：参数允许 NULL？→不允许（UB，防御用 assert）；拷到哪里停？→**连同 `'\0'` 一起拷、拷完即停**；返回什么？→dst 原值（非 src、非 NULL）。
- **一句话考什么**：赋值表达式作循环条件的 C 惯用法 + 防御性写法（工程素养信号）。

## 二、解题思路

朴素写法"先 strlen 再 for 拷贝"两遍扫描且不说，最常见的错误版是 `while (*src != '\0') *dst++ = *src++;`——它**漏拷了 `'\0'`**，目标串没有终止符，后续读取越界。

正解惯用法：把赋值整个放进循环条件——`while ((*dst++ = *src++) != '\0');`。赋值表达式的值就是被拷的那个字符：非零继续、拷到 `'\0` 时赋值结果为 0 循环自然停，**且 `'\0'` 已被拷入**。一个表达式同时完成"拷贝、推进、判断"三件事。

```
dst: [H][e][l][l][o][\0][?][?]
src: "Hello" 的副本被逐字节写入
     ↑ 每轮：*dst++ = *src++，遇 \0 赋值后条件为假退出
```

防御四要素：入口 `assert(dst && src)`；src 加 `const`；先保存 dst 原值；返回 dst 原值。

## 三、代码（两版）

### 3.1 面试清爽版

```c
#include <assert.h>

char *strcpy(char *dst, const char *src)
{
    assert(dst && src);
    char *ret = dst;
    while ((*dst++ = *src++) != '\0')
        ;
    return ret;
}
```

### 3.2 教学讲解版

```c
char *strcpy(char *dst, const char *src)
{
    // 防御入口：契约规定调用者保证非 NULL，违者属调用方 bug，
    // assert 让它在开发期当场爆炸而不是静默崩溃——这是"显式失败"哲学
    assert(dst && src);

    // 必须先存 dst 原值：循环结束后 dst 已走到末尾，
    // 直接 return dst 返回的是"串尾指针"而非串头——高频翻车点
    char *ret = dst;

    // 核心惯用法，一个表达式三件事：
    //   *dst++ = *src++  → 拷贝一个字符、双指针各前进一步
    //   赋值表达式的值 = 刚拷的字符 → 充当循环条件
    //   拷到 '\0' 时：'\0' 已写入 dst（先赋值后判断），条件为假自然退出
    // 所以终止符既不漏拷、也不会多拷
    while ((*dst++ = *src++) != '\0')
        ;

    // 返回 dst 原值：strcpy 的存在意义之一是支持链式调用
    // char buf[16];  size_t n = strlen(strcpy(buf, "hi"));
    return ret;
}
```

## 四、代码解析

**三块结构**：防御入口 → 保存返回值 → 赋值表达式循环。

两条顺序纪律：①`ret = dst` 必须在循环前（循环后 dst 已位移）；②判断 `!= '\0'` 不可拆成"循环内判断再拷"——拆开必然在终止符处多想一步，错误率最高的就是自作聪明的拆法。

**不变量视角**：循环每轮结束时，`ret..dst-1` 是已拷完的前缀、`src-1` 指向刚消费的字符——两指针步调严格同步，拷贝前缀始终等长。终止时前缀恰为整个字符串含 `'\0'`。

**高频追问**（对话层）：为什么返回 `char*` 而不是 void？→链式调用；strcpy 与 strncpy 区别？→后者按 n 截断且**不保证补 `'\0'`**（需手动）；为什么 dst 不能加 const 而 src 要加？→写目标读源，const 表达"我不会动你的源"。

## 五、复杂度

- **时间 O(n)**：n=strlen(src)，每字符恰好一次读+一次写；最坏=平均（长度确定）。
- **空间 O(1)**
  - **口径说明**：辅助空间=两个局部指针；dst/src 缓冲区属**调用者提供的输入空间**，不计入；无输出空间增量（写入目标即职责本身）。
- **口述模板**："O(n) 逐字节单遍，赋值表达式当条件，'\0' 拷完即停；辅助空间 O(1) 两个指针；防御三件套 assert/const/返回原 dst 是工程素养分。"
