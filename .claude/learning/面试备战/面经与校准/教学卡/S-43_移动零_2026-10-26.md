# S-43｜283. 移动零（Move Zeroes）

> **卡头**：S-43｜LC283｜F8 数组与矩阵族｜P2 激活池 → **10-26 数组·字符串四题首发（用户拍板启动）**｜Easy｜C++（C 风格）
> **实证**：华为 HS-008「移除元素/移动零」；总清单 S-43 原定"大厂邀约激活"，本次按四题建模型目标提前启用
> **定位**：**快慢双指针（读写分工）模板题**——`slow` 管写、`fast` 管读。这一套骨架直接贯穿：移除元素 LC27、删除有序数组重复项 LC26、压缩 LC443。学它=学四个题。

## 一、题目解析

- **输入**：整数数组 `nums`，n ≥ 1（0 ≤ nums[i] ≤ 5×10⁴ 的旧约束可忽略，值不限）。
- **输出**：**原地**修改——非零元素保持相对顺序移到前面，0 全部挪到末尾；不开新数组。
- **约束确认**（写码前 30 秒口述）：
  1. 必须原地吗？→ 是，返回 void，改的是调用方的数组。
  2. 非零元素的相对顺序要保吗？→ 要（"保持原来的相对顺序"），这排除了"交换到任意位置"的解法。
  3. 0 之外还关心值的大小吗？→ 不关心，本题只有"是 0 / 不是 0"两种身份。
- **一句话考什么**：把"筛选并前移"和"补零收尾"拆成两段写——读写双指针的**职责分离**。

## 二、解题思路

暴力想法：每遇到一个 0 就把它后面所有元素前移一位——O(n²)，n 大了直接崩。

瓶颈：0 后面的元素被反复搬运。其实每个非零元素**只需要被搬一次**——从"它现在的位置"到"它在答案里的位置"。这两个位置差就是"它前面 0 的个数"。

于是两个下标分工：

- `slow`（写指针）：**永远指向"下一个非零元素该去的位置"**——它左边全是已经就位的非零元素。
- `fast`（读指针）：逐个考察元素，是非零就搬到 `slow` 位，然后 `slow++`。

读完后 `[0, slow)` 是全部非零元素（顺序不变），`[slow, n)` 整段填 0。

```
nums = [0, 1, 0, 3, 12]          初始: slow=0, fast=0

fast=0 读到 0    → 跳过           [0, 1, 0, 3, 12]   slow 不动
fast=1 读到 1    → 写到 0 位      [1, 1, 0, 3, 12]   slow=1
fast=2 读到 0    → 跳过           [1, 1, 0, 3, 12]
fast=3 读到 3    → 写到 1 位      [1, 3, 0, 3, 12]   slow=2
fast=4 读到 12   → 写到 2 位      [1, 3, 12, 3, 12]  slow=3
读毕: [slow=3, n) 填 0           [1, 3, 12, 0, 0]   ✓
```

现场快照的读法：**`slow` 左边=已完工区，`fast` 左边=已检查区，两区之间=还没处理的 0（暂存区）**。循环任何时刻这三段划分都成立——这就是这题的不变量。

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
void moveZeroes(vector<int>& nums) {
    int slow = 0;
    for (int fast = 0; fast < (int)nums.size(); fast++) {
        if (nums[fast] != 0)
            nums[slow++] = nums[fast];
    }
    while (slow < (int)nums.size())
        nums[slow++] = 0;
}
```

### 3.2 教学讲解版

```cpp
void moveZeroes(vector<int>& nums) {
    int slow = 0;
    // 不变量：[0, slow) 内全是非零元素，且相对顺序与原数组一致
    for (int fast = 0; fast < (int)nums.size(); fast++) {
        if (nums[fast] != 0)
            nums[slow++] = nums[fast];   // 覆盖写：slow 位上可能是 0 也可能是
                                         // 已拷贝过的旧值，覆盖它们是安全的——
                                         // 因为 fast >= slow 恒成立，被覆盖的
                                         // 数据要么已入完工区，要么本来就该丢
    }
    // 尾部统一补 0：前移写法天然保序（对比 swap 写法），代价是第二趟
    while (slow < (int)nums.size())
        nums[slow++] = 0;
}
```

## 四、代码解析

**两块结构**：

1. **筛选块**（for 循环）：fast 逐个读，非零则写到 slow 位。顺序纪律：`nums[slow++] = nums[fast]` 一句里先写后自增——先放数据再让位，反过来就把未写的位置漏了。
2. **补零块**（while 循环）：把剩余段整体置 0。它必须在整个筛选完成**之后**执行；若边搬边清零，fast 还没读到的位置会被抹掉。

**不变量视角**：循环每轮开始时，`[0, slow)` = 已就位的非零前缀，`[slow, fast)` = 已跳过的 0，`[fast, n)` = 未考察。这句就是你向面试官解释代码时的主轴——说清它，代码为什么对就不证自明。

**覆盖为什么安全**（面试官爱追的点）：因为 `fast ≥ slow` 恒成立，被覆盖的位置只有两种情况——原值是 0（该丢）、原值已被拷到完工区（旧副本该丢）。不存在"覆盖了还没读的数据"。

## 五、复杂度

- **时间 O(n)**：fast 走一遍、补零走一遍，共两次线性扫描；没有最坏/平均差异。
- **空间 O(1)**（口径：**辅助空间**；输出即输入——原地修改，无输出数组、无递归栈、不复制输入）。
- **口径说明**：本题返回 void、原址改输入，O(1) 指除输入外零额外分配。
- **口述模板**："读写双指针各走一遍，时间 O(n)，辅助空间 O(1)，原地完成；非零元素被搬运次数恰好一次，所以比逐个前移的 O(n²) 暴力好在这。"

## 变式迁移（学完本卡口述回答）

1. LC27 移除元素（删所有值为 val 的元素）：把 `!= 0` 换成 `!= val`，**删掉补零段**——返回 slow 即新长度。
2. LC26 删除有序数组中的重复项：判据换成 `fast==0 || nums[fast]!=nums[fast-1]`，同样保留 slow。
3. 字节实例（把 0 挪到**前面**且保序）：倒着跑双指针即可，或先反转再跑。
