# S-39｜统计单词数 / 最高频单词

> **卡头**：S-39｜嵌入式原创（无 LC 对应）｜F7 字符串·算法族｜P1｜Easy｜C++（C 风格）
> **实证**：地平线 HS-016（现场）
> **定位**：**状态机切词**的经典练习——"空格→非空格"的转移就是一台两状态自动机；与 S-13 atoi/S-27 按键消抖同一思维family。

---

## 一、题目解析

- **输入**：一行文本（单词以空格分隔，可能含连续空格/前导尾随空格）。
- **输出**：单词个数；或再进阶——出现频率最高的单词。
- **约束确认**：连续空格？→当一个；标点属于单词吗？→约定即可（口述声明）；空输入？→0 个。
- **一句话考什么**：**转移边沿检测**（从"空格态"进入"字符态"的瞬间=新单词开始）——比"逐字符判断"高一个抽象层。

## 二、解题思路

不逐字符问"这是不是单词的一部分"，而是维护**当前状态**（在词内/在词外）：

```
状态机:  [词外] --遇非空格→ 计数+1, 进入 → [词内]
         [词外] --遇空格→ 留在 [词外]
         [词内] --遇非空格→ 留在 [词内]（继续当前词）
         [词内] --遇空格→ 回到 [词外]

关键只有一条边: 词外 →(非空格)→ 词内 的【进入瞬间】才计数
"  hello   world " 的进入瞬间只有 2 次 → 答案 2
```

进阶（最高频）：切出词后查频率表——嵌入式做法是"排序后的单词数组线性扫最大连续段"（O(n log n) 无哈希）；或简化字符集用桶。

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
int countWords(const char *s)
{
    int count = 0;
    int inWord = 0;
    for (; *s; s++) {
        if (*s == ' ' || *s == '\t') {
            inWord = 0;
        } else if (!inWord) {
            inWord = 1;
            count++;
        }
    }
    return count;
}
```

### 3.2 教学讲解版

```cpp
int countWords(const char *s)
{
    int count = 0;
    int inWord = 0;     // 状态变量：0=词外，1=词内——整台状态机的全部状态

    for (; *s; s++) {
        if (*s == ' ' || *s == '\t') {
            inWord = 0;             // 分隔符 → 无条件回词外态
        } else if (!inWord) {
            // 唯一有动作的转移边：词外 → 词内 的【进入沿】。
            // 连续非空格字符只走 else 分支（已 inWord，什么都不做）——
            // 连续空格只把 0 变 0——两种"连续"都被状态天然折叠
            inWord = 1;
            count++;
        }
    }
    return count;
}
```

## 四、代码解析

**单循环 + 状态变量结构**：全部逻辑压缩在"当前字符 + 当前状态 → 动作"的二维表里。

设计要点：**动作只挂在转移沿上**（进入词内才 count++），而非挂在"处于词内"上——后者会把每个字符都数一遍。这就是边沿触发 vs 电平触发的区别，嵌入式工程师的母语。

**不变量视角**：任意时刻 count = "已发生进入沿的次数" = 已开始的不同单词数——扫描结束即答案，与空格的分布形态无关（前导/尾随/连续全被状态吸收）。

**追问预案**（对话层）：如何同时取最长词？→进入沿记起点，离开沿（词内遇空格）算长度；如何取最高频？→切词存数组+排序+最大连续段（口述）。

## 五、复杂度

- **时间 O(n)**：单遍扫描每字符一次分类；进阶版加排序 O(w log w)（w=词数）。
- **空间 O(1)**
  - **口径说明**：辅助空间=两个 int（count/inWord）；进阶版的单词数组属**输出空间**（结果本身），按口径惯例不计入辅助；哈希表版则需 O(不同词数)。
- **口述模板**："两状态自动机单遍 O(n)：只有'词外遇非空格'这条进入沿才计数——连续空格和词内字符都被状态折叠，空间就两个变量。"
