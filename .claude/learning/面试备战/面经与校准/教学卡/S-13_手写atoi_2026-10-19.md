# S-13｜手写 atoi（状态机雏形）

> **卡头**：S-13｜嵌入式原创（LC8 为其强化版）｜F2 库函数手写族｜P1｜嵌入式基础｜纯 C（原创轨）
> **实证**：CVTE HS-014（现场）
> **定位**："atoi 是状态机雏形"——跳空白、取符号、逐位累积、非数字即停，四段流水是所有解析类代码的微缩模型。

---

## 一、题目解析

- **输入**：C 字符串（标准 atoi 契约：跳过前导空白 → 可选正负号 → 连续数字 → 遇非数字截断）。
- **输出**：转换后的 int。
- **契约三问**：空串/全非数字？→返回 0；溢出？→标准 atoi 为 UB（**面试必须主动声明**并给出 clamp 方案）；"+123"？→合法；"12 3"？→返回 12（空格即截断）。
- **一句话考什么**：**分段解析的状态推进** + 溢出意识（嵌入式数据面代码的日常）。

## 二、解题思路

四个阶段严格串行，每阶段有自己的进入/退出条件——这就是状态机的骨架：

```
[跳空白] --非空白--> [取符号] --数字--> [累积] --非数字--> [结束返回]
 isspace 循环        至多一个 +/-      val = val*10 + (c-'0')
                                      （逐位左移乘十拼数）
```

累积式 `val = val*10 + (c-'0')` 是核心：数字从高位到低位到达，每来一位，已有值整体升一位（×10）再拼上新数字。

溢出判断（加分项）：在乘之前检查 `val > (INT_MAX - digit) / 10`——用"逆运算"避免先算后判时的中间溢出。负数侧对称处理（标准 clamp：正溢出返回 INT_MAX、负溢出 INT_MIN）。

## 三、代码（两版）

### 3.1 面试清爽版

```c
#include <assert.h>
#include <ctype.h>
#include <limits.h>

int my_atoi(const char *s)
{
    assert(s);
    while (isspace((unsigned char)*s)) s++;
    int sign = 1;
    if (*s == '+' || *s == '-') {
        if (*s == '-') sign = -1;
        s++;
    }
    int val = 0;
    while (isdigit((unsigned char)*s)) {
        int digit = *s - '0';
        if (val > (INT_MAX - digit) / 10)
            return sign == 1 ? INT_MAX : INT_MIN;
        val = val * 10 + digit;
        s++;
    }
    return sign * val;
}
```

### 3.2 教学讲解版

```c
int my_atoi(const char *s)
{
    assert(s);

    // 阶段一：跳过前导空白（isspace 含空格/\t/\n/\r/\v/\f）
    // 传 unsigned char 是 ctype 家族的标准防御：负索引 UB
    while (isspace((unsigned char)*s)) s++;

    // 阶段二：符号至多一个。"12+3" 中的 + 属阶段四（截断），不走这里
    int sign = 1;
    if (*s == '+' || *s == '-') {
        if (*s == '-') sign = -1;
        s++;
    }

    int val = 0;
    while (isdigit((unsigned char)*s)) {
        int digit = *s - '0';   // 数字字符到数值：减 '0'（ASCII 连续性）

        // 溢出前置检查：若再做一次 val*10+digit 就超界，立即截断。
        // 变形自 val*10 > INT_MAX-digit ——先除后比，避免左边先乘爆
        if (val > (INT_MAX - digit) / 10)
            return sign == 1 ? INT_MAX : INT_MIN;   // clamp 而非 UB

        // 累积：每来一位，旧值整体 ×10 腾出个位，拼入新数字
        val = val * 10 + digit;
        s++;
    }
    // 阶段四：遇非数字自然退出，"123abc" → 123；全非数字 → 0
    return sign * val;
}
```

## 四、代码解析

**四阶段结构**，每段一个循环/分支，**顺序不可交换**：空白必须在符号前（"  -5" 合法而 "-  5" 截断为 0）；符号必须在数字前（"+-3" 截断为 0，第二个 − 走到阶段四）。

溢出检查的数学：合法当且仅当 `val*10 + digit ≤ INT_MAX`，逆推得 `val ≤ (INT_MAX - digit)/10`——整数除法向下取整天然保守，不会漏判。**先检查后累积**的顺序是铁律，反了就是"用溢出值检测溢出"。

**不变量视角**：进入第 k 轮累积时，`val` 等于已消费数字串的数值且 ≤ INT_MAX——每轮维持，退出时仍成立，clamp 分支是其边界延伸。

**高频追问**（对话层）：为什么不用 `strtol`？→strtol 自带 errno 溢出报告，工程首选；手写版考的是无库环境能力（嵌入式-bootloader 场景）。

## 五、复杂度

- **时间 O(n)**：单遍扫描，每字符一次分类+至多一次累积；最坏=平均。
- **空间 O(1)**
  - **口径说明**：辅助空间=常数变量（val/sign/digit）；无递归栈（迭代状态机 vs 递归下降——后者要 O(n) 栈，这是"循环状态机"的胜利）。
- **口述模板**："单遍 O(n)：跳空白、取一个符号、逐位 ×10 累积、非数字截断；溢出用 (INT_MAX-digit)/10 前置判断并 clamp——标准 atoi 溢出是 UB，工程上该用 strtol。"
