# S-47｜232. 用栈实现队列

> **卡头**：S-47｜LC232｜F9 栈与队列族｜P0 第四批｜Easy｜C++（C 风格）
> **实证**：地平线 HS-015（现场）、理想 ST-07（06 表登记原题）
> **定位**：**双栈倒序**思想——in 栈只进、out 栈只出，倒灌时机是全部考点；"用旧结构造新结构"是嵌入式资源思维的缩影。

---

## 一、题目解析

- **输入**：操作序列 push(x) / pop() / peek() / empty()（只准用两个栈）。
- **输出**：队列语义（FIFO）的正确行为；均摊复杂度要求（进阶 O(1)）。
- **约束确认**：pop/peek 作用于空队列？→题目保证不发生；栈可否用数组自实现？→口述声明即可（LC 直接用 stack 容器）。
- **一句话考什么**：**负负得正**——栈倒一次序，两个栈倒两次回到原序。

## 二、解题思路

一个栈做不到 FIFO（它天生 LIFO）。两个栈分工：`in` 收新元素（保持到达序），`out` 供弹出。**当 out 为空且需要弹出时，把 in 全部倒灌进 out**——元素经两次 LIFO，恢复 FIFO 序。

关键时机选择："out 空才倒"而不是"每次 pop 都倒"：倒灌后 out 里的顺序已就绪可连续弹出；若 out 非空还倒，新来的会压在旧元素**下面**破坏顺序。

```
push 1,2,3 → in: [1,2,3](顶3)   out: []
pop → 倒灌: out: [1,2,3](顶1)  in: []  → 弹出 1 ✓
push 4   → in: [4]              out: [2,3](顶2)  ← 各司其职
pop → out 非空直接弹 2；pop → 3；pop → out 空,倒灌 → 4
```

**均摊 O(1)**：每个元素一生恰好经历"进 in 一次、倒灌一次、弹出一次"——三次基本操作，除以 n 次弹出 = 常数。

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
class MyQueue {
    stack<int> in, out;

    void shift() {
        if (!out.empty()) return;
        while (!in.empty()) {
            out.push(in.top());
            in.pop();
        }
    }
public:
    void push(int x) { in.push(x); }

    int pop() {
        shift();
        int v = out.top();
        out.pop();
        return v;
    }

    int peek() {
        shift();
        return out.top();
    }

    bool empty() { return in.empty() && out.empty(); }
};
```

### 3.2 教学讲解版

```cpp
class MyQueue {
    // 分工铁律：in 只管收（到达序），out 只管弹（出队序）——
    // 元素一旦进入 out 就永不回流（单向阀门）
    stack<int> in, out;

    // 懒倒灌：仅在"out 空且要取元素"时触发。
    // 这是均摊 O(1) 的根源——倒灌成本被摊到此后连续的 pop 上，
    // 且每元素一生只被倒一次（进 out 后再无倒灌路径）
    void shift() {
        if (!out.empty()) return;       // out 还有存货：顺序已就绪，倒不得！
        while (!in.empty()) {           //   （此时倒灌会让新元素压在旧元素下）
            out.push(in.top());
            in.pop();
        }
    }
public:
    void push(int x) { in.push(x); }    // push 永远直接进 in，零额外成本

    int pop() {
        shift();                        // 取元素前统一走这道门
        int v = out.top();
        out.pop();
        return v;
    }

    int peek() {
        shift();                        // peek 与 pop 共用倒灌逻辑
        return out.top();
    }

    bool empty() { return in.empty() && out.empty(); }  // 两栈皆空才是空
};
```

## 四、代码解析

**一阀门 + 三入口结构**：`shift()` 是唯一的倒灌点，pop/peek 都从它进——逻辑单点维护。

三条纪律：①**"out 空才倒"的卫兵**（`if (!out.empty()) return`）是正确性命门——out 非空时倒灌等于把新元素插到队首；②push 直进 in 不看 out——保持"到达序"纯净；③empty 必须查两栈——in 有待倒元素时队列非空。

**不变量视角**：任意时刻，队列的逻辑内容 = `out（自顶向下） + in（自底向上）` 的拼接——shift 只是形式转换不改变逻辑内容。

**追问预案**（对话层）：两队列实现栈？→一个主队列存全部，pop 时把前 n-1 个倒到备用队列取最后一个；均摊怎么算的？→聚合分析：n 次 push+n 次 pop 总操作 ≤ 3n。

## 五、复杂度

- **时间**：push O(1)；pop/peek **均摊 O(1)**（最坏单次 O(n)——倒灌整栈，但每元素一生至多被倒一次，n 次操作总成本 ≤ 3n）。**口径说明：均摊≠最坏**，面试要主动区分这两个口径。
- **空间 O(n)**
  - **口径说明**：两栈合计存 n 个元素——这是**容纳数据所必需的结构空间**（不算"浪费的辅助"）；对比单队列实现栈同样 O(n)，无更省方案。
- **口述模板**："双栈负负得正：in 只进 out 只出，out 空才倒灌——顺序就绪且可连弹；均摊 O(1)，因为每元素一生进 in、倒灌、弹出各一次；单次最坏 O(n)，两个口径要分清。"
