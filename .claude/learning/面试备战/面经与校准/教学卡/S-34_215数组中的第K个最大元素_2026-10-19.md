# S-34｜215. 数组中的第 K 个最大元素（Kth Largest Element）

> **卡头**：S-34｜LC215｜F6 排序查找族｜P0 第五批｜Medium｜C++（C 风格）
> **实证**：华为 B2-30（指定快速选择）｜HS-008
> **定位**：TopK 双解对照卡——小顶堆 K 容量口径 vs 快速选择只递归一侧；前者是数据流 TopK 的活接口，后者复用 S-32 partition。

---

## 一、题目解析

- **输入**：整型数组 `nums`、整数 `k`；规模 1~1e5，值域 −1e4~1e4，可能有重复；`1 ≤ k ≤ n`。
- **输出**：**升序排位后的第 k 个最大元素**（含重复计数，不是去重第 k 大）。
- **约束确认**（写码前 30 秒口述）：重复怎么算？→ 逐位计（[3,3,2] k=2 答案 3）；要 O(n) 吗？→ 快选平均 O(n)；n 巨大内存小？→ 堆解只留 K 个，海量数据/数据流场景。
- **一句话考什么**：两解法各自的复杂度口径与适用场景——能否说清"为什么快选平均 O(n)"是本题的分水岭。

## 二、解题思路

**解一（小顶堆）**：维持一个容量 K 的小顶堆——堆顶是"当前 TopK 里最小的"，新元素比堆顶大就挤掉堆顶；扫描完堆里就是全局最大的 K 个，堆顶即答案。
**解二（快速选择）**：partition 后基准归位于下标 p，即"第 p 小"。求第 k 大 = 求第 n−k 小，目标下标 `t=n-k`：p==t 直接返回；p<t 只递归右侧；p>t 只递归左侧——**另一侧整段丢弃**是平均 O(n) 的全部来源。

```
解二示例 [3,2,1,5,6,4], k=2 → t = n-k = 4（第 5 小 = 第 2 大）
partition 取 3： [2 1 | 3 | 5 6 4]  p=2 < 4 → 只递归右段 [5 6 4]
partition 取 5： [4 | 5 | 6]        p=4 == 4 → 返回 5 ✔   左段 [4] 直接丢弃
```

```
解一小顶堆（K=2）扫 [3,2,1,5,6,4]：
3→{3}  2→{2,3}  1≤堆顶2弃  5>2→挤2 {3,5}  6>3→挤3 {5,6}  4≤堆顶5弃
堆顶 5 ✔（K 个容量，堆顶 = TopK 的门槛）
```

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态）

```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        int n = nums.size(), t = n - k;
        int l = 0, r = n - 1;
        while (l < r) {
            int p = partition(nums, l, r);
            if (p == t) return nums[p];
            if (p < t)  l = p + 1;
            else        r = p - 1;
        }
        return nums[l];
    }
private:
    int partition(vector<int>& a, int l, int r) {
        int pivot = a[l], i = l, j = r;
        while (i < j) {
            while (i < j && a[j] >= pivot) j--;
            if (i < j) a[i++] = a[j];
            while (i < j && a[i] <= pivot) i++;
            if (i < j) a[j--] = a[i];
        }
        a[i] = pivot;
        return i;
    }
};
```

### 3.2 教学讲解版（快选关键决策 + 堆解对照）

```cpp
// 快速选择（主解）：复用 S-32 挖坑 partition，改为迭代定位
int findKthLargest(vector<int>& nums, int k) {
    int t = nums.size() - k;        // 第 k 大 = 升序下标 n-k（重复逐位计）
    int l = 0, r = (int)nums.size() - 1;
    while (l < r) {                 // 不再全排：定位到目标下标即停
        int p = partition(nums, l, r);
        if (p == t) return nums[p]; // 基准已在最终位 → 就是答案
        if (p < t)  l = p + 1;      // 只递归含 t 的一侧；
        else        r = p - 1;      // 另一侧与答案无关，整段不碰——
    }                               // 期望规模 n+n/2+n/4+… = 2n → O(n)
    return nums[l];                 // l==r：区间收敛到目标位
}
```

```cpp
// 小顶堆解（对照）：K 容量，堆顶=TopK 门槛；海量数据/数据流用它
int findKthLargestHeap(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> hp;  // greater = 小顶堆
    for (int x : nums) {
        if ((int)hp.size() < k) hp.push(x);   // 未满 K：照单全收
        else if (x > hp.top()) {              // 挤掉门槛才能入堆：
            hp.pop();                         // x ≤ 堆顶时它进不了 TopK，
            hp.push(x);                       // 这个比较是堆解的全部逻辑
        }
    }
    return hp.top();                          // K 个里的最小者 = 第 K 大
}
```

## 四、代码解析

**三块结构（快选）**：

1. **目标转换块**：`t = n−k` 把"第 k 大"换成升序下标语言，partition 只会讲"第 p 小"，先统一方言。
2. **定位循环块**：与二分同构——p 与 t 三比较；`l=p+1`/`r=p−1` 跨过 p（p 已判定不是答案）。迭代化免递归栈。
3. **收尾块**：`l==r` 时区间收敛到目标位，`nums[l]` 即答案。

**堆解两块**：未满 K 全收；满了比堆顶大才"pop+push"。**不变量视角**：任意时刻堆内=已扫部分的 TopK，堆顶是其最小者，扫描结束即为答案。

## 五、复杂度

- **时间**：快选**平均 O(n)**——期望 n+n/2+n/4+…=2n；**最坏 O(n²)**（partition 每次切在端点，随机基准缓解）。堆解 O(n log K)：n 个元素各一次 O(log K) 堆操作。
- **空间**：快选 O(1) 辅助（迭代版，原地 partition）；堆解 O(K) 辅助（堆本身）。
- **口径说明**：输入 n 元素不计入；快选迭代版无递归栈——递归版另报 O(log n) 期望栈深；堆的 O(K) 是**额外辅助结构**，海量场景里它恰是省内存的代价优势（不存全量）。
- **口述模板**："快选平均 O(n)、最坏 O(n²)，随机基准可避；每次只递归含目标下标的一侧，期望总代价 2n。海量数据要小顶堆：O(n log K) 时间、O(K) 空间，只留 K 个——数据流场景唯一解。"
