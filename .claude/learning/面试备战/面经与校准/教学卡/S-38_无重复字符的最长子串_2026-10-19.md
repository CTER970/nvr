# S-38｜3. 无重复字符的最长子串

> **卡头**：S-38｜LC3｜F7 字符串·算法族｜P2 激活池（大厂 Hot100）｜Medium｜C++（C 风格）
> **实证**：字节 HS-029、华为 B2-30（"无重复子串"）
> **定位**：**滑动窗口模板题**——右扩左收的窗口维护是字符串族最值钱的套路，一题通一串（最小覆盖子串/含 K 种字符子数组同模板）。

---

## 一、题目解析

- **输入**：字符串 `s`（英文字母/数字/符号/空格，0 ≤ n ≤ 5×10⁴）。
- **输出**：最长**无重复字符子串**（连续）的长度。
- **约束确认**：子串还是子序列？→**子串（连续）**——高频审题坑；字符集？→ASCII 可见字符（count[128] 定长数组够用）；空串？→0。
- **一句话考什么**：滑动窗口 + 计数数组的窗口合法性判定。

## 二、解题思路

窗口 `[l, r]` 维护"无重复"性质：r 逐步右扩纳入新字符；一旦新字符使窗口内出现重复（计数 > 1），**l 收缩到重复消失为止**——l 只进不退，整体单向 O(n)。

记录每个字符出现次数的容器选 **count[128] 定长数组**（嵌入式不引第三方库的默认解法；比哈希表省内存且无哈希开销）。

```
s = "abcabcbb"
r=0 'a': [a]bc…      len=1
r=1 'b': [ab]c…       len=2
r=2 'c': [abc]…       len=3
r=3 'a': 重复! l 移到 1 → [bca]     len=3
r=4 'b': 重复! l 移到 2 → [cab]     len=3
r=5 'c': 重复! l 移到 3 → [abc]     len=3 …
窗口像毛毛虫: 头(右)前进, 尾(左)只在重复时收缩
```

## 三、代码（两版）

### 3.1 面试清爽版

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int cnt[128] = {0};
        int best = 0;
        for (int l = 0, r = 0; r < (int)s.size(); r++) {
            cnt[(unsigned char)s[r]]++;
            while (cnt[(unsigned char)s[r]] > 1)
                cnt[(unsigned char)s[l++]]--;
            best = max(best, r - l + 1);
        }
        return best;
    }
};
```

### 3.2 教学讲解版

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        // 定长计数数组代替哈希表：ASCII 字符集 128 槽足够，
        // O(1) 访问无哈希开销——嵌入式语境的默认选择
        int cnt[128] = {0};
        int best = 0;

        // 窗口不变量：[l, r] 内任意字符计数 ≤ 1（无重复）
        for (int l = 0, r = 0; r < (int)s.size(); r++) {

            // 右端纳入：可能破坏不变量（新字符计数变 2）
            cnt[(unsigned char)s[r]]++;

            // 左端收缩直到恢复不变量：
            // l 只会移到"上一个同字符位置+1"——while 循环自动完成，
            // 无需显式记住重复字符在哪（这是计数版优于记位置版的理解点）
            while (cnt[(unsigned char)s[r]] > 1)
                cnt[(unsigned char)s[l++]]--;

            // 窗口重新合法，刷新答案——每轮 r 都结算一次，不漏任何峰值
            best = max(best, r - l + 1);
        }
        return best;
    }
};
```

## 四、代码解析

**两拍结构**：右扩（无条件）→ 左收（条件 while）→ 结算。

三条纪律：①**收缩条件盯住"刚进来的字符"** `cnt[s[r]] > 1`——重复的根源是它，l 收缩到它旧出现点之后计数自然回落；②l/r 都单调前进不回退——O(n) 的来源（每字符至多进出窗口各一次）；③结算放在收缩之后——保证结算时窗口合法。

**不变量视角**：每轮结算时 `[l, r]` 无重复且**以 r 为右端的最长**——r 走遍所有位置，答案取遍"每个右端点的最优左端"，全局最优必在其中。

**变式口述**：最小覆盖子串（LC76）=窗口条件从"无重复"换成"覆盖 t"——同构的右扩左收，不同的合法判据。

## 五、复杂度

- **时间 O(n)**：l、r 各走至多 n 步（**均摊**分析：看似双重循环，内层总执行次数 ≤ n）；最坏=平均。
- **空间 O(1)**
  - **口径说明**：cnt[128] 是**固定大小**辅助数组（与 n 无关，按字符集计），常数级；哈希表版口径为 O(字符集)——本题两者同阶。
- **口述模板**："滑动窗口 O(n)：右端无条件扩、重复时左端收缩到恢复无重复，计数用 128 定长数组代替哈希；每轮结算窗口长取最大；l/r 都不回退所以线性。"
