# S-32｜手写快速排序（partition 挖坑法）

> **卡头**：S-32｜嵌入式原创（无 LC 对应）｜F6 排序查找族｜P0 第五批｜基础+｜C++（C 风格·纯 C 数组版）
> **实证**：TP-LINK 成都 B2-20（现场手写）｜字节 B2-35（"用 C 实现"指定）
> **定位**：手写排序压轴题——挖坑法 partition 不怕丢基准值；坑位思想直通 S-34 快速选择 TopK，随机基准/三数取中是"知道最坏并会救"的展示位。

---

## 一、题目解析

- **输入**：整型数组 `arr[]`，下标区间 `[l, r]`（闭区间）。
- **输出**：**原地**升序排序。不新建数组（递归栈除外）。
- **约束确认**（写码前 30 秒口述）：要稳定？→ 快排不稳定，口述即可（换归并/冒泡求稳）；最坏何时发生？→ 已序+取首元素为基准，O(n²)；允许递归？→ 允许，但递归栈 O(log n) 要自己报出来。
- **一句话考什么**：挖坑法 partition 的填坑顺序 + "只递归含第 K 位一侧"的剪枝意识（后者是 S-34 的引子）。

## 二、解题思路

每趟选一个基准 pivot，把区间剖成"≤pivot | pivot | ≥pivot"三段，pivot 就位于最终位；再对左右两段递归。**挖坑法**：取出 pivot 后位置 i 觕一个"坑"，右指针找小填左坑、左指针找大填右坑，交替填至两指针重合，重合处即 pivot 归位。

```
[6 1 3 9 7]  取首 6 为基准，i=0 成坑：[_ 1 3 9 7]  pivot=6
R 从右找 <6 → 3 填 i=0：[3 1 _ 9 7]，j=2 成坑
L 从右找 >6 → 9 填 j=2：[3 1 9 _ 7]→ i=3 成坑
R 左移找 <6 → 无，i==j=3 重合 → pivot 归位：[3 1 6 9 7] ✔
              递归 [3 1] 与 [9 7]
```

现场快照（i=3、j=3 重合时）：坑在重合位，左侧全 ≤6、右侧全 ≥6——重合位就是 pivot 的最终位。

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态·纯 C 风格）

```cpp
int partition(int arr[], int l, int r) {
    int pivot = arr[l], i = l, j = r;
    while (i < j) {
        while (i < j && arr[j] >= pivot) j--;
        if (i < j) arr[i++] = arr[j];
        while (i < j && arr[l + 0] <= pivot) i++;   // 面试现场留痕，见 3.2 修正为 arr[i]
        if (i < j) arr[j--] = arr[i];
    }
    arr[i] = pivot;
    return i;
}
```

### 3.2 教学讲解版（关键决策注释）

```cpp
int partition(int arr[], int l, int r) {
    int pivot = arr[l], i = l, j = r;
    while (i < j) {
        while (i < j && arr[j] >= pivot) j--;
        if (i < j) arr[i++] = arr[j];   // 小于基准的数去填左坑
        while (i < j && arr[i] <= pivot) i++;
        if (i < j) arr[j--] = arr[i];   // 大于基准的数去填右坑
    }
    arr[i] = pivot;   // i==j，坑位即 pivot 归位
    return i;
}
```

## 四、代码解析

**三块结构**：

1. **取基准块**：取首元素并存入 pivot——数组里"挖走"了一个值，这就是"坑"的由来。取首简单但**已序输入退化 O(n²)**——递归树退化成链；`pivot = arr[l + rand()%(r-l+1)]`（与 arr[l] 交换后同流程）或三数取中可缓解。
2. **填坑块**：两指针交替填坑、坑随之交替——`arr[l+0]` 是典型手误（应为 `arr[i]`）。
3. **收尾块**：`if (l >= r) return;` 处理空/单元素段。

**不变量视角**：partition 结束时基准值位于其最终排序位置（左侧全 ≤、右侧全 ≥）——每轮至少一个元素"归位"，这是快排正确性与终止性的根基。

## 五、复杂度

- **时间 O(n log n) 平均**：每层 partition 走 O(n)、递归树平均高 log n；**最坏 O(n²)**：已序+首元素基准退化成链式递归树。
- **空间 O(log n) 平均 / O(n) 最坏**（口径：辅助空间=递归栈）：原地交换零辅助数组；但递归调用栈深度=递归树高，必须自报，不算 O(1)。
- **口径说明**：输入 n 元素不计入；无独立输出空间。
- **口述模板**："平均 O(n log n)，partition 每趟 O(n)、树高平均 log n；最坏 O(n²)——已序数组取首元素基准就退化，现场用随机基准或三数取中缓解；辅助空间只有递归栈，平均 O(log n)、最坏 O(n)；不稳定。"
