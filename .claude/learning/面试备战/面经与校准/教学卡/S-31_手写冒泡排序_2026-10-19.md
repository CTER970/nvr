# S-31｜手写冒泡排序（带提前退出 flag）

> **卡头**：S-31｜嵌入式原创（无 LC 对应）｜F6 排序查找族｜P0 第五批｜基础｜C++（C 风格·纯 C 数组版）
> **实证**：小米 HS-076（现场手写）｜MTK HS-083/132
> **定位**：手写排序第一课——"相邻交换 + 边界收缩"是快排 partition、链表冒泡变体的共同母型；提前退出 flag 是嵌入式中断轮询场景的常见小技巧。

---

## 一、题目解析

- **输入**：整型数组 `arr[]`，长度 `n`（n 可为 0 或 1）。
- **输出**：**原地**升序排序——只许 O(1) 辅助变量，不新建数组。
- **约束确认**（写码前 30 秒口述）：数组为空/单元素？→ 直接返回；要求稳定？→ 冒泡相邻交换天然稳定（相等不换）；要不要提前退出？→ 要，已序输入从 O(n²) 降到 O(n)。
- **一句话考什么**：内层界限随轮收缩 `n-1-i` 的边界推导 + flag 无交换即序的提前终止。

## 二、解题思路

每轮从左到右比较**相邻**两元素，逆序则交换——一轮结束，当前未排序段的最大值"冒泡"到段尾。第 i 轮后，末尾 i 个元素已就位，下一轮内层只需走到 `n-1-i`。若某一整轮**一次交换都没发生**，说明全序，立刻退出。

```
第 0 轮 (i=0, j: 0 → n-2)：[5 1 4 2 8] → [1 4 2 5 8]   最大 8 就位 ┐
第 1 轮 (i=1, j: 0 → n-3)：[1 4 2 5 8] → [1 2 4 5 8]   5   就位 ├ 尾部有序区
第 2 轮 (i=2, j: 0 → n-4)：[1 2 4 5 8] → 无交换 → flag 未置位 ──→ 提前退出 ✔
```

现场快照（第 1 轮 j=1 时）：`[1 | 4 2 | 5 8]`——j 左侧相对有序，j 处 4>2 将交换，尾部 8 已就位不再碰。

## 三、代码（两版）

### 3.1 面试清爽版（现场手写形态·纯 C 风格）

```cpp
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int t = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;
    }
}
```

### 3.2 教学讲解版（关键决策注释）

```cpp
void bubbleSort(int arr[], int n) {
    // 外层 n-1 轮即可：n-1 个元素就位后最后一个必然就位；
    // n<=1 时 n-1<=0，循环体不执行，空/单元素边界自动覆盖，无需特判
    for (int i = 0; i < n - 1; i++) {
        // flag 每轮重置——"无交换"只对本轮有意义；
        // 已序数组第 0 轮就无交换，总代价降到 O(n)，这是 flag 的全部价值
        int swapped = 0;
        // 界限 n-1-i：第 i 轮开始前，末尾 i 个元素已是最终位（不变量），
        // 再比较它们是白费；同时保证 j+1 永不越界（最大 j = n-2-i）
        for (int j = 0; j < n - 1 - i; j++) {
            // 严格 > 而非 >=：相等不交换 → 稳定排序（口述加分点）
            if (arr[j] > arr[j + 1]) {
                int t = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = t;
                swapped = 1;
            }
        }
        // 本轮零交换 ⇒ 相邻全序 ⇒ 整体有序，提前终止；
        // 放在轮末而非轮中——必须看完整轮才能下"无交换"结论
        if (!swapped) break;
    }
}
```

## 四、代码解析

**三块结构**：

1. **外层块**：控制轮数与有序区大小。`n-1` 轮封顶（n-1 个大值就位后最小值被挤到首位）；i 同时是"末尾已就位元素个数"的计数器。
2. **内层块**（界限收缩）：`j < n-1-i` 是本卡核心——比较范围**随有序区从尾部蚕食而缩短**，且天然防 `j+1` 越界。顺序纪律：先比后换、swap 三步不能漏中间暂存。
3. **退出块**：`swapped` 必须每轮开头清零（放循环内），判退出必须在整轮结束之后（轮中退出会误杀"前半无交换"的乱序数组）。

**不变量视角**：每轮开始时，`arr[n-i..n-1]` 是已就位的最终序且均 ≥ 前段所有元素；循环结束（无交换提前退出）时该命题给出整体有序。

## 五、复杂度

- **时间 O(n²) 最坏/平均**：比较次数 ∑(n-1-i) ≈ n²/2，逆序输入全交换。**最好 O(n)**：已序输入第 0 轮零交换即退（flag 的贡献）；平均仍 O(n²)——随机数据每轮大概率仍有交换。
- **空间 O(1)**（口径：辅助空间）：仅 i/j/swapped/t 四个标量；原地交换，不新建数组，无递归栈。
- **口径说明**：输入数组 n 个元素属**输入空间，不计入**；本算法无独立输出（原地上写）。
- **口述模板**："最坏和平均 O(n²)——相邻比较对数约 n²/2；最好 O(n)，靠提前退出 flag 在已序时一轮收工；辅助空间 O(1)，原地交换，稳定排序——严格大于才换。"
