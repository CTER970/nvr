## B. 生成指令（AI 逐段规范）

| 段 | 生成规范 | 硬性规则 |
|---|---|---|
| 卡头 | 从总清单 §三/§四/§8.2 取 S 卡号、族、批次、实证公司；语言按 §C-1 | S 卡号必须与总清单一致，不得自造 |
| 一、题目解析 | 输入/输出照题面**抄全约束**（规模、值域、可否为空）；约束确认=写码前应口述的 2-3 问自答 | 不允许省略约束——边界意识从读题开始 |
| 二、解题思路 | 先自然语言后图；图必须覆盖：**输入形态→核心现场→循环/递归步骤→收尾**四层；配"某一轮进行到一半的现场快照" | **每卡必配一图**（SVG widget 直出 + 卡内文字版示意）；图要能当白板画 |
| 三、代码 | **两版并排**：①面试清爽版=现场手写形态（只留必要注释）；②教学讲解版=关键决策注释（数据结构选择理由/顺序不可换的理由/整体接上的合法性/必须保持的状态） | 禁止逐行流水注释（"tail 前进"这类复述禁用——要写"如何恢复不变量"）；清爽版必须像面试现场写出的；语言按 §C-1，原创轨纯 C 禁 STL |
| 四、代码解析 | 按"块"讲（初始化/主循环/收尾…）；每块含顺序纪律（哪行必须在前+为什么） | **必含"不变量视角"**——面试官最认的讲法 |
| 五、复杂度 | 时间=最坏+平均差异（若不同）；空间**必须分口径**：辅助空间/输出空间/递归栈/是否复用输入节点；递归计入栈、返回新数组计输出、哈希计入额外、图计入 visited+队列；原地算法不得写"没有新数组所以 O(1)" | 必附口径说明行+口述模板（面试 15 秒版） |

**生成流程**：收到题目 → 查总清单定位 S 卡号（没有则先报卡号再生成）→ 按 A 骨架五段生成 → 图以 SVG widget 直出 → 卡写入 `教学卡/{S 卡号}_{题名}_{日期}.md`。

## C. 策略（四条）

1. **语言分轨**（10-19 11:06 拍板）：LC 原题轨=C++（"C 风格 C++"：裸指针为主/nullptr/引用可用/克制 STL；嵌入式面试官面前主动声明可纯 C）；嵌入式原创轨=纯 C（strcpy/memmove/环形缓冲等考的就是 C 契约，STL 失分）。
2. **图先行**：思路段的图是卡片灵魂——先画图后写码，图=白板预演；图的四层结构（输入/现场/步骤/收尾）=闭卷写码的提纲。
3. **验收四步**（对话层执行，不入卡）：闭卷复现（≤10 分钟）→边界用例→复杂度口述→变式迁移口述；AI 辅助学习后同样闭卷，不许"看懂即过"。
4. **错题与复做**（对话层执行，不入卡）：**固定的是复测机制，不固定所有题的间隔**——1/3/7 天只是默认计划，按表现分派：

   | 表现 | 后续安排 |
   |---|---|
   | 无提示通过且变式通过 | 1 次延迟复测即可 |
   | 原题会、变式不会 | 优先安排变式复测 |
   | 代码正确但解释不清 | 先做口述复测 |
   | 多次指针/边界错误 | 先画图+走小样例，再复写 |
   | 看答案后仍不能复现 | 当天立即重教，不进普通复测 |

   难题可加密节奏（当天短复现/次日完整/三日变式）；卡壳登记（卡点/关键转折/复做日期）与翻车点记工作日志的惯例不变。
