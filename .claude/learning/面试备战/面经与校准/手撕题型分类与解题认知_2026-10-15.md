# 手撕题型分类与解题认知(2026-10-15)

## 一、本文定位与用法

- **数据源**:`手撕面经样本库_2026-10-15.md`(134 份有效样本 / 116 份含手撕 / 576 个题目实例)+ `手撕考题频次统计_2026-10-15.md`(16 统计大类 + 全量题目频次)。
- **为什么不能直接按统计大类学习**:统计 16 大类是采集口径,把「考察载体」(链表/字符串/数组)、「考察技能」(排序/位运算/DP)和「岗位特化」(宏/环形缓冲/C++类)混在一层。学习要按**解题套路是否同族**重组:同一族内的题,会一道母题就能推一片变式。

## 三、T0 主战场六族——解题大体认知

### 族 1. 链表族(50 样本/43.1%,手撕第一大户)

**考什么**:指针操控能力 + 断链防护 + 边界意识。嵌入式 C 岗最直接的「指针功底试纸」。单链表反转 26 次为全部手撕题之王——约每 5 个含手撕的样本出现 1 次。

**解题大体认知(五条)**:

1. **画图先行**。任何链表题先在纸上画 3-4 个节点,标出 `prev / cur / next`(或 dummy)三个指针此刻各指向谁,再动手写代码。链表题翻车九成来自「指针位置还没画清就开写」。
2. **改指针前先存后继**。`next = cur->next;` 永远写在改动之前——先改 `cur->next = prev` 就再也找不回后半截链(断链)。
3. **dummy 虚拟头节点(哨兵)**。凡是「头节点可能被删/被换」的题(删除节点、合并、区间反转),先造 `dummy`,`dummy->next = head`,循环里用前驱指针走,最后返回 `dummy->next`——头节点的所有特判一笔勾销。
4. **快慢指针垄断半壁高频**。判环:fast 每次走 2、slow 走 1,相遇即有环;找中点:同法,fast 到尾时 slow 在中点;倒数第 K:fast 先走 K 步再同速;环入口:相遇后把一个指针放回表头,两指针同速前进,再相遇处即入口(依据:头到入口距离 a = 相遇点到入口绕回距离 c,面试要能当场推)。
5. **现场写迭代,递归要能口述**。迭代版好画图好验证、无爆栈风险,是现场首选;反转的递归版(先递归到底,回程逐层改指)是高频追问,要能白板说清。

**易错点**:空表/单节点不判;反转最后忘记 `return prev`(新表头);合并有序链表漏了「循环结束后把未耗尽的一段直接接上」;环入口只会背结论推不出 a=c。

**母题清单(按此顺序精写,覆盖约九成变式)**:单链表反转(迭代+递归)→ 判环 + 环入口 → 合并两个有序链表 → 删除倒数第 K(快慢)→ 两链表交点(长度差对齐后同速走)→ O(1) 删除给定节点(把后继拷进来再删后继,并说清尾节点不适用)→ 区间反转(dummy + 四指针)。

### 族 2. 字符串·库函数手写族(strcpy 10 + memmove 9 + 杂项 ≈30 样本)

**考什么**:不是算法,是**函数契约的精确理解**——`'\0'` 在哪结束、NULL 怎么防、内存重叠怎么办、返回值为什么是 `char *`。这是嵌入式岗的身份题:写得出 memmove 重叠处理 = 懂内存模型。

**解题大体认知(五条)**:

1. **动手前先背契约**。每个函数三问:参数允许 NULL 吗?拷到哪里停?返回什么?——strcpy 返回 dest(支持链式调用);memcpy 不看 `'\0'` 只认长度 n;strcmp 返回差值不是固定 ±1。
2. **strcpy 四要素**:入口 `assert(dst && src)`;循环 `while ((*dst++ = *src++) != '\0');`(赋值表达式的值就是被拷字符,循环条件天然把 `'\0'` 也拷进去且到此停);指针先存 dest 原值;最后 `return` dest 原值。src 加 const 修饰。
3. **memcpy → memmove 的重叠分界**:dst 落在 `(src, src+n)` 区间内时正向拷会踩掉还没读的源字节 → 必须从尾部反向拷。memmove 就是「先判方向、再选路线」的 memcpy。实现里 `void *` 不能直接解引用,逐字节转 `unsigned char *` 操作。
4. **atoi 是状态机雏形**:跳过空白 → 取正负号 → 逐位 `val = val*10 + (c-'0')`,遇非数字即停;进阶要提溢出判断。
5. **防御性写法是加分信号**:assert/判 NULL/const/返回值,写全 = 「有工程素养」,面试官看得见。

**易错点**:memcpy 无脑正向拷不判重叠(这恰是考点本体);strcpy 循环条件写成 `*src != '\0'` 再单独拷 `'\0'`(可行但易错,推荐赋值表达式版);strcmp 返回值写死 1/-1;忘记返回 dest。

**母题清单**:strcpy(安全版)→ memmove(重叠双向)→ strlen / strcmp → atoi → memset(注意按字节赋值,初始化为 0 之外的值时 int 数组会得到 0x01010101 这类结果,能讲出这一点是加分)。

### 族 3. 位运算与字节序族(24 样本/20.7%)

**考什么**:对二进制位的精确操控——它就是「寄存器读改写」的直接预演,嵌入式岗身份题,而且题都很短,性价比极高。

**解题大体认知(四条)**:

1. **三板斧必成肌肉记忆**:置位 `x |= (1u << n)`;清零 `x &= ~(1u << n)`;翻转 `x ^= (1u << n)`;取第 n 位 `(x >> n) & 1`。清掉某段位再写入新值 = 先 `&= ~mask` 再 `|= (val << shift)`——这就是寄存器 read-modify-write 标准姿势。
2. **高频四性质**:(a) 判 2 的整数次幂:`n > 0 && (n & (n-1)) == 0`(n-1 会借位消掉唯一的 1;`n > 0` 必须带,否则 0 会误判);(b) 数 1 的个数:循环 `n &= (n - 1)` 每次消掉最低位的 1,循环次数即个数(比逐位右移快);(c) 异或性质 `a^a = 0, a^0 = a` → 找落单的数(全员异或)、不用临时变量交换;(d) `x & 1` 判奇偶,`x >> 1` 除 2。
3. **大小端两解**:union 法——`union { uint32_t i; uint8_t b[4]; }` 看 `b[0]` 是不是 i 的最低字节;指针法——`*(uint8_t *)&i`。手写 htonl/字节序转换 = 移位拼字节(`(x>>24)&0xFF` 逐个取出)。
4. **字面量与 UB**:掩码用 `1u` 防符号位;移位量大于等于类型宽度是未定义行为,面试提一句就是亮点。

**易错点**:置位写成加法、清零忘对 mask 取反;大小端只会说「架构差异」给不出判别代码;`n & (n-1)` 判 2 的幂漏 `n > 0`。

**母题清单**:置位/清零/翻转/取位 → 大小端判断(两法)+ 手写 32 位字节序转换 → 数 1 的个数(两法)→ 判 2 的幂 → 异或找落单数 → 不用临时变量交换(能讲清何时安全)。

### 族 4. C语言基本功族——宏/对齐/指针(23 样本/19.8%)

**考什么**:预处理器的「文本替换」本质 + 内存对齐规则 + 指针与数组辨析。和族 3 一样题小量大、纯背诵+理解,投入产出比极高。

**解题大体认知(五条)**:

1. **宏 = 纯文本替换,一切坑都源于替换后优先级变了**。所以安全宏 = 每个参数加括号 + 整体加括号:`#define MAX(a,b) ((a) > (b) ? (a) : (b))`。副作用坑要会讲:`MAX(i++, j)` 里 `i++` 被求值两次——追问时给 GCC `typeof` 语句表达式安全版。
2. **多语句宏包 `do { } while(0)`**:防 else 悬挂;宏定义末尾不写分号(分号由使用者写)。
3. **offsetof / container_of**:`(size_t)&((type *)0)->member`——在 0 地址上「假想」一个结构体,取其成员地址,值即成员偏移;container_of = 成员地址减偏移反推宿主对象地址(Linux 链表内核写法,讲得出=读过内核风格代码)。
4. **sizeof 手算三规则**:每个成员的偏移是其「对齐数」(自身大小与 pack 值取小)的整数倍,不足补空;总大小补齐为最大成员对齐数的整数倍;`#pragma pack(n)` 后对齐数取小。位域紧凑设计是变式。
5. **绝对地址写寄存器**:`*(volatile uint32_t *)0x40021018 = val`——volatile 防优化必带,能顺带讲「为什么 ISR 共享变量也要 volatile」。

**易错点**:宏只给整体括号漏参数括号(或反之);offsetof 推不出 container_of;对齐题忘了「总大小补齐到最大对齐数整数倍」这最后一步;寄存器指针忘 volatile。

**母题清单**:MAX/MIN 宏 + 副作用 → SWAP 宏(加法版溢出坑/异或版同变量坑)→ offsetof + container_of → 结构体 sizeof 手算(含 pack 变式)→ 绝对地址 + volatile。

### 族 5. 嵌入式特色族——环形缓冲/状态机/滤波(27 样本/23.3%)

**考什么**:资源受限下的工程实现力——不让 malloc、不用浮点、栈很小、可能被中断打断。这是嵌入式岗区别于纯软件岗的**主场题**,与 NVR 项目的 frame_grabber「单槽最新帧」是同一种设计思想,天然面试素材。

**解题大体认知(五条)**:

1. **环形缓冲区(11 次,本族之王,也是全部手撕题第 3 名)**:定长数组 + 读写下标 head/tail + `% N` 取模回绕;**满/空判别两法**——(a) 维护一个计数 count;(b) 缓冲区永远浪费一格,`(tail+1) % N == head` 为满、`tail == head` 为空。两法都能写、能互说优缺点(计数多一个变量但利用率满格;浪费一格少一次共享变量访问)。追问「单生产者单消费者怎么免锁」:head 只被消费者写、tail 只被生产者写,各自 volatile,可做到无锁(SPSC);多对多就回退加锁。
2. **状态机**:「当前状态 + 事件 → 次态 + 动作」。基础版 = enum 状态 + while(1) + switch 转移;升级版 = **函数指针表**(状态到处理函数一一映射,查表分发,加状态不改 switch)——按键消抖 20ms、识别字符串 "embedded" 都是经典题面。
3. **滑动平均/窗口滤波**:环形缓冲 + 游标 + 新值替旧值,增量更新和(减旧加新)避免每轮重算;禁动态内存、除法避浮点(定标/移位)是隐形要求。
4. **socket 手写 TCP echo**:五步 `socket → bind → listen → accept → recv/send`,echo = 收到什么回什么;能不查书写出最小版即过关,追问点=字节流粘包怎么处理。
5. **一切本族题的隐形前提**:静态分配、不依赖标准库之外的设施、可重入。写代码时主动说一句「这里不用 malloc,用静态数组」就是嵌入式身份的信号。

**易错点**:环形缓冲满空判别混淆(两法混用);`% N` 忘在回绕处;状态机忘了「事件驱动下每态只处理自己该处理的」;SPSC 免锁条件说成「任何情况都能免锁」。

**母题清单**:环形缓冲区(两法满空 + SPSC 免锁口述)→ 按键消抖状态机(含函数指针表版)→ TCP echo server → 滑动平均滤波。

### 族 6. 排序与查找族(24 样本/20.7%)

**考什么**:必背代码的熟练度,嵌入式笔试面试的签到题。冒泡(9)与快排(8)两极,堆/归并(各 3)次之。

**解题大体认知(六条)**:

1. **冒泡是嵌入式签到题之王**:相邻比较交换,每轮沉底一个最大值;带提前退出 flag(本轮无交换即已序)是标配加分。会冒泡 ≈ 会选择(每轮选最小放前面)和插入(新牌往前插),三者同属 O(N²) 家族,只是「交换谁/选谁」的差别。
2. **快排 = partition + 分治递归**:partition 挖坑法或前后指针法把「小于基准的挪到左边」;递归终止 `left >= right`;平均 O(N log N)、最坏 O(N²)(已序 + 取首元素为基准),要能口述原因和缓解(随机取基准/三数取中)。
3. **归并 = 分治 + 合并两段有序**,合并逻辑与「合并两个有序链表」同款;代价是 O(N) 辅助数组。快排 vs 归并的「空间/稳定性」对比是高频追问。
4. **堆 = 数组下标公式**:节点 i 的孩子是 `2i+1 / 2i+2`;自底向上建堆 O(N);「维护 K 个元素的小顶堆」解 TopK(求第 K 大用小顶堆存前 K 大,堆顶即答案),避免全排序。
5. **二分查找 = 闭区间不变量**:`while (l <= r)`,命中返回,否则 `r = mid-1` / `l = mid+1`;写之前先声明自己维护的区间含义,变式(左界/右界)只是区间收紧规则不同。两有序数组中位数是 hard 变式,T2 级。
6. **快速选择 = 只递归包含第 K 位的那一侧**,平均 O(N) 求第 K 大——TopK 的另一解,与堆解互为对照,面试常要求两个都说。

**易错点**:二分开区间闭区间混写死循环;快排 partition 边界(off-by-one);堆的下标从 0 还是 1 起算前后不一致;冒泡内层循环界限写死 `n-1` 而不是随轮收缩。

**母题清单**:冒泡(带 flag)→ 快排(partition + 最坏复杂度口述)→ 二分查找(闭区间版)→ TopK(小顶堆 + 快速选择两解)→ 归并/堆排序(能写能比)。

## 四、T1 要会五族——解题大体认知

### 族 7. 字符串·算法族(翻转/回文/子串/分割,≈30 样本)

**考什么**:双指针与计数两大套路在字符数组上的应用。与族 2 的区别:族 2 考契约,族 7 考套路。

**解题认知(五条)**:① C 字符串 = 字符数组 + `'\0'`,一切下标操作都可用指针算术改写;② 翻转类 = 首尾双指针向中间交换;单词级翻转 = 「先整体翻、再逐词翻」两遍法;③ 统计/去重类 = `count[128/256]` 定长数组当哈希(嵌入式不引第三方库的默认解);④ 子串/窗口类 = 滑动窗口右扩左收 + 计数判合法(最长无重复字符子串是模板题);⑤ 题面写「不用库函数」= 连 strlen 都自己写循环。**易错**:单词翻转漏尾词;滑动窗口收缩条件错;IP 转整数漏「每段 0-255 且无前导零」校验。**母题**:字符串整体翻转 → 单词翻转 → 回文判断 → 最长无重复字符子串 → atoi(与族 2 共享)→ IP 与整数互转。

### 族 8. 数组与矩阵族(30 样本/25.9%)

**考什么**:下标边界感 + 原地操作意识。多为笔试和低轮次,套路密度高。

**解题认知(五条)**:① 先写「循环不变量」——用一句话定义哪些区间已处理/未处理(如 `[0..slow)` 是已保留的合法区),代码自然写对;② 原地删除/去重/移零 = 快慢双指针,慢针收结果;③ 两数之和类 = 哈希一遍过,有序则首尾夹逼;④ 矩阵题 = 下标变换,旋转 90° 最稳的写法是「先转置再每行反转」;顺时针打印 = 四个边界变量逐层收缩;⑤ 题面出现「O(N) 时间 / O(1) 空间」的限制词,本身就是提示:双指针 / 原地交换 / 计数数组三选一。**易错**:边界变量收缩后忘判交叉;三数之和忘了先排序 + 去重。**母题**:移除元素/移动零(快慢针)→ 两数之和 → 三数之和 → 顺时针打印矩阵 → 旋转矩阵。

### 族 9. 栈与队列族(6 样本,嵌入式加权后重要性远高于数字)

**考什么**:用基本结构互相模拟的实现能力——与嵌入式「用数组造一切」的思路同源;「两个栈实现队列」3 次全部来自嵌入式样本。

**解题认知(五条)**:① 数组造栈:`top` 下标 + 判满判空,push/pop 各一行;② 数组造队列:环形 + 取模——**这就是环形缓冲区本体**,与族 5 是同一道题的两种问法,复习时合并;③ 两个栈造队列:in 栈只进、out 栈只出,out 空了才把 in 整个倒过去(倒的时刻是关键,均摊 O(1));④ 最小栈:辅助栈与主栈同步,每 push 存「当前最小」;⑤ 括号匹配:左括号压栈,右括号弹栈比对,结束栈必须为空。**易错**:两栈队列在 out 非空时也去倒(破坏顺序);环形队列满空判别与族 5 同坑。**母题**:数组实现栈 → 两个栈实现队列 → 括号匹配 → 最小栈。

### 族 10. 二叉树与递归族(18 样本/15.5%)

**考什么**:递归函数的设计能力——三要素是否内化。

**解题认知(五条)**:① **递归三问先行**:这个函数的返回值代表什么?终止条件是什么?单层做什么(左右子树的信息怎么向上合并)?写任何树题前先口头答这三问,答不出 = 还没想清;② 遍历是地基:前/中/后序 DFS 递归版 + 层序 BFS(队列);非递归遍历 = 显式栈,考察「递归本质是隐式栈」的理解;③ 高频题全是「信息上汇」模式:深度 = max(左右)+1;平衡 = 左右深度差 ≤1 且两子树都平衡;LCA = 左右都有命中返回自己、只一边命中就透传;④ 嵌入式岗考频中等,「遍历(递归+非递归)+ 深度 + 层序 + LCA」四件覆盖绝大多数;⑤ 序列化/BST 转双链表是较难变式,先保四件。**易错**:LCA 忘了「树内有重复值/节点也等于 p 或 q」的边界;层序忘了按层分行(队列 size 快照)。**母题**:三种序遍历(递归)+ 前序非递归 → 层序 → 最大深度 → 判断平衡 → LCA。

### 族 11. 并发编程族(12 样本/10.3%)

**考什么**:互斥锁 + 条件变量的正确协作。与通用八股 P0 的进程线程线是同一条知识的「笔头版」——那边的理论已过,这边只差落成代码。

**解题认知(五条)**:① **生产者消费者 = 模板题**:环形队列 + 一把 mutex + 两个条件变量(not_full / not_empty);判条件用 `while` 不用 `if`(被唤醒后条件可能又变了 + 虚假唤醒);`pthread_cond_wait` 调用前必须持锁,返回时自动重新持锁——这三点是全部追问的来源;② 线程安全容器 = 每个公共方法加锁,或封装「锁 + 条件变量」的队列;③ 两线程交替打印 = 条件变量 + 「轮到谁」标志位,每方打印后唤醒对方、自己休眠;④ 线程池 = 任务队列 + 固定 worker 循环取任务 + shutdown 标志优雅收尾;⑤ 写的时候主动说「锁粒度只罩住共享数据临界区,不在持锁时做慢 IO」——这正是 NVR 项目审计过的坑(publish 快照 I/O),可反向引用。**易错**:if 判条件;双条件变量只用一个(死锁互相等错信号);忘 join 导致主线程先退。**母题**:生产者消费者(环形队列版)→ 两线程交替 → 线程池骨架(伪码级)。

## 五、T2 视投递四族(三句口径起步,投对应岗位再加量)

**族 12. C++类与设计族(24 样本,🔵 集中在 C++ 后台样本)**:核心四件 = String 类(构造/析构/拷贝构造/赋值四件套,深拷贝 + 自赋值检查,即「三法则」)、单例(私有构造 + 静态实例;线程安全直接用 C++11 局部静态变量 Meyers 版)、智能指针(shared_ptr 引用计数/控制块)、LRU(哈希表 + 双链表,O(1) 读写)。嵌入式校招维持三句口径;投 C++ 岗时升为精写族。

**族 13. DP/回溯/贪心族(19 样本,🔵 字节/腾讯/好未来类样本主成分)**:入门三板斧 = 爬楼梯/斐波那契(一维 dp)、最大子数组和、01 背包;套路固定 = 定义 dp[i] 含义 → 写转移方程 → 初始化 → 遍历顺序;回溯 = 递归 + 撤销选择的固定模板(全排列/组合总和)。嵌入式岗低频,投大厂算法浓的岗再补,先保一维 dp。

**族 14. 数学逻辑族(16 样本,🟡 笔试为主)**:素数(试除到 √n / 埃氏筛)、平方根(二分或牛顿迭代)、进制转换(除基取余逆序拼)。课后题难度,是细心分不是能力分,笔试前统一过一遍即可。

**族 15. 代码改错族(11 样本,🔴)**:不单独立项刷题,拿一张 bug 模式清单当「读码眼力」复习:返回局部变量地址 / 野指针 / ISR 里调用不可重入函数(malloc/printf)/ 共享变量缺 volatile / strcpy 无边界 / 数组越界 / #define 带分号陷阱。与八股的 C 细节线合并复习。

## 六、方向加权口径(嵌入式 vs C++ 池)

样本池混含嵌入式汇总与 C++ 后台样本,按既定「方向主成分」原则:

- **嵌入式子池主成分**(投嵌入式岗时真实频率比总表更高):链表、字符串库函数、位运算、宏、环形缓冲/状态机、冒泡——T0 六族就是嵌入式手撕的生死线。
- **C++ 后台大厂池主成分**(投 C++ 岗才需加量):C++ 类族、DP/回溯、LRU、线程池、最小覆盖子串类 hard 字符串题。
- **两池混考**:生产者消费者、单例、快排、TopK、二叉树遍历。
- **无手撕名单参考**:18 份无手撕样本里海康/大华/宇视/星宸/瑞芯微/兆易等在列——安防音视频链不少公司手撕不是硬关卡,**但同池的华为/小米/地平线/联发科/CVTE 手撕很重**,按投递清单分别对待,不能一刀切。

## 七、深入顺序建议(第一遍认知 → 第二遍母题)

**第一遍(本文档,约 1-2 小时)**:通读 §三/§四/§五,每族只求「考什么 + 认知条目能看懂」,不写代码。

**第二遍(母题精写,建议顺序)**——按「量大 × 套路密 × 已有基础」排:

| 序 | 族 | 理由 | 建议量 |
|---|---|---|---|
| 1 | 字符串·库函数手写族 | 题少套路密;已有 strcpy/memmove 基础,最快收全 | 5 母题 |
| 2 | 链表族 | 题量第一大户;反转+判环+合并三题覆盖近半频次 | 7 母题 |
| 3 | 位运算 + C 基本功族 | 嵌入式身份题,题小量大,合并推进 | 5+5 母题 |
| 4 | 嵌入式特色族 | 主场题;环形缓冲区单题频次第 3;直连 NVR 项目素材 | 4 母题 |
| 5 | 排序查找族 | 冒泡/快排/二分三件先背,堆/归并次之 | 5 母题 |
| 6 | 栈队列 + 字符串算法族 | 栈队列与环形缓冲同源,顺手收 | 4+6 母题 |
| 7 | 数组 + 二叉树 + 并发族 | T1 收尾;并发已有 P0 理论基础,只差落码 | 按余力 |

**每族深入的动作**(与现行验收场节奏一致):母题限时手写(不查资料)→ 讲清 why(契约/复杂度/边界)→ 接一个变式 → 隔场复写。T2 四族不进此排程,投递命中对应岗位再启动。

## 八、与现行手撕 10 题的衔接

现行 P0 手撕 10 题(见底稿 06 进度总表)全部落在 T0/T1 族内:strcpy 安全版、memmove 重叠(族 2)、链表反转(族 1)、大小端(族 3)、栈实现队列(族 9)、生产者消费者(族 11)——即 10 题线是本文 15 族体系的一个嵌入式核心子集。后续手撕推进建议直接以本文档的「族」为单元扩展:原 10 题完成者视作对应族的母题已过,族内剩余母题按 §七 顺序补齐,不再另立清单。
