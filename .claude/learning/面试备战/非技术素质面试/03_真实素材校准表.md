# 非技术素质面试·真实素材校准表

> **用途**：把 18 个核心答题单元里的【方括号】换成真实事实。只填写你亲历过的事，不补写、不美化、不编数字。
>
> **使用方式**：先填“事实”，再写“一句话版本”，最后才改写成 60–90 秒口述稿。没有证据的字段写“不确定”或“待核”，不要猜。
>
> **配套文件**：[01_总册_方法论与18题答案.md](01_总册_方法论与18题答案.md) · [02_题库_真题与来源.md](02_题库_真题与来源.md)

---

## 〇、填写原则

1. **一件事实只写一次**：完整故事放在本表，答案里引用，不重复造版本。
2. **结果优先于形容词**：写“原来多久/后来多久”“原来会怎样/后来是否解决”，不写“效果很好”。
3. **没有数字就写状态变化**：例如“原来靠手工，后来能稳定复现”，不要编百分比。
4. **区分记忆与推测**：不确定的细节标【待核】，面试前必须核实或删掉。
5. **隐私与敏感信息**：公司名、客户名、未公开代码、个人信息不要写进公网 AI；本表只记必要事实。

## 六、跨故事一致性检查

填完后逐项检查：

- [ ] 同一场面试不会把故事 A 用在三道以上题；
- [ ] 团队故事里能明确区分“我”和“我们”；
- [ ] 挫折故事不是人际抱怨或性格缺陷；
- [ ] AI 故事里有一个真实的错误，不是只说“AI 很好用”；
- [ ] 所有数字都有来源，没有来源的已改成状态变化；
- [ ] 缺点（单元 17）和职业规划（单元 18）说的是同一个能力缺口；
- [ ] 求职动机（单元 18）能对应公司真实业务，而不是空泛夸奖；
- [ ] 每个故事都能接住“具体怎么做的、为什么、怎么验证、重来怎么改”四层追问。

---

## 七、面试前最小准备集

至少准备以下四个故事，才进入口述练习：

1. 一个真实团队项目；
2. 一个真实紧急任务；
3. 一个真实 AI 出错/验证案例；
4. 一个真实学习或科研困难。

没有这四类素材时，先练流程和方法，不要把模板当成自己的经历。
