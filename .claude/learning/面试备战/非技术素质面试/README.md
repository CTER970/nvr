# 非技术素质面试专区

> 建立：2026-10-25。把原先分散在根目录的题库、方法论、表达框架和旧版答案整理为**三份现行文档**。
>
> 本专区只处理非技术素质题：AI 使用、学习方法、抗挫折、压力与优先级、团队协作、沟通分歧、自我认知、求职动机。技术八股、简历拷打、项目深挖不在这里。

推荐顺序：

1. 先读 `01` 的第一部分，理解评分与表达原则；
2. 再按目标题看 `01` 的对应单元；
3. 需要核对问法时查 `02`；
4. 把真实经历填入 `03`，再回过头改 `01` 里的【方括号】；
5. 最后录音练 60–90 秒主答案和 30 秒压缩版。

## 二、当前内容状态

### 已经比较完整、校准事实后可直接练

- 自我介绍；
- AI 使用、AI 错误、AI 边界、AI 影响；
- 快速学习、知识盲区、挫折、两难取舍、创新方法；
- 优缺点、求职动机与职业规划。

### 方法论和表达模板完整，必须填真实素材

- 紧急任务与优先级；
- 瓶颈、延误和资源不足；
- 团队角色与成就；
- 团队分歧；
- 帮助队友；
- 需求变化与适应新环境。

原因不是方法缺失，而是这些题要回答“队友是谁、你具体做了什么、结果如何”。没有真实事实时，硬编会在第二、三层追问露馅。

## 四、文档规则

1. **不再按日期创建新副本**。当前版直接更新 `01/02/03`；需要保留旧版时放 `_归档/`。
2. 新增题目先判断能否归入现有 18 个单元，不轻易增加题号。
3. 同一道题的新问法只在 `02` 做变体映射，不重复写答案。
4. 任何数字必须可追溯；没有记录就用前后状态变化，不编百分比。
5. 外部调查和公司流程只作参考，最终以邀请邮件、系统提示和真实面经来源为准。
