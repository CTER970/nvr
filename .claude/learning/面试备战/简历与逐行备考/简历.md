## 项目介绍

端边云三层架构的智能 NVR 边侧网关，运行于 IMX6ULL（800MHz Cortex-A7 单核，无 H.264 硬解）。端侧 V821 经 MIPI CSI 采集视频，H.264 硬编码后通过 Wi-Fi RTSP 推流；边侧以 C 多线程守护进程实现：拉流接入、7×24 循环录像、MJPEG 实时预览与 MP4 回放、抽帧上云识别与事件入库、GPIO 告警联动、Web 管理与配置热更新、RTSP 转发。

技术栈：C、pthread；FFmpeg（libavformat 拉流/remux，libavcodec 软解，libswscale 缩放）；SQLite；libcurl；HTTP（MJPEG/Range）与 RTSP/RTP 均为手写，无框架。

## 核心贡献

完成该网关在 i.MX6ULL 与嵌入式 Linux 上的部署联调与全部 11 个模块的源码级精读,打通拉流、录像、预览、回放、上云识别与转发全链路;针对无硬解约束,分析并验证「主通路压缩域直通、预览与上云按需软解」的分工,使录像转发与预览识别解耦;逐模块审计累计定位 26 处缺陷与工程隐患(覆盖数据正确性、掉电安全、网络字节序、锁内延迟四类典型),并据此补齐配置样例契约与配置接口输入校验。

## 技术亮点

①**零转码录像与掉电可恢复存储**：录像路径不解码、不转码，只做压缩域重新封装（remux），CPU 开销近零。按关键帧边界切分为多个视频段，每段采用 fragmented MP4，封装索引随各 fragment 就近写入而非集中压在文件尾，已写完的 fragment 在掉电后仍可播放。磁盘剩余低于水位时，按时间顺序删除最旧段，并保留正在写入的段，循环覆盖。

②**一次拉流，三路分发（录像/抽帧/转发）**：单拉流线程将同一路码流同步分发给录像、抽帧和转发，全程仅一次拉流。码流包由拉流线程统一消费与释放，下游只借用不持有；抽帧模块持续解码以维持 H.264 参考帧有效，任意时刻只保留最新一帧 JPEG。预览与识别以深拷贝取得该帧并自行释放，最新帧缓存为单写者多读者。

③**自研 RTSP 流媒体转发服务**：轻量 RTSP 服务，H.264 原样透传。SDP 内嵌源流参数集（SPS/PPS）供播放器完成解码初始化，超 MTU 的 NALU 按 FU-A 分片，支持 TCP interleaved 与 UDP 单播，RTP 时基 90kHz，各会话独立维护包序号。

④**自研 HTTP 媒体服务（MJPEG 预览 + MP4 回放）**：一连接一线程，慢客户端只占用自身连接线程。MJPEG 预览由服务端按固定节拍取最新帧，以 multipart 流持续推送，浏览器一次请求即可连续观看。MP4 回放按 HTTP Range 提供文件字节，播放位置由播放器按 MP4 索引换算。

⑤**云端 AI 识别与事件告警（失败只丢一帧）**：云端识别在独立线程内读取 JPEG 并完成 HTTPS 请求，失败只丢弃当前帧。有效事件写入 SQLite 后，由告警线程输出 GPIO。录像与本地预览独立于识别结果。

支撑句(项目介绍带过,不占条):配置 tmp+fsync+rename 原子保存。③回补核对已完成(09-28,609 行零硬伤),独立成条维持;归属自报收口前,③短板话术见 07 拷打表该节头。

   - ⑯**fMP4≠掉电零损坏**:缩小损坏范围(已完整 fragment 可播)≠零丢失(末 fragment/页缓存/文件系统元数据仍可能丢)。

## 1 分钟口述版(2026-09-21 v7 修订)

【定位】我的项目是跑在 IMX6ULL 上的边侧智能 NVR 网关,在端边云架构里守边缘这一层:端侧摄像头硬件编码后 RTSP 推流,我在板上完成 7×24 录像、抽帧识别和报警,只把结构化事件推上云。

【架构】板子 800MHz 单核、没有 H.264 硬解,所以录像和转发全程不解码——压缩域直通;只有 JPEG 抽帧旁路按需软解加节流,把像素域开销压到最小。

【亮点一】录像用 fragmented MP4:按关键帧切 fragment、索引随数据落盘,掉电时损坏范围缩小到末尾片段、已落盘的片段仍可播,避开传统 MP4 索引压在文件尾、断电整文件报废的问题。

【亮点二】抽帧通路只存最新一帧、不建队列——下游要的是当前画面不是历史,丢帧本身就是背压;取帧做拷贝并移交所有权,读者线程不会被写侧的 realloc 伤到。

【战绩】我把 11 个模块逐个做了源码审计,登记了 26 处缺陷,最典型的是配置保存不查 fflush/fsync 返回值——盘满时残缺的临时文件被 rename 转正、接口还报成功,整条事故链我推到底,后来据此补了配置接口的输入校验。

【稳定性】云端识别是独立旁路线程,超时失败不传染主链,云端挂了录像预览照跑;事件回调锁外执行,不持总线锁、不拖其他订阅者。

【角色】我负责板端部署联调和全模块源码精读,「我审出来的东西」和「每个选型为什么」我都能展开讲,您感兴趣我可以挑一条链路讲。
