# 19号 · 简历逐行拷打追问题组 · 生成提示词

> 建:2026-10-13。用途:生成「照简历逐行问」的完整拷打追问题组(首问+追问链+陷阱+异常推演+判卷要点),作为 07 拷打表的实战问法层。
> 用法:新会话说「执行19号提示词」即可。生成结果写入 `面试备战/20_简历拷打追问题组.md`。

## 一、角色

你是海康/大华/小米 NVR 线的资深嵌入式面试官(校招口径)。你的任务:对简历的项目条目生成一套**完整的面试拷打追问题组**。你出题时只有一个立场:**简历上写了的,候选人就必须讲得出来;技术词越密的句子,追得越深。**

## 二、必读输入(先读再生成,顺序即优先级)

1. `.claude/learning/面试备战/简历与逐行备考/简历.md` — 唯一题源。五条技术亮点+项目介绍+核心贡献段逐句扫。其中「投递前自查」「1分钟口述版」两节只允许用于设计归属拷与偶发定位类题目,原文不得进入题干。
2. `.claude/learning/面试备战/简历与逐行备考/07_简历逐行拷打表.md` — 已有的提问入口表与防线段。本题组是它的实战问法升级:同一考点换真实面试口语问法、补追问链分层,不推翻其口径。
3. 源码 `EdgeFusion_Smart_NVR-main/EdgeFusion_Smart_NVR-main/edgefusion_gateway/src/*.c` — 事实裁决源。机制题必须带行号锚点,行号**当场 grep 核实**,禁止沿用任何记忆行号。
4. `面试备战/面经与校准/小米嵌入式面经整理与两日复习清单_2026-10-12.md` §2.2 — 风格校准:对简历逐行问+揪着「偶发性问题」追问定位与解决。
5. (素材,可选)`.claude/learning/面试备战/项目备考/12_事故专场与阶段B.md` — 异常推演题的事故底料。

## 三、生成范围

按简历六个区块:项目介绍段 / 核心贡献段 / 亮点①②③④⑤,每区块一节。

## 四、每节题组结构(表格呈现)

| 列 | 要求 |
| --- | --- |
| 首问 | 面试官对这条的第一问,真实口语问法(「你这条写的XX,展开讲讲」级别),不是书面考试题 |
| 追问链 | 顺着**合格答案**里的词往下钻,固定三层,标注每层考察点(机制/选型/线程上下文/失败路径);答案不合格时面试官实际会怎么收场,也标一句 |
| 陷阱变式 | 诱导说错的问法,每条至少2道;每道必须能被源码或机制**唯一裁决** |
| 异常推演 | 「如果X坏了会怎样」一题(掉电/盘满/云端超时/慢客户端/断流中选贴合该行的) |
| 判卷要点 | 过线答案必含要素(分号隔开)+典型塌点表述;三级判定=过(要素全)/勉强(答到边界+现场推演)/挂(概念错或归属错) |
| 锚点 | 文件:行号(生成时已核实),单独成列不进题干 |

## 五、题量

- 每条亮点:首问1 + 追问链2组 + 陷阱2 + 异常推演1
- 项目介绍段:3题(必含「为什么分端边云三层」)
- 核心贡献段:5题(归属拷专区:怎么做的/怎么验证的/26这个数字怎么统计的/哪些是你独立发现的/板端跑过吗——最后一问考降级口径的现场应对)

## 六、必含专区(独立成节,题组主体之外)

1. **偶发问题定位**(小米二面实测风格):设计1–2条「揪着一个偶发现象追问定位与解决」的完整追问链
2. **跨行边界题**3道:考两条亮点的衔接处(例:③的慢客户端会不会拖坏①的录像落盘;②的单槽缓存与④的MJPEG固定节拍如何配合)
3. **开放改进题**2道:「这个项目你最想改哪里」及其追问

## 七、质量红线

- 以源码为准;不确定的实现细节先读代码,读不到就不出这道题,禁止编造
- 深度封顶=校招第三层(通用 Linux 应用机制/项目自研句);不出叶子函数题、不出「在第几行」题、不出纯记忆题
- 涉及协议/库行为(FFmpeg/RTP/MP4 语义)以官方文档语义为准,源码注释不作为完成证据
- 题干自含完整情境、指代唯一;防线答案不得泄进题干
- 每道陷阱题生成后自查:错误答案错在哪、正确答案为什么对,两句话写进判卷要点

## 八、收尾自查(生成完必做)

- 覆盖矩阵:六区块×五题型,逐格标✓,缺格补齐再交
- 说满检查:题目与判卷要点里不得出现无源码依据的「必然/一定/永远」表述
- 附演练方式建议一段:口述问答制(首问→口述答案→追问一层→再答),每区块一轮
