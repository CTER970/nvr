## 1. 任务目的与意义(四层)

① **为什么存在**:B2 反复在用"type 7/8"但没讲 type 从哪来——NALU 头第一字节的低 5 位是全阶段被引用最多的一个字段,B4(切分后判型)、B5(配置记录里的参数集)、B9(FU 头里藏的原 type)全部压在它上面。
② **项目背景**:parse_nalus 每切出一个 NALU,消费者(sdp_collect_cb / collect_cb 下游)第一件事就是 `nal[0]&0x1f` 判型分拣;整个转发器对码流的"理解"就这一字节,其余 passthrough——这是"自研 RTSP 但不解码"的准确技术表述。
③ **岗位/面试**:「字节 0x67,不查表说出它是什么」是 H.264 字节层经典筛人题——答得出=真拆过码流,答不出=只背过概念。
④ **学完能做**:不查表拆任意 NALU 首字节;讲清项目两处位运算(c:239 继承 F/NRI、c:255 取原 type)各取哪几位、为什么。

## 2. 前置概念声明(铁律21)

本块核心机制=**位掩码取字段**:协议头把多个字段装进一/两字节,用"按位与掩码+移位"取出目标段。与 V4L2 已知的 `v4l2_buf.flags & V4L2_BUF_FLAG_KEYFRAME` 同族:`0x1f` 就是掩码 `0b00011111`,`&` 完已是低位对齐,连移位都省了。协议字段位宽不是字节对齐时,全靠这套手法。

## 3. 标识符词源解析(铁律22)

- **NALU** = Network Abstraction Layer Unit。Network Abstraction Layer=网络抽象层(H.264 为"跨网络传输"设计的包装层),Unit=单元;一个 NALU = 1 字节头 + 载荷(RBSP)。
- 头三字段:**F**=Forbidden zero bit(禁位,规范恒 0,网络发现=1 可判损坏);**NRI** = nal_ref_idc(NAL Reference IDC,参考重要性,0=无参考价值可先丢,3=最重要);**type**=单元类型(低 5 位)。
- 项目用到的 5 个 type:**1** 非 IDR slice、**5** IDR slice、**7** SPS、**8** PPS、**28** FU-A(B9)。

## 4. 类比锚点

NALU 头=**快递面单**(1 字节写清三件事):是否违禁品(F)、优先级几颗星(NRI)、货物类型(type);载荷=箱内物品。分拣员(本项目 rtsp_server)不看箱内物品,只看面单决定送往哪个口。

## 5. 五件套草稿

- ① 一句话:每个 NALU 第 1 字节 = F(1bit)+NRI(2bit)+type(5bit);type 是流内分拣的唯一依据。
- ② 设计动机:**自描述单元**——每个单元自带类型与重要性,接收端/网络设备不解载荷就能分拣(参数集识别、拥塞时丢 NRI 低的)。
- ③ 结构:位布局 `|F(1)|NRI(2)|type(5)|`;0x67 = 0_11_00111。
- ④ 项目落点:c:122 判 7/8 收参数集;c:239 `(nal_hdr&0xE0)|28`(取高 3 位 F+NRI、type 换 28 造 FU indicator);c:255 `nal_hdr&0x1f`(原 type 存进 FU header)。三处同一字节的三个用法。
- ⑤ 面试变体:「`&0x1f` 取的是哪个字段?」「NRI 是什么?什么包可以被先丢?」

## 6. 字节样例库(2 正常+2 陷阱)

- **正常 1(四字节拆表,纸笔主操作)**:`0x67`(F=0,NRI=3,type=7 SPS)、`0x68`(PPS)、`0x65`(IDR slice,NRI=3)、`0x41`(非 IDR slice,NRI=2)。逐个拆三字段填表。
- **正常 2(项目真实验证)**:B2 解出的缺省 SPS 首字节 0x67、PPS 首字节 0x68——回收一次,确认 type 与 B2 结论一致。
- **陷阱 1(设计目的:NRI≠type,防只看高 3 位/字节值)**:`0x61` vs `0x65`——高 3 位同为 `011`,低 5 位 `00001` vs `00101`;0x61 是"高优先级的非 IDR slice",0x65 才是 IDR。数值只差 4,语义完全不同。
- **陷阱 2(设计目的:分清"码流里的头"vs"传输层自造的头")**:`0x7C` = 0x60|28——它**不是**码流里真实存在的 type 28 NALU,而是本项目发送时造的 FU-A indicator(B9);真正的 type 5 藏在下一字节 FU header 低 5 位。重组时 0x7C 要被换回 0x65。先埋这个钉子,B9 收口。
