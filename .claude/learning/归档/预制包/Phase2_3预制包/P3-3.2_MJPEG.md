## 1. 任务目的（四层）

① 链路 B（预览）的出口全在这 30 行——「浏览器为什么能直播」的答案。② 项目背景：浏览器原生不播 RTSP，MJPEG 是最轻的兼容方案；与 rtsp_server（自研 RTP）构成「同一帧的两种封装出口」，选型对比是现成面试题。③ 岗位背景：multipart/x-mixed-replace 是嵌入式摄像头 Web 预览的事实标准；「一次 send 语义/短写」在此显形。④ 学完交 JPEG→浏览器时序图，3.3 Range 是它的姊妹卡（同一 fd 上的另一种输出）。

## 2. 数据流坐标

链路 B：`frame_grabber g_jpeg（生产节流=web_mjpeg_fps，经 set_target_fps）→ get_jpeg malloc 拷贝（web 客户端线程）→ multipart part 头+JPEG 字节 → send → free → usleep(200ms) → 下一帧`。

## 3. 锚点（已实测，serve_mjpeg 185-215）

## 4. 卡内前置（铁律 21/22）

- **multipart/x-mixed-replace**（卡内讲）：「连续包裹」机制——响应体=无限个 part，每 part 以 `--boundary` 分隔条开始、自带小 Content-Length 定界；`x-mixed-replace`=浏览器每收到新 part 就**替换**画面（不是追加）。类比：一直寄包裹，每件贴分隔条，收一件挂一件。
- 词源：`boundary`（边界/分隔条，头里声明、体里以 `--` 前缀出现）；`mixed`（混合多部件）；`replace`（替换语义）。
- 迁移：get_jpeg 四后果（1.9-Q4）；生产/消费节流分离（2.1-Q6 在此闭环）。

## 5. 引导问题（手册 7 问照用）

1. 为什么不直接用 RTSP 而用 MJPEG？（浏览器原生不支持 RTSP；MJPEG=纯 HTTP 零插件零依赖）
2. 整体 header、boundary、单帧头、JPEG 字节的发送顺序？（见锚点表——流头一次/part 头每帧）
3. buffer 谁 free？三个发送点失败都收口吗？（每轮 free c:212；前两个 send<0 分支 free+break c:209-210，**第三 send 尾包不看返回**——小审计）
4. 无新 JPEG 怎么避免忙等？客户端断开怎么退出？（100ms 退避；send 返回≤0 即 break——TCP 断开触发）
5. `web_mjpeg_fps` 热更新改发送 sleep 还是产帧率？（**生产端** set_target_fps；发送侧固定 200ms——审计⑧）
6. 固定 200ms 下「发送 fps 与配置严格一致」成立吗？（上限≈5fps；配置 8 时发送仍 5——可见帧率=min(生产,5)）
7. 一次 send 成功=整个 buffer 发完吗？（否——短写；当前不处理=审计⑦，对照 rtsp_server send_all）

## 6. 产出与通过标准

JPEG拷贝→part头→JPEG→free→下一帧/断连时序图；生产fps/发送周期/可见帧率三栏区分表；慢客户端+阻塞 send+短写三边界口述。通过=三栏表（生产 fps / 发送 200ms / 可见 min）+ 断连靠 send≤0 退出。短写只要求「一次 send 成功≠整缓冲发完，本实现不处理」一句。

## 7. 闭卷与变式（已过深度滤网）

- 闭卷：默写一个发送循环轮（含无帧/断连/正常三分支）。
- V1（变式）：慢客户端 TCP 缓冲满，send 阻塞——这个 web 客户端线程拖住谁？别的预览页/别的 API 受影响吗？（线程-per-连接隔离；被拖的只有这一路+它占住的 g_jpeg 拷贝——C3-V2 复现）
- V2：两个浏览器同时开 /stream，frame_grabber 产 5fps，两路各自拿到完整序列吗？（各自独立 get_jpeg 拷贝；可能交错取到不同帧，但各自完整可用——「单槽多读者」复习）
- 提升池（一句话）：WebSocket/WebRTC 是更现代方案，带宽/延迟各有取舍，本项目不涉及。

## 8. 预制时审计发现（核实后用）

⑦全 web 无短写处理（send_http c:123-124 同病）；⑧200ms 固定节流；尾包 send 不查返回 c:211。慢客户端 send 阻塞还会**占住该连接的 JPEG 拷贝内存**（free 推迟）——一句话。

## 9. 快问快答

1. 为什么流头只发一次而 part 头每帧发？（会话头 vs 单件快递单）
2. MJPEG 一路带宽多大？（≈帧率×JPEG大小，640×360 q70 约 30-60KB/帧——心算演示）
3. 断开后线程怎么终结？（send 失败 break→client_thread close fd→线程退出）
4. 为什么 MJPEG 不能拖动回放？（无历史，只有「最新」——对照 3.3 Range 的是文件）
