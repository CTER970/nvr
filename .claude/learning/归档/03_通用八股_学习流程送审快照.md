## 四、单场学习流程(核心循环)

```
平时:学习者在飞书文档自学若干知识点(相关知识点凑一批)
  ↓ 学完主动触发:「拷打通用八股〈主题〉」(可一次报多个相关主题)
开场设置(1–2 轮):确认主题范围 + 本场题数(约 8–12 题)
  ↓ 若错题册有存货 → 先抽检 3–5 道旧错题(变式形式),再开新题
场内(冷面,模拟真实面试):
  · 一次只问一题,等回答
  · 从答案里挑词追问下钻 2–3 层,直到边界或断点
  · 不纠错、不提示、不评价(答错只记录)——防「当场提示→假性掌握」
  · 察觉背书感(答案过顺/过书面/像背材料)→ 换变式或要求现场推演
  · 学习者喊「结束」或题数用尽 → 收场
场后:
  · 出塌点报告(格式见 §六)
  · 复盘解禁:此时可逐题讲解、答疑(教学只发生在场后)
  · 错题入册 + 在覆盖地图上标记本场覆盖的题号
  ↓ 下一场开场回到「抽检」环节,形成循环
```

判分三档(每题一判):

| 档 | 定义 | 判据 |
| --- | --- | --- |
| ✅ 过 | 机制层立住 | 能说清 why(不只结论),且能应对一层变式 |
| ⚠️ 条件过 | 结论层对,缺口 ≤1 处 | 或「答到自己真实边界 + 现场推演姿态」兜住 |
| ❌ 不过 | 概念错/卡壳 | 含把学习材料里的错误事实当真 |

> 判卷基准=机制+权威源。学习者答案与其自学材料冲突时,**按机制判**,并将材料可疑条目记入「底稿存疑」栏(附建议核验源;已有先例:某材料称 delete[] 按逆序析构,C++ 标准实际未规定顺序)。

## 五、纠错机制

1. **场内零纠正**(冷面),含糊回答只记录——理由:模拟真实面试压力;当场提示会让「听过」冒充「会」。
2. **场后复盘**:塌点报告驱动,学习者可指定任意题要求讲透;这是唯一的当场教学通道。
3. **错题册数据模型**(每条错题一行):

| 字段 | 说明 |
| --- | --- |
| 编号/主题 | 如「TCP挥手-TIME_WAIT意义」 |
| 日期/判定 | 三档之一 |
| 缺什么 | 错因四分类:概念错 / 机制空心(只有结论)/ 背书感 / 材料源错误 |
| 变式复测状态 | 未测 / 通过 / 未通过 |
| 下次抽检安排 | 默认下一场开场 |

4. **变式复测规则**:错题必须以「换条件重问」的形式通过才算清零;原题重答通过不算——防「再认」冒充「回忆」。
5. **防背书**:三件套=追问下钻(从答案挑词)/变式(换条件)/实证要求(现场推演、举反例)。
6. **底稿存疑闭环**:存疑条目记录材料原话+建议核验源,复盘时明确告知学习者「这条别背」。

## 六、复盘与总结

- **场级**:塌点报告=逐题表(问题/回答要点忠实记录/判定/追问链在第几层断)+ 总评(该主题 N 题:几过几条件几挂,塌在哪层)+ 塌点清单(每条=现象+缺什么+回补入口)。
- **域级(卷级)收口**:①跨题串联——把该域题目织成主题网络(例:把对齐/内存分区/大小端串成「程序怎么躺在内存里」),防碎片化;②该域错题全部变式清零;③覆盖地图打勾。
- **跨域混合抽考场**:每 3–4 场插一场,从已通过域随机混抽(模拟真实面试的跳跃式提问+对抗遗忘曲线)。

## 七、后续复习(间隔循环设计)

| 机制 | 频率 | 说明 |
| --- | --- | --- |
| 开场错题抽检 | 每场 3–5 题 | 优先抽:距上次答错最久的、曾两次未清零的 |
| 错题清零标准 | 变式通过 ×1 | 连续两次变式通过 → 移出高频抽检池(降频随访) |
| 已过域维持 | 不重学,只抽检 | 靠检索练习维持,不重新通读材料 |
| 跨域混合场 | 每 3–4 场一次 | 见 §六 |
| 临面收口 | 有邀约时触发 | 按 JD 加权抽一场专项 + 错题册高危项过一遍 |

## 八、防偏差与质量控制

1. **异源出题**:出题方不读学习者的飞书材料,按主题的标准校招问法自出——测的是理解不是复述;代价=题目可能覆盖材料外内容,这被视为特性(补盲区)而非缺陷。
2. **覆盖地图+搭题**:自选主题的已知风险是舒适区偏置与漏网。对冲=①每场在底稿题纲上标记覆盖;②学习者点名的主题必考之外,同域相邻高频题搭抽 1–2 题。
3. **缺页纪律**:题纲缺页的题不出;识别截断的题重述题干。
4. **与主项目的挂接三档**(重叠约 6 域:大小端/粘包/锁/epoll/队列模型/IPC):
   - 挂接滑入:允许且鼓励把通用机制滑入项目实例(如大小端→项目里的 htons 字节序缺陷);
   - 防挂错:禁止把通用机制错安到项目上(如 epoll 并非该项目在用模型——该用一连接一线程;生产者-消费者队列并非项目实况——项目是单槽覆盖式最新帧);
   - 送分快过:学习者已超规格持有的域(如 V4L2/mmap/Socket 编程)快速过,不耗时间。
5. **出题方自身约束**:不确定的事实必须查权威源后判;判卷宁严不松,但「边界+现场推演」可判条件过。

## 九、已知风险与未决问题(请审查方重点评估)

1. **纯冷面的学习效率**:新知识依赖学习者先在飞书自学,场内零纠正。若自学质量差,大量「不过」,纠偏全压在场后复盘——是否太晚?是否应对全新域恢复「逐题刷题-当场纠正」模式(该模式已保留为可选)?
2. **自选主题防漏**:覆盖地图+搭题 1–2 是否足以对冲舒适区偏置?
3. **复习密度**:开场抽检 3–5 题/场,对 60–100 缺口+后续累积错题的规模,是否够?间隔是否应显式分档(如 1 天/3 天/7 天)?
4. **判分信度**:三档制靠 AI 主观判定,同一答案跨场稳定性无校验机制,是否需要抽判一致性检查?
5. **时间预算**:阶段1(三高优域,合计约 80–100 题)计划两周、每天 45–90 分钟投入——现实吗?
6. **手撕排期**:排在阶段1 中段启动,嵌入式一面常见当场手写,是否应提前?
7. **混合场频率**:每 3–4 场一次是否最优?
8. **存疑闭环**:材料错误已记「底稿存疑」,但学习者是否可能把存疑答案又背回去(目前只有口头提醒,无强制核验动作)?
