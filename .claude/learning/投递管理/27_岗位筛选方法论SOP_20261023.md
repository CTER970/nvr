## 一、四层漏斗（标准流程）

```
层1 标准层：目标岗 = 嵌入式 Linux 用户态应用开发（C/C++，多线程/socket/网络协议为技能特征）
            音视频方向（RTSP/RTP/FFmpeg/编解码/IPC/NVR/相机）= 强加分，非必要
层2 排除层：红灯词否决（v2 词表沿用）
            + 行业级排除（本轮新增，见下）
层3 初筛层：逐家官网/搜索引擎核"岗位名+JD 摘要"，命中关键词组合的进入层4
层4 精筛层：JD 三招定生死——职责动词（开发/联调/维护=应用✅；移植/bring-up=驱动❌；调优/训练=算法❌）
            + 关键词密度 + "经验优先"栏
```

## 二、行业级排除规则（层2 新增，省掉无效官网核）

以下行业的公司**跳过层3**（其"嵌入式软件工程师"经验证为电机控制/RTOS/驱动向，命中率趋近于零）：
- 机器人/具身智能（除非岗位名明确含"音视频/相机/多媒体"）——今晚实证 ~25 家全军覆没
- IC/芯片设计公司（软件岗稀少，多为设计验证/固件）
- 装备制造/工业自动化/轨交/电力（PLC/运动控制/BMS 为主）
- 纯互联网/金融科技（无嵌入式岗）

**保留核验的行业**：消费电子/安防监控/音视频/智能硬件/网络通信/汽车智能座舱（多媒体向）/医疗影像设备。
