## 教学模式:三步制

对脊梁上的未学模块(event_bus 剩余 / alarm / web / conf),每个模块:

**① 教练系统讲解(10–15min)**——铁律 1:
- 模块在 4 条链路的位置与一句话职责;
- 框架:几个线程、主循环在哪、核心状态谁创建谁释放(一句话);
- 主要函数地图(铁律 8:入口 / orchestrator / 阶段边界 / 核心数据 / 叶子点名即过);
- 一层选型 why。函数结论必须带已核实的 `文件:行号`。

**② 学生函数功能级过码(25–60min)**:
- `.h` 全读;
- `.c` 主要函数逐个扫函数体,每函数一句话「做什么 / 输入输出 / 主流程哪一步」;
- 错误分支只标记出口类型,不展开失败矩阵;
- 叶子只看名字;
- web.c:`handle_client_inner` + 四代表(mjpeg / Range / events / config POST),其余 URL 映射。

**③ 学生口述(约 10min)** → 卡点入 `复述卡点清单.md` → 过闸写入 `过码台账.md`。

**已学内容不走三步、不重讲**:Phase 1 三模块、2.1/2.2、C1、C2、SQLite 前置、第 1 讲。段 1 对 stmt 五步 / copy-then-release 最多一句挂钩。

**联系课**(段 3 / 段 6)不走三步,走「数据形态换了几次 + 途经函数名」口述。
